# W-41 — Partager une page entière de notes bibliques avec une autre machine

Jusqu'ici, une note ne pouvait quitter l'application qu'**un élément à la fois**. Un fichier de notes entier —
toutes les notes qu'il contient, les images et les clips qui s'y trouvent, et l'arrière-plan que vous y avez
joint — voyage désormais en un seul paquet.

1. Dans le panneau **[en:tran:Bible Notes]**, cliquez sur le `⋮` du fichier de notes voulu (ou faites un clic droit
   sur son nom) et choisissez **[en:tran:Export]**. Il se trouve juste sous **[en:tran:Import]**. 📸
2. Un petit panneau affiche deux cases, **[en:tran:Password]** et **[en:tran:Confirm Password]**. Laissez les deux vides pour un paquet ordinaire, ou tapez le même
   mot de passe dans les deux pour le verrouiller. Appuyez sur **[en:tran:Ok]**.
3. Vous obtenez un seul fichier `<name>.owanote.tar.gz` dans votre dossier **Téléchargements** (Downloads) —
   `<name>.owanote.enc` si vous avez mis un mot de passe — et l'application ouvre le dossier en vous le montrant. 📸

   > Tout ce vers quoi une note pointe voyage à l'intérieur : une image que vous avez collée, un clip que vous avez inséré,
   > le fichier son que vous avez joint. Ce paquet est donc bien plus gros que celui d'une liste biblique :
   > laissez un moment à une note pleine de vidéos pour finir.

   > **Il contient ce que vous avez tapé en dernier, pas ce que vous avez enregistré en dernier.** Une fenêtre de note
   > garde votre saisie jusqu'à ce que vous appuyiez sur **[en:tran:Save]** (W-14), et le paquet
   > est écrit à partir de la note telle que cette fenêtre l'a — ainsi rien de ce que vous avez tapé
   > n'est laissé de côté, que vous ayez pensé à enregistrer avant ou non.

4. Sur l'autre machine, cliquez sur le `⋮` en haut du panneau **[en:tran:Bible Notes]** → **[en:tran:Import]** et choisissez le fichier — ou **faites glisser le `.owanote.tar.gz` (ou le `.owanote.enc`) sur
   le panneau Notes bibliques**. Un paquet protégé demande d'abord son mot de passe.
   **[en:tran:Import From URL]** fonctionne aussi ici si le paquet est sur le web. 📸
5. Le fichier de notes apparaît dans le dossier des notes de cette machine avec toutes ses notes, vos
   surlignages et commentaires, et ses images et clips lus depuis les copies locales.

   > Si un fichier de notes de ce nom s'y trouve déjà, le vôtre n'est jamais écrasé : le
   > fichier importé arrive à côté sous le nom `name (1)`. Renommez celui que vous préférez.

6. Pour déplacer une **seule note** au lieu de la page entière, utilisez le `⋮` de cette note →
   **[en:tran:Export]**, puis **[en:tran:Import]** sur le fichier de notes où elle doit arriver — n'importe quel fichier de notes,
   pas seulement **Default**. Cette méthode emporte aussi votre saisie non enregistrée.
