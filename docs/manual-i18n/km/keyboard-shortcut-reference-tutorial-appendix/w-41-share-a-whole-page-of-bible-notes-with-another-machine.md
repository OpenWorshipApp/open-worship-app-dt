# W-41 — ចែករំលែកទំព័រកំណត់ត្រាព្រះគម្ពីរទាំងមូលជាមួយម៉ាស៊ីនមួយទៀត

ពីមុនមក កំណត់ត្រាអាចចេញពីកម្មវិធីបានតែ **ម្ដងមួយធាតុៗ** ប៉ុណ្ណោះ។ ឥឡូវ ឯកសារកំណត់ត្រាទាំងមូល — កំណត់ត្រាទាំងអស់នៅក្នុងនោះ រូបភាព និងវីដេអូនៅក្នុងកំណត់ត្រាទាំងនោះ និងផ្ទៃខាងក្រោយដែលអ្នកបានភ្ជាប់ជាមួយវា — អាចផ្ញើទៅជាកញ្ចប់តែមួយ។

1. នៅក្នុងផ្ទាំង **[en:tran:Bible Notes]** ចុច `⋮` លើឯកសារកំណត់ត្រាដែលអ្នកចង់បាន (ឬចុចកណ្ដុរស្ដាំលើឈ្មោះរបស់វា) ហើយជ្រើស **[en:tran:Export]**។ វានៅខាងក្រោម **[en:tran:Import]** ភ្លាម។ 📸
2. ផ្ទាំងតូចមួយនឹងសួររក **[en:tran:Password]** និង **[en:tran:Confirm Password]**។ ទុកប្រអប់ទាំងពីរឱ្យនៅទទេ សម្រាប់កញ្ចប់ធម្មតា ឬវាយពាក្យសម្ងាត់ដូចគ្នាក្នុងប្រអប់ទាំងពីរ ដើម្បីចាក់សោវា។ ចុច **[en:tran:Ok]**។
3. អ្នកនឹងទទួលបានឯកសារ `<name>.owanote.tar.gz` មួយ ក្នុងថត **Downloads** របស់អ្នក — ឬ `<name>.owanote.enc` ប្រសិនបើអ្នកបានដាក់ពាក្យសម្ងាត់ — ហើយកម្មវិធីនឹងបើកថតនោះ ដោយបង្ហាញឯកសារនោះ។ 📸

   > អ្វីៗទាំងអស់ដែលកំណត់ត្រាមួយចង្អុលទៅ ត្រូវបានដាក់ចូលក្នុងកញ្ចប់៖ រូបភាពដែលអ្នកបានបិទភ្ជាប់ វីដេអូដែលអ្នកបានបញ្ចូល ឯកសារសំឡេងដែលអ្នកបានភ្ជាប់។
   > ដោយហេតុនេះ កញ្ចប់នេះធំជាងកញ្ចប់បញ្ជីព្រះគម្ពីរច្រើន ដូច្នេះសូមរង់ចាំបន្តិច ឱ្យកំណត់ត្រាដែលមានវីដេអូច្រើនបញ្ចប់។

   > **វាផ្ទុកអ្វីដែលអ្នកបានវាយចុងក្រោយ មិនមែនអ្វីដែលអ្នកបានរក្សាទុកចុងក្រោយទេ។** បង្អួចកំណត់ត្រាមួយ
   > រក្សាការវាយរបស់អ្នក រហូតដល់អ្នកចុច **[en:tran:Save]** (W-14) ហើយកញ្ចប់ត្រូវបានសរសេរចេញពីកំណត់ត្រា
   > តាមដែលបង្អួចនោះមាន — ដូច្នេះគ្មានអ្វីដែលអ្នកបានវាយត្រូវបាត់ទេ ទោះអ្នកចាំរក្សាទុកជាមុនឬអត់ក៏ដោយ។

4. នៅលើម៉ាស៊ីនមួយទៀត ចុច `⋮` នៅខាងលើផ្ទាំង **[en:tran:Bible Notes]** → **[en:tran:Import]** ហើយជ្រើសឯកសារនោះ — ឬ **អូសឯកសារ `.owanote.tar.gz` (ឬ `.owanote.enc`) មកទម្លាក់លើផ្ទាំងកំណត់ត្រាព្រះគម្ពីរ**។ កញ្ចប់ដែលមានការការពារ នឹងសួររកពាក្យសម្ងាត់របស់វាជាមុន។ **[en:tran:Import From URL]** ក៏ប្រើបាននៅទីនេះដែរ ប្រសិនបើកញ្ចប់នោះនៅលើអ៊ីនធឺណិត។ 📸
5. ឯកសារកំណត់ត្រានឹងលេចឡើងក្នុងថតកំណត់ត្រារបស់ម៉ាស៊ីននោះ ជាមួយនឹងកំណត់ត្រាទាំងអស់របស់វា ការគូសពណ៌ និងមតិយោបល់របស់អ្នក ហើយរូបភាព និងវីដេអូរបស់វា ចាក់ពីច្បាប់ចម្លងនៅលើម៉ាស៊ីននោះផ្ទាល់។

   > ប្រសិនបើមានឯកសារកំណត់ត្រាឈ្មោះដូចគ្នានៅទីនោះរួចហើយ ឯកសាររបស់អ្នកមិនដែលត្រូវសរសេរជាន់ពីលើទេ៖
   > ឯកសារដែលនាំចូលនឹងមកនៅក្បែរវា ជា `name (1)`។ ប្ដូរឈ្មោះមួយណាក៏បាន តាមដែលអ្នកចូលចិត្ត។

6. ដើម្បីផ្លាស់ទី **កំណត់ត្រាតែមួយ** ជំនួសឱ្យទំព័រទាំងមូល សូមប្រើ `⋮` លើកំណត់ត្រានោះ → **[en:tran:Export]** ហើយ **[en:tran:Import]** លើឯកសារកំណត់ត្រាដែលអ្នកចង់ឱ្យវាទៅដល់ — ឯកសារកំណត់ត្រាណាក៏បាន មិនមែនតែ **Default** ទេ។ វិធីនោះក៏ផ្ទុកការវាយដែលមិនទាន់រក្សាទុករបស់អ្នកដែរ។
