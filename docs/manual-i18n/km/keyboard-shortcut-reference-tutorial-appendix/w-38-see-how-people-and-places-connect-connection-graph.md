# W-38 — មើលពីរបៀបដែលមនុស្ស និងទីកន្លែងភ្ជាប់គ្នា (ក្រាបទំនាក់ទំនង)

បង្អួចធាតុប្រាប់អ្នកថា _នរណា_ ជានរណា។ ក្រាបបង្ហាញអ្នកថា _ពួកគេភ្ជាប់គ្នាដោយរបៀបណា_ —
ឪពុកម្ដាយ ប្ដីប្រពន្ធ កូន បងប្អូនជីដូនមួយ និងទីកន្លែង ទាំងអស់នៅលើផ្ទាំងក្រណាត់តែមួយ ដែលអ្នកអាចរុករកបាន។

1. បើក **[en:tran:Names and locations lookup]** (`👤📍`) ពីក្បាលនៃការស្វែងរកព្រះគម្ពីរ ហើយរកមនុស្សម្នាក់ — សាកល្បង **យ៉ាកុប** (Jacob)។ 📸
2. ចុច **⋮** នៅចុងខាងស្ដាំនៃជួរ — ឬ **ចុចកណ្ដុរស្ដាំ** លើជួរ — ហើយជ្រើស **[en:tran:Open Graph Preview]**។ បង្អួចអណ្ដែតមួយនឹងបើកឡើង ដោយមានមនុស្សនោះនៅកណ្ដាល។
   > អ្នកអាចចុចកណ្ដុរស្ដាំលើឈ្មោះមួយ នៅកន្លែងណាក៏បាន ដែលវាអាចចុចបានរួចហើយ — ក្នុងបញ្ជី ក្នុងផ្ទាំង

   > នៃបង្អួចធាតុ។ **⋮** មាននៅលើជួរនៃកន្លែងពីរដំបូង ដែលជាកន្លែងដែលអ្នកនឹងទៅរកវា។ បង្អួចធាតុ
   > ក៏មានរូបតំណាងដ្យាក្រាមតូចមួយ នៅក្បែរចំណងជើងរបស់វាដែរ។
3. ប្រអប់នីមួយៗបង្ហាញលេខមួយ នៅក្បែររូបតំណាងដ្យាក្រាមតូចមួយ — នោះគឺជាចំនួនធាតុពាក់ព័ន្ធដែលវាមាន។ **ចុចលើលេខនោះ។** ម៉ឺនុយមួយនឹងបើកឡើង ដោយរាយ **[en:tran:All] (47)** មុនគេ បន្ទាប់មក មានតែប្រភេទដែលធាតុនេះពិតជាមាន៖ _ឪពុកម្ដាយ (2)_, _ប្ដីប្រពន្ធ (4)_, _បងប្អូន (2)_, _កូន (16)_, _បងប្អូនជីដូនមួយ (22)_, _ទីកន្លែង (1)_។ 📸
4. ជ្រើសប្រភេទមួយ — ឧទាហរណ៍ **[en:tran:Children]** — ហើយមានតែប្រអប់ទាំងនោះប៉ុណ្ណោះដែលលេចឡើង ជារង្វង់ជុំវិញមនុស្សនោះ ហើយភ្ជាប់ដោយខ្សែកោង។ ខ្សែនីមួយៗមានស្លាកទំនាក់ទំនង ដូចដែលអ្នកនិយាយ៖ _កូនប្រុស_, _កូនស្រី_, _ប្រពន្ធ_, _ឪពុក_, _ស្ថិតនៅ_។

   > ប្រអប់សែសិបជាងក្នុងពេលតែមួយ គឺច្រើនណាស់សម្រាប់អាន។
5. រុករក៖ **អូស** ប្រអប់ណាមួយ ដើម្បីផ្លាស់ទីវា (វានៅកន្លែងដែលអ្នកដាក់) **អូសផ្ទាំងក្រណាត់ទទេ** ដើម្បីរំកិលមើល ហើយ **រមូរ** ដើម្បីពង្រីក និងបង្រួម ជុំវិញទ្រនិចរបស់អ្នក។ **ចុចពីរដង** លើប្រអប់មួយ ដើម្បីធ្វើឱ្យវាក្លាយជាកណ្ដាលថ្មី។

   > _ប្រើជាចំណុចចាប់ផ្ដើម_ សម្អាតអ្វីៗផ្សេងទៀតចេញ ហើយទុកតែប្រអប់នោះ ដូច្នេះអ្នកអាចចាប់ផ្ដើមរុករកម្ដងទៀត
   > ពីធាតុដែលនៅមុខអ្នករួចហើយ។ វាមានអ្វីៗទាំងអស់ដែលប៊ូតុងតូចៗនៅខាងក្រោមប្រអប់ធ្វើបាន ហើយ
   > វាក៏ដំណើរការលើប្រអប់ដែលអ្នកបានបង្រួម ដែលលាក់ប៊ូតុងទាំងនោះ។ ជួរដែលអ្នកមិនអាចប្រើបាន

8. **រកខ្សែភ្ជាប់ពីមនុស្សនេះទៅមនុស្សម្នាក់ទៀត។** ចុចរូបតំណាងស្លាកសញ្ញាផ្លូវ នៅជ្រុងខាងលើផ្នែកខាងស្ដាំ។ កណ្ដាលរបស់ក្រាប គឺជាចំណុចចាប់ផ្ដើមរួចហើយ — វានៅទីនោះជាបន្ទះមួយ — ដូច្នេះអ្នកគ្រាន់តែប្រាប់ថា អ្នកចង់ **ទៅដល់** ណា។ សម្រាប់ឧទាហរណ៍នេះ បើកក្រាបលើ **ដាវីឌ (David)** (ជំហាន 2 ពីជួររបស់គាត់) ជំនួសឱ្យយ៉ាកុប — ពីយ៉ាកុប ខ្សែសង្វាក់វែងជាងអ្វីដែលការស្វែងរកអនុញ្ញាត ដូចដែលកំណត់សម្គាល់ខាងក្រោមបានប្រាប់ — បន្ទាប់មកវាយ **jesus** ជ្រើស **យេស៊ូវ (Jesus)** ពីបញ្ជី (ឈ្មោះនីមួយៗត្រូវបានផ្ដល់ឱ្យ ជាមួយឈ្មោះភាសាអង់គ្លេសរបស់វានៅក្បែរ) ហើយចុច **[en:tran:Find Connection]**។ ផ្ទាំងក្រណាត់នឹងពេញដោយជំនាន់ៗ ពីដាវីឌ ចុះមកដល់ព្រះយេស៊ូវ ដោយខ្សែភ្ជាប់ត្រូវបានបន្លិច ហើយប្រអប់នីមួយៗនៅលើខ្សែនោះ នៅតែអាចពន្លាបាន។ 📸
