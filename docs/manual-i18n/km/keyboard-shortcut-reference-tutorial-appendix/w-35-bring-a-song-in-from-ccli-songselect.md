# W-35 — នាំចម្រៀងចូល ពី CCLI SongSelect

ប្រសិនបើក្រុមជំនុំរបស់អ្នក មានសិទ្ធិប្រើ CCLI **SongSelect Partner API** កម្មវិធីអាចស្វែងរកក្នុង SongSelect
ហើយប្ដូរចម្រៀងមួយ ទៅជាឯកសារទំនុកច្រៀងដោយផ្ទាល់ — មិនចាំបាច់វាយឡើងវិញទេ។ អ្នកត្រូវការព័ត៌មាន
សម្គាល់ API ដែល CCLI បានផ្ដល់ឲ្យអ្នក (**Client ID**, **Subscription Key** និង
**Redirect URI** ដែលអ្នកបានចុះឈ្មោះ។ អតិថិជនខ្លះ ក៏មាន **Client Secret** ដែរ)។

> CCLI បានបញ្ឈប់ការចុះឈ្មោះដៃគូថ្មីហើយ ដូច្នេះវាដំណើរការតែជាមួយព័ត៌មានសម្គាល់ ដែលអ្នក
> មានរួចហើយប៉ុណ្ណោះ។ អ្វីៗខាងក្រោម ត្រូវបានសាកល្បងផ្ទាល់ ជាមួយម៉ាស៊ីនមេ SongSelect ជំនួស។ ការប្រគល់វេន
> ចូលគណនីចុងក្រោយ ទៅទំព័រយល់ព្រមពិតរបស់ CCLI ត្រូវបានផ្ទៀងផ្ទាត់តាមកូដប្រភព ប៉ុន្តែ **មិនទាន់បានសង្កេតឃើញ**
> ពីដើមដល់ចប់ទេ ដោយសារគ្មានព័ត៌មានសម្គាល់ពិត។

1. បើក **[en:tran:Settings]** → **[en:tran:Others]**។ ខាងលើ **[en:tran:Extra Binaries]**
   មានកាតមួយ ដែលមានចំណងជើង **[en:tran:SongSelect Integration]** ជាមួយប៊ូតុង
   **SongSelect ↗** ដែលបើក songselect.ccli.com នៅក្នុងកម្មវិធីរុករករបស់អ្នក។ កាតដែល
   បង្ហាញតែចំណងជើងរបស់វា គឺត្រូវបានបត់ — ចុចចំណងជើង ដើម្បីបើកវា។ 📸
2. បំពេញ **Client ID**, **Subscription Key** និង **Redirect URI** (និង **Client Secret**
   ប្រសិនបើអ្នកមាន)។ វាលនីមួយៗ រក្សាទុកភ្លាមៗ នៅពេលអ្នកចុចចេញពីវា ហើយទទួលបាន
   ✓ ពណ៌បៃតង។ រហូតដល់វាលទាំងបីត្រូវបានបំពេញ **[en:tran:Sign In]** នៅតែពណ៌ប្រផេះ — ការដាក់កណ្ដុរលើវា
   ប្រាប់អ្នកពីអ្វីដែលខ្វះ។
3. ចុច **[en:tran:Sign In]**។ បង្អួច CCLI មួយបើកឡើង ដើម្បីឲ្យអ្នកចូលគណនី និងយល់ព្រម។ ប្រសិនបើអ្នកបិទ
   វាជំនួសវិញ កម្មវិធីនិយាយថា **ការចូលគណនីបរាជ័យ — [en:tran:Sign in was canceled]** ហើយគ្មានអ្វីផ្លាស់ប្ដូរទេ។ នៅពេលចូលគណនីរួច កាតបង្ហាញ
   **[en:tran:Signed in]** ពណ៌បៃតង ជាមួយប៊ូតុង **[en:tran:Sign Out]** ហើយ
   កម្មវិធីរក្សាវគ្គឲ្យថ្មីជានិច្ច ដោយខ្លួនឯង។
4. ត្រឡប់មកទំព័រ ធ្វើបទបង្ហាញ វិញ សូមបើក **⋮ [en:tran:More Options]** របស់បញ្ជី **[en:tran:Documents]**។ ជម្រើសថ្មីមួយ
   **[en:tran:Import From SongSelect]** ឥឡូវស្ថិតនៅក្រោម
   **[en:tran:Import From Public Domain Songs]** — វាមាននៅទីនោះ តែពេលអ្នកបានចូលគណនីប៉ុណ្ណោះ។ 📸
5. ចុចវា។ ផ្ទាំងអណ្ដែត **[en:tran:Import From SongSelect]** មួយបើកឡើង (អូសវាទៅកន្លែងណាក៏បាន
   កម្មវិធីចងចាំកន្លែងដែលអ្នកដាក់វា)។ វាយក្នុង **[en:tran:Search songs]** — លទ្ធផល
   លេចឡើង នៅពេលអ្នកឈប់វាយមួយភ្លែត ជាមួយអ្នកនិពន្ធ លេខចម្រៀង CCLI បន្ទាត់មួយនៃទំនុកច្រៀង
   និងស្លាក **[en:tran:Public Domain]** នៅកន្លែងដែលពាក់ព័ន្ធ។ ប្ដូរទំព័រ
   បញ្ជីលទ្ធផលវែងៗ ដោយសញ្ញាព្រួញ ‹ › នៅខាងក្រោម។ ចម្រៀងដែលគណនីរបស់អ្នក មិនមាន
   អាជ្ញាប័ណ្ណយក មានប៊ូតុងទាញយកពណ៌ប្រផេះ។ 📸
6. ចុចប៊ូតុងទាញយក ☁⬇ របស់ចម្រៀងមួយ។ មួយភ្លែតក្រោយមក កម្មវិធីបញ្ជាក់
   **[en:tran:Lyric document created successfully]** ហើយចម្រៀងលេចឡើង
   ក្នុងបញ្ជី **[en:tran:Documents]** របស់អ្នក ជាទំនុកច្រៀង (♪) ដែលមានឈ្មោះតាមចំណងជើងរបស់វា។ ផ្ទាំងនៅតែ
   បើក ដូច្នេះអ្នកអាចបន្តទាញយក។ ការទាញយកចម្រៀងដដែលពីរដង រក្សាទាំងពីរ —
   ចម្រៀងទីពីរ ក្លាយជា `<Title> (1)`។ 📸
7. ចុចជួរថ្មី: វាបង្ហាញមើលជាមុន ស្លាយម្តងមួយៗ — ស្លាយ **Info** ដែលមានចំណងជើង
   អ្នកនិពន្ធ និងបន្ទាត់រក្សាសិទ្ធិ `CCLI Song #` បន្ទាប់មកស្លាយមួយ សម្រាប់ផ្នែកនីមួយៗ (**Verse 1**,
   **Chorus**, …)។ បង្ហាញវាដូចទំនុកច្រៀងផ្សេងទៀត (W-04) ឬកែពាក្យក្នុង
   កម្មវិធីកែសម្រួលទំនុកច្រៀង ជាមុនសិន។ 📸

> **ប្រសិនបើ SongSelect មិនភ្ជាប់ទេ សូមពិនិត្យមើលរឿងទាំងនេះ។** **[en:tran:Sign In]** ដែលប្រផេះ មានន័យថាប្រអប់មួយក្នុងចំណោមប្រអប់ទាំងបី
> — Client ID, Subscription Key, Redirect URI — នៅទទេ៖ ដាក់កណ្ដុរលើវា ហើយវាប្រាប់ថាមួយណា។
> ការស្វែងរក ឬការទាញយកដែលបរាជ័យ ប្រាប់មូលហេតុ នៅក្នុងផ្ទាំងផ្ទាល់ ឬជាសារលេចឡើង (toast)៖
