# W-49b — បញ្ជាស្លាយពីរីម៉ូត (យកគ្រាប់ចុចមកវិញ ដោយមិនបាច់ចុចកណ្ដុរ)

**គោលដៅ:** បន្តទៅស្លាយបន្ទាប់ពីរីម៉ូត ឬពីក្ដារចុច ពេលអ្នកមិនអាចដើរត្រឡប់ទៅកុំព្យូទ័រ ដើម្បីចុចលើផ្ទាំងណាមួយបាន។

1. **Space**, **→**, **↓** និង **Page Down** — គ្រាប់ចុចដែលរីម៉ូតផ្ញើ សម្រាប់ _បន្ទាប់_ — ធ្វើឲ្យផ្ទាំងមួយផ្លាស់ទីបាន តែពេលផ្ទាំងនោះកំពុងទទួលគ្រាប់ចុចប៉ុណ្ណោះ៖ ផ្ទាំងមើលជាមុនរបស់តារាងកម្មវិធី (W-22b) ស្លាយនៅកណ្ដាលទំព័រធ្វើបទបង្ហាញ (W-03) ផ្ទាំងអណ្ដែត **[en:tran:Slides]** ដែលមើលឯកសារផ្សេងទៀតជាមុន ឬផ្នែកដែលភ្លឺនៃ **[en:tran:Long Text Show]** (W-53)។ ចុចតែម្ដងនៅកន្លែងផ្សេង — ឯកសារមួយក្នុងបញ្ជី ប៊ូតុងមួយនៅក្រោមអេក្រង់ — ហើយគ្រាប់ចុចនឹងទៅកាន់អ្វីដែលអ្នកបានចុច ដូច្នេះរីម៉ូតហាក់ដូចជាលែងដំណើរការ។
2. **ចុចគ្រាប់ចុចនោះបីដងយ៉ាងលឿន** — ក្នុងរយៈពេលមួយវិនាទីកន្លះ។ គ្រាប់ចុចនឹងត្រឡប់ទៅកាន់អ្វីដែលកំពុងបង្ហាញ។ ការចុចលើកទីបីនោះ គ្រាន់តែប្រគល់គ្រាប់ចុចប៉ុណ្ណោះ៖ គ្មានអ្វីប្រែប្រួលនៅលើអេក្រង់ទេ។ ការចុចលើក **បន្ទាប់** ទើបផ្លាស់ទីទៅមុខ។ បើគ្មានអ្វីកើតឡើង សូមពិនិត្យថាតើរបារអូសមានការផ្ដោត ឬទស្សន៍ទ្រនិចនៅក្នុងប្រអប់ **[en:tran:Bible Lookup]** ដែលកំពុងបើកឬអត់៖ ការចុចបីដងទុកប៊ូតុងបញ្ជាទាំងនោះនៅដដែល។ សូមពិនិត្យផងដែរថា ផ្ទាំងមួយក្នុងចំណោមផ្ទាំងទាំងបួនខាងក្រោម មានអ្វីមួយកំពុងបង្ហាញ។
3. **ផ្ទាំងណាដែលទទួលគ្រាប់ចុច** — ផ្ទាំងដំបូងក្នុងចំណោមផ្ទាំងខាងក្រោម ដែលមានអ្វីមួយកំពុងដំណើរការ៖
   - ផ្ទាំងមើលជាមុនរបស់តារាងកម្មវិធី ដែលការដំណើរការរបស់វាបានចាប់ផ្តើម (បន្ទាត់មួយរបស់វាមានគែមព័ទ្ធជុំវិញ)។
   - ស្លាយនៅកណ្ដាលទំព័រធ្វើបទបង្ហាញ ពេលស្លាយមួយនៃឯកសារនោះកំពុងនៅលើអេក្រង់។
   - ផ្ទាំងអណ្ដែត **[en:tran:Slides]** ពេលស្លាយមួយរបស់វាកំពុងនៅលើអេក្រង់។
   - **[en:tran:Long Text Show]** ដែលអត្ថបទរបស់វាកំពុងនៅលើអេក្រង់ ដោយមានផ្នែកមួយរបស់វាភ្លឺ៖ គ្រាប់ចុចទៅកាន់ប៊ូតុងរបស់ផ្នែកនោះ នៅលើកាតខាងលើគេ។

   ដូច្នេះ ពេលតារាងកម្មវិធីបានចាប់ផ្តើម ហើយមានចម្រៀងនៅលើអេក្រង់ផងដែរ គឺតារាងកម្មវិធីដែលទទួលគ្រាប់ចុច។ ពេលគ្មានផ្ទាំងណាមួយក្នុងចំណោមទាំងបួននេះ មានអ្វីកំពុងដំណើរការ ការចុចបីដងមិនផ្លាស់ប្តូរអ្វីទេ — គ្មានអ្វីដែលគ្រាប់ចុចអាចផ្លាស់ទីបានឡើយ — ដូច្នេះសូមចុចលើអ្វីដែលអ្នកចង់បង្ហាញជាមុនសិន។
4. **គ្មានអ្វីសោះដែលទទួលគ្រាប់ចុច** — ឧទាហរណ៍ អ្នកបានបិទផ្ទាំងដែលអ្នកកំពុងប្រើ៖ មិនចាំបាច់ចុចបីដងទេ។ ការចុចលើកទីមួយ ទៅកាន់ផ្ទាំងដដែល តាមលំដាប់ដដែល ហើយផ្លាស់ទីវាទៅមុខ។
5. **អ្វីដែលការចុចបីដងមិនដែលដកយកគ្រាប់ចុចពីវា:** របារអូស (slider) ឬ **[en:tran:Bible Lookup]** ដែលកំពុងបើក ហើយមានទស្សន៍ទ្រនិចនៅក្នុងប្រអប់របស់វា — នៅទីនោះ គ្រាប់ចុចនៅតែធ្វើអ្វីដែលវាធ្លាប់ធ្វើ។ ហើយផ្ទាំងដែលកំពុងផ្លាស់ទីរួចហើយ ត្រូវបានទុកដដែល មិនថាអ្នកចុចលឿនប៉ុណ្ណាក៏ដោយ៖ ការចុចឆ្លងកាត់ចម្រៀងមួយយ៉ាងលឿន មិនដែលធ្វើឲ្យអ្នកលោតទៅតារាងកម្មវិធីទេ។
