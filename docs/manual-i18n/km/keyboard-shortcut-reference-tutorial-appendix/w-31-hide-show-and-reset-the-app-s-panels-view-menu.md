# W-31 — លាក់ បង្ហាញ និងកំណត់ផ្ទាំងរបស់កម្មវិធីឡើងវិញ (ម៉ឺនុយ View)

**គោលដៅ:** យកផ្ទាំងមួយមកវិញ បន្ទាប់ពីវាបានបង្រួម លាក់ផ្ទាំងដែលអ្នកមិនត្រូវការ ឬដាក់ប្លង់ទាំងមូល ត្រឡប់ទៅដូចពេលដំឡើងដំបូងវិញ។

ផ្ទាំងនីមួយៗដែលអាចប្តូរទំហំបាននៅក្នុងកម្មវិធី គឺជា **widget** មួយ។ អ្នកអាចបង្រួមផ្ទាំងមួយបានរួចហើយ ដោយអូសបន្ទាត់ខណ្ឌរបស់វា រហូតដល់គែម — វារួញទៅជាឆ្នូតពណ៌បៃតងស្ដើងមួយ ដែលមានឈ្មោះរបស់វានៅលើ ហើយការចុចលើឆ្នូតនោះ នាំវាមកវិញ។ ម៉ឺនុយ **View** នៅលើរបារម៉ឺនុយខាងលើ ធ្វើរឿងដដែលនេះតាមឈ្មោះ ដែលងាយស្រួលជាង ពេលរកឆ្នូតនោះពិបាក។ ហើយបន្ទាត់ខណ្ឌខ្លួនឯង មានម៉ឺនុយចុចកណ្ដុរស្ដាំ ដែលធ្វើរឿងនេះនៅនឹងកន្លែង (ជំហាន 7–9) — ជាវិធីតែមួយគត់ នៅក្នុងបង្អួចលេចឡើង (popup) ដែលរបារម៉ឺនុយរបស់វាត្រូវបានលាក់។

1. បើក **View** នៅលើរបារម៉ឺនុយខាងលើ → **[en:tran:Widgets]**។ 📸
   អ្នកនឹងឃើញប្រអប់ធីកមួយ សម្រាប់ផ្ទាំងនីមួយៗ នៅលើទំព័រដែលអ្នកកំពុងមើល ឧទាហរណ៍ នៅលើទំព័រធ្វើបទបង្ហាញ៖ **[en:tran:App Presenter Left]** / **[en:tran:App Presenter Middle]** / **[en:tran:App Presenter Right]**, **[en:tran:Document List]**, **[en:tran:Presenting Flow List]**, **[en:tran:Presenter]**, **[en:tran:Background]**, **[en:tran:Bible and Notes]**, **[en:tran:Mini Screen]**, **[en:tran:Bibles]**, **[en:tran:Bible Notes]**, **[en:tran:Previewer]**, **[en:tran:Slides]**, **[en:tran:Note]**។
   នៅក្នុងទំព័រអានព្រះគម្ពីរ ផ្នែកផ្ដេកទាំងបីគឺ **[en:tran:Bible and Notes]**, **[en:tran:Bible Lookup]** និង **[en:tran:Advance Lookup]**។ ប៊ូតុងកែវយឹត **[en:tran:Advance Bible Lookup]** នៅជ្រុងខាងលើខាងស្ដាំ បើក ឬបិទផ្នែកស្វែងរកកម្រិតខ្ពស់ដដែលនោះ។
   - **បានធីក** = ផ្ទាំងបើក។ **មិនបានធីក** = វាត្រូវបានបង្រួមទៅជាឆ្នូតរបស់វា។
   - **[en:tran:Note]** — កំណត់ត្រារបស់ឯកសារ និងស្លាយ នៅក្រោមការមើលស្លាយជាមុន (W-03) — គឺជាផ្ទាំងតែមួយគត់ដែល **ចាប់ផ្តើមដោយមិនបានធីក**៖ វាមកដោយបង្រួមជាឆ្នូតពណ៌បៃតងរបស់វា ព្រោះកម្មវិធីថ្វាយបង្គំភាគច្រើន មិនដែលត្រូវការវាទេ។ ធីកវា ឬចុចលើឆ្នូតនោះ ដើម្បីបើកវា។
2. ចុចលើផ្ទាំងដែលបានធីកមួយ — ផ្ទាំងនោះបង្រួមទៅជាឆ្នូតពណ៌បៃតងរបស់វា ហើយកន្លែងរបស់វាទៅឲ្យផ្ទាំងជិតខាង។ 📸
3. ចុចវាម្ដងទៀត — ផ្ទាំងនោះត្រឡប់មកវិញភ្លាម។ គ្មានអ្វីផ្ទុកឡើងវិញទេ ហើយគ្មានអ្វីដែលអ្នកកំពុងធ្វើ ត្រូវបានរំខានឡើយ។
4. ផ្ទាំងដែលកម្មវិធីមិនអនុញ្ញាតឲ្យអ្នកបង្រួម (ផ្នែកបំបែកមេឌៀ/សំឡេងនៃផ្ទៃខាងក្រោយ កម្មវិធីមើលព្រះគម្ពីរជាមុន និង Stage Previewer របស់ទំនុកចម្រៀង) គ្រាន់តែមិនមាននៅក្នុងបញ្ជីប៉ុណ្ណោះ។

**ដាក់អ្វីៗទាំងអស់ត្រឡប់ដូចដើមវិញ:**

5. បើក **View** នៅលើរបារម៉ឺនុយខាងលើម្ដងទៀត ហើយចុច **[en:tran:Reset Widgets Size]**។ កុំបើក **Widgets** សម្រាប់រឿងនេះ៖ **[en:tran:Reset Widgets Size]** គឺជាជួរមួយនៃម៉ឺនុយ **View** ផ្ទាល់ ជាជួរនៅខាងក្រោម **Widgets** ភ្លាម។ ឆ្លើយ **[en:tran:Yes]** ចំពោះសំណួរ “[en:tran:Are you sure to reset every widget size and reopen the widgets?]” 📸
6. ផ្ទាំងនីមួយៗត្រឡប់ទៅទទឹង និងកម្ពស់ដែលវាមាន ពេលកម្មវិធីត្រូវបានដំឡើង ហើយ **ផ្ទាំងណាដែលអ្នកបានបង្រួម នឹងត្រូវបានបើកឡើងវិញ**។ រឿងនេះកើតឡើងភ្លាមៗ — មិនចាំបាច់ផ្ទុកឡើងវិញទេ។ ឆ្លើយ **[en:tran:No]** ហើយគ្មានអ្វីផ្លាស់ប្តូរទេ។

**ឬប្រើបន្ទាត់ខណ្ឌរវាងផ្ទាំងពីរ** — មិនចាំបាច់ប្រើរបារម៉ឺនុយទេ ដូច្នេះវិធីនេះក៏ដំណើរការនៅក្នុងបង្អួចលេចឡើងដែរ៖

7. ចុចកណ្ដុរស្ដាំលើ **បន្ទាត់ខណ្ឌរវាង Document List (បញ្ជីឯកសារ) និង Presenting Flow List (បញ្ជីតារាងកម្មវិធី)** — បន្ទាត់ស្ដើងរវាងផ្ទាំងទាំងពីរ នៅខាងឆ្វេងនៃទំព័រធ្វើបទបង្ហាញ (គ្រប់បន្ទាត់ខណ្ឌក្នុងកម្មវិធី មានម៉ឺនុយនេះ) — ហើយជ្រើស **[en:tran:Close First Widget]**។ 📸 ផ្ទាំងទីមួយក្នុងចំណោមផ្ទាំងទាំងពីរ (ផ្ទាំងខាងឆ្វេង ឬផ្ទាំងខាងលើ) បង្រួមទៅជាឆ្នូតពណ៌បៃតងរបស់វា ហើយផ្ទាំងម្ខាងទៀតយកកន្លែងរបស់វា។ **[en:tran:Close Second Widget]** ធ្វើដូចគ្នាចំពោះផ្ទាំងម្ខាងទៀត។ ម៉ឺនុយនោះមានតែជម្រើសទាំងពីរនោះ និង **[en:tran:Reset Size]** (ជំហានទី 9) ប៉ុណ្ណោះ។ ការដាក់កណ្ដុរលើបន្ទាត់ខណ្ឌ បង្ហាញជម្រើសពីរដដែលនេះ ជាព្រួញតូចៗ ដែលនីមួយៗមានឈ្មោះតាមចំហៀងដែលវាបិទ — **[en:tran:Collapse left panel]** / **[en:tran:Collapse right panel]** ឬ **[en:tran:Collapse top panel]** / **[en:tran:Collapse bottom panel]** នៅលើបន្ទាត់ខណ្ឌរវាងផ្ទាំងខាងលើ និងផ្ទាំងខាងក្រោម។ ផ្ទាំងដែលបានបង្រួម គ្មានបន្ទាត់ខណ្ឌទេ — ប្រសិនបើផ្ទាំងមួយក្នុងចំណោមពីរនោះ ជាឆ្នូតរួចហើយ សូមចុចលើឆ្នូតនោះជាមុនសិន។
8. ចុចលើឆ្នូតពណ៌បៃតង **[en:tran:Document List]** — ផ្ទាំងនោះត្រឡប់មកវិញភ្លាម។
9. ចុចកណ្ដុរស្ដាំលើ **បន្ទាត់ខណ្ឌរវាង Document List និង Presenting Flow List** ម្ដងទៀត ហើយជ្រើស **[en:tran:Reset Size]** — មានតែផ្ទាំងទាំងពីរនោះប៉ុណ្ណោះ ដែលត្រឡប់ទៅទំហំដើមរបស់វា។ ការចុចពីរដងលើបន្ទាត់ខណ្ឌ ក៏ធ្វើដូចគ្នាដែរ។ **[en:tran:Reset Widgets Size]** របស់ម៉ឺនុយ View (ជំហាន 5) គឺសម្រាប់គ្រប់ផ្ទាំងក្នុងពេលតែមួយ។

**ជាមួយក្ដារចុច:** ចុច **Tab** រហូតដល់បន្ទាត់ខណ្ឌមួយ បង្ហាញគែមពណ៌ខៀវ។ គ្រាប់ចុច **Menu** (ឬ **Shift+F10**) បើកម៉ឺនុយដដែលនឹងការចុចកណ្ដុរស្ដាំ ហើយគ្រាប់ចុចព្រួញផ្លាស់ទីបន្ទាត់ខណ្ឌ — **←/→** សម្រាប់បន្ទាត់ខណ្ឌរវាងផ្ទាំងដែលនៅក្បែរគ្នា **↑/↓** សម្រាប់បន្ទាត់ខណ្ឌរវាងផ្ទាំងខាងលើ និងផ្ទាំងខាងក្រោម ហើយ **Shift** សម្រាប់ជំហានធំជាង។ គ្រាប់ចុចព្រួញមិនដែលបង្រួមផ្ទាំងទេ។ ម៉ឺនុយទេ ដែលធ្វើរឿងនោះ។

> ពីមុន នេះជាប៊ូតុងមួយនៅក្នុង ការកំណត់ → ទូទៅ ដែលវាមិនធ្វើអ្វីទាល់តែសោះ រហូតដល់អ្នកចុច **អនុវត្តការកំណត់** ផងដែរ ហើយកម្មវិធីផ្ទុកឡើងវិញ។
> ឥឡូវនេះ វានៅលើម៉ឺនុយ View ហើយមានប្រសិទ្ធភាពភ្លាមៗ។
