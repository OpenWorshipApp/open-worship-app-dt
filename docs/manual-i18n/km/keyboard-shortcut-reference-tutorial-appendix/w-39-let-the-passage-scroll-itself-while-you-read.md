# W-39 — ឱ្យបទគម្ពីររំកិលដោយខ្លួនឯង ខណៈពេលអ្នកអាន

ពេលជំពូកមួយវែងជាងផ្ទាំង អ្នកមិនចាំបាច់បង្វិលកង់កណ្ដុររហូតនោះទេ
— កម្មវិធីអាចរំកិលវាឱ្យអ្នក តាមល្បឿនណាក៏ដោយដែលអ្នកកំណត់។

1. បើកបទគម្ពីរមួយដែលវែងល្មមអាចរំកិលបាន នៅក្នុងផ្ទាំងព្រះគម្ពីរ នៅលើការមើលអេក្រង់ជាមុន ឬនៅក្នុងផ្ទាំងអណ្តែតតូចដែលបទគម្ពីរបើកនៅក្នុងនោះ (ចុចកណ្ដុរស្ដាំលើបទគម្ពីរ → **[en:tran:Floating]** ឬចុចលើឯកសារយោងឆ្លង)។
   នៅជ្រុងខាងស្ដាំខាងក្រោមនៃអត្ថបទ មានប៊ូតុងព្រាលៗពីរ នៅពីលើគ្នា៖
   ព្រួញឡើងលើ (**[en:tran:Scroll to the top]** ដែលបង្ហាញតែពេលអត្ថបទបានរំកិល
   ចុះហើយប៉ុណ្ណោះ) និងសញ្ញាព្រួញទ្វេ (double chevron) នៅខាងក្រោមវា។
   សញ្ញាព្រួញទ្វេនោះ គឺជាប៊ូតុងរំកិលដោយស្វ័យប្រវត្តិ។ 📸
2. ចុចសញ្ញាព្រួញទ្វេម្ដង។ អត្ថបទចាប់ផ្ដើមរំកិលចុះយឺតៗ។ ចុចវាម្ដងទៀត នោះ
   វាទៅលឿនជាងមុន។ ការចុចម្ដងៗ បន្ថែមល្បឿនបន្តិចទៀត។
   វារំកិលក្នុងល្បឿនស្មើៗ នៅលើកុំព្យូទ័រណាក៏ដោយ ហើយល្បឿននោះទៅតាមទំហំអក្សរ៖ ធ្វើឱ្យ
   អក្សរធំជាងមុន នោះវារំកិលបានឆ្ងាយជាងមុនក្នុងមួយវិនាទី ដូច្នេះអ្នកនៅតែអានបានចំនួន
   បន្ទាត់ដដែលក្នុងមួយនាទី។ រំកិលវាដោយខ្លួនឯង ខណៈពេលវាកំពុងដំណើរការ — ថយក្រោយដើម្បីអានឡើងវិញ ឬទៅមុខ —
   នោះវាបន្តពីកន្លែងដែលអ្នកទុកវា។
3. ភ្លាមៗពេលវាកំពុងរំកិល **⋯** មួយលេចឡើងនៅខាងឆ្វេងវា។ ចុចវា។ 📸
   ម៉ឺនុយតូចមួយបើកឡើង ដោយរាយបញ្ជីអ្វីៗទាំងអស់ដែលប៊ូតុងនេះអាចធ្វើបាន ជាមួយសកម្មភាពកណ្ដុរសម្រាប់
   នីមួយៗ សរសេរនៅក្បែរវា៖
   - **[en:tran:Auto Scroll Speed]** — ល្បឿនដែលវាកំពុងទៅឥឡូវនេះ។
   - **[en:tran:Speed Up]** — ដូចគ្នានឹងការចុចសញ្ញាព្រួញទ្វេ។
   - **[en:tran:Speed Up Faster]** — លោតល្បឿនធំជាង ដូចគ្នានឹងការចុចពីរដងលើវា។
   - **[en:tran:Slow Down]** — ដូចគ្នានឹងការចុចកណ្ដុរស្ដាំលើវា។
   - **[en:tran:Stop Auto Scrolling]** — ដូចគ្នានឹង Alt + ចុចកណ្ដុរស្ដាំ។
4. ជ្រើសរើស **[en:tran:Slow Down]** ម្ដង បើកម៉ឺនុយម្ដងទៀត ហើយមើលថាលេខល្បឿនបាន
   ធ្លាក់ចុះ — ក្រោយការចុចពីរដងនៃជំហានទី 2 ការជ្រើស **[en:tran:Slow Down]** លើកទីពីរ នឹងធ្វើឱ្យវាដល់
   សូន្យ ដែលបញ្ឈប់ការរំកិលដោយខ្លួនឯង។ ជ្រើសរើស **[en:tran:Stop Auto Scrolling]** ដើម្បីបញ្ចប់វា — អត្ថបទឈប់ ហើយ **⋯**
   បាត់ទៅ ព្រោះលែងមានអ្វីត្រូវគ្រប់គ្រងទៀតហើយ។ 📸
   > **⋯** មានតែនៅពេលបទគម្ពីរកំពុងរំកិលពិតប្រាកដប៉ុណ្ណោះ។ ប្រសិនបើអ្នក
   > មើលមិនឃើញវា បទគម្ពីរមិនកំពុងរំកិលទេ — សូមចុចសញ្ញាព្រួញទ្វេជាមុនសិន។
   > អ្នកមិនចាំបាច់ប្រើម៉ឺនុយនោះទេ៖ សកម្មភាពកណ្ដុរទាំងបួនដែលវារាយ ដំណើរការដោយផ្ទាល់លើ
   > សញ្ញាព្រួញទ្វេ ហើយតែងតែដំណើរការដូច្នេះជានិច្ច។ ម៉ឺនុយនោះមាន ដើម្បីឱ្យអ្នករកវាឃើញ និង
   > ដើម្បីឱ្យវាដំណើរការលើអេក្រង់ប៉ះ ដែលគ្មានការចុចកណ្ដុរស្ដាំសោះ។
