# W-48 — ផ្ដល់ការផ្លាស់ប្តូរផ្ទាល់ខ្លួនដល់ស្លាយ ចម្រៀង ផ្ទៃខាងក្រោយ ឬផ្ទៃខាងមុខ

ស្លាយរបស់វា បន្ទាប់មកឯកសាររបស់វា បន្ទាប់មកអេក្រង់ នៅពេលជម្រើសផ្ទាល់ខ្លួនរបស់វាមិនត្រូវបានធីក។

1. **ចម្រៀង ឬឯកសារស្លាយទាំងមូល។** នៅក្នុងផ្ទាំងមើលស្លាយជាមុន ចុច ⋮ នៅ
   ជ្រុងខាងលើស្ដាំរបស់វា (សម្រាប់ចម្រៀង ⋮ នៅក្បាលនៃ អ្នកមើលជាមុនដំណាក់កាល ក៏ប្រើបានដែរ)

   _ការផ្លាស់ប្តូរ: រសាត់ (ការកំណត់អេក្រង់)_។ នៅក្នុងប្រអប់ដែលបើកឡើង ធីក

   គ្រប់អេក្រង់។ ប៊ូតុងមូលពណ៌ខៀវខ្ចី ដែលមានរូបតំណាងនៃបែបផែននោះ លេចឡើងនៅក្បែរ
   ⋮ ខាងលើស្ដាំនៃផ្ទាំងមើលជាមុន។ ព័ត៌មានជំនួយរបស់វាប្រាប់ឈ្មោះបែបផែននោះ។ ចុចវា ដើម្បីប្ដូរ
   ឬដោះធីកជម្រើសរបស់ឯកសារ។ វាបាត់ទៅវិញ នៅពេលឯកសារធ្វើតាម
   អេក្រង់

2. **ស្លាយមួយ។** ចុច ⋮ នៅលើកាតរបស់ស្លាយនោះ (ឬចុចកណ្ដុរស្ដាំលើវា) ហើយ
   ជ្រើស **[en:tran:Transition]** — វាសរសេរថា _ពង្រីក (ការមើលស្លាយជាមុន)_ ព្រោះ
