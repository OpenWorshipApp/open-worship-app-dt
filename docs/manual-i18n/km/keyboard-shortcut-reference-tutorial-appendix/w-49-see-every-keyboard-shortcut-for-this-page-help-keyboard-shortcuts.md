# W-49 — មើលផ្លូវកាត់ក្ដារចុចទាំងអស់សម្រាប់ទំព័រនេះ (ម៉ឺនុយ Help → ផ្លូវកាត់ក្ដារចុច)

**គោលដៅ:** រកគ្រាប់ចុចសម្រាប់ធ្វើអ្វីមួយ ដោយមិនបាច់ដើររកតាមស្លាកពន្យល់ដែលលេចឡើងពេលដាក់កណ្ដុរ ហើយរៀនគ្រាប់ចុចរបស់ទំព័រដែលអ្នកកំពុងនៅ។

1. នៅលើរបារម៉ឺនុយ បើក **Help → [en:tran:Keyboard Shortcuts]**។ វានៅខាងក្រោម **[en:tran:Tips of the Day]** និង **[en:tran:All tips]**។
2. ផ្ទាំងអណ្ដែតមួយនឹងបើកឡើង ដែលមានចំណងជើង **[en:tran:Keyboard Shortcuts] ·** និងឈ្មោះទំព័រដែលអ្នកកំពុងនៅ — **[en:tran:Presenter]**, **[en:tran:Bible Reader]** ឬ **[en:tran:Slide Editor]**។ ទ្រនិចវាយអក្សរនៅក្នុង **[en:tran:Search shortcuts]** រួចជាស្រេច។ ជួរនីមួយៗប្រាប់ថាគ្រាប់ចុចមួយធ្វើអ្វី នៅខាងឆ្វេង ហើយបង្ហាញគ្រាប់ចុចនោះនៅខាងស្ដាំ។ គ្រាប់ចុចដែលមានពីររបៀប បង្ហាញទាំងពីរ (**[en:tran:Redo]** គឺ `Ctrl+Shift+Z` និង `Ctrl+Y`)។ បន្ទាត់ពណ៌ប្រផេះនៅក្រោមចំណងជើង ឬក្រោមជួរមួយ ប្រាប់ថាពេលណាគ្រាប់ចុចនោះដំណើរការ — ឧទាហរណ៍ **[en:tran:While the slides panel has focus]**៖ ព្រួញស្លាយផ្លាស់ទីស្លាយ តែបន្ទាប់ពីអ្នកចុចចូលក្នុងផ្ទាំងស្លាយប៉ុណ្ណោះ — ឬបន្ទាប់ពីចុចបីដងលឿនៗ ដែលជាជួរ **[en:tran:Take the keys back to what is being presented]** (W-49b)។
3. ទំព័រនីមួយៗរាយគ្រាប់ចុចរបស់ខ្លួន។ ទំព័រធ្វើបទបង្ហាញចាប់ផ្ដើមដោយ **[en:tran:Screens]** (`F5` បង្ហាញ ឬលាក់អេក្រង់ដែលបានជ្រើស `F6`–`F10` លុបអ្វីៗលើអេក្រង់ទាំងនោះ `F4` សារ) បន្ទាប់មក **[en:tran:Slides]**, **[en:tran:Bible Lookup]**, **[en:tran:Presenting Flow]**, **[en:tran:Long Text Show]** និងគ្រាប់ចុច **[en:tran:Drawing]** និង **[en:tran:Focusing]** របស់អេក្រង់តូច។ ទំព័រអានព្រះគម្ពីររាយគ្រាប់ចុចស្វែងរក និងគ្រាប់ចុចបំបែក ហើយទំព័រកែសម្រួលស្លាយរាយគ្រាប់ចុចផ្ទាំងក្រណាត់។ ទំព័រនីមួយៗបញ្ចប់ដោយ **[en:tran:Every window]**, **[en:tran:Presenting Control]** និង **[en:tran:Dialogs and menus]**។ នៅលើ Mac គ្រាប់ចុចត្រូវបានបង្ហាញតាមរបៀប Mac (`⌘⇧ S`)។
4. វាយពាក្យ ឬគ្រាប់ចុចមួយ — `clear`, `split`, `f5` — ហើយបញ្ជីនឹងរួមតូចមកនៅតែជួរដែលត្រូវគ្នា។ លេខរាប់នៅក្បែរប្រអប់ បង្ហាញថាមានគ្រាប់ចុចប៉ុន្មានរបស់ទំព័រនេះដែលត្រូវគ្នា។ **[en:tran:No shortcuts found]** មានន័យថាគ្មានអ្វីត្រូវគ្នាទេ។
5. **Esc** ក្នុងប្រអប់ ធ្វើឱ្យវាទទេ។ **Esc** លើកទីពីរ បិទផ្ទាំង ហើយ **✕** របស់វាក៏បិទដែរ។ អូសរបារចំណងជើង ដើម្បីផ្លាស់ទីផ្ទាំង អូសគែមវា ដើម្បីប្ដូរទំហំ ហើយប្រើសញ្ញាព្រួញ ដើម្បីរមូរវាឡើងឱ្យនៅត្រឹមចំណងជើង។ វានឹងបើកម្ដងទៀត នៅកន្លែងដែលអ្នកបានទុកវា។
6. ផ្ទាំងនេះមិនដកក្ដារចុចចេញពីកម្មវិធីទេ៖ ពេលវាបើក គ្រាប់ចុចទាំងអស់ដែលវារាយ នៅតែដំណើរការ ដូច្នេះអ្នកអាចអានគ្រាប់ចុចមួយ ហើយសាកល្បងវាបាន។ មានតែការវាយក្នុងប្រអប់ស្វែងរករបស់វាប៉ុណ្ណោះ ដែលនៅក្នុងប្រអប់ — Enter, Tab និងព្រួញនៅទីនោះ មិនទៅដល់ទំព័រនៅពីក្រោយវាទេ ខណៈដែលគ្រាប់ចុចមុខងារដូចជា `F5` ឬគ្រាប់ចុច `Ctrl` នៅតែទៅដល់។
7. **ពេលផ្ទាំងស្វែងរកព្រះគម្ពីរកំពុងបើក។** នៅក្នុងទំព័រធ្វើបទបង្ហាញ ឬកែសម្រួលស្លាយ បើក **[en:tran:Bible Lookup]** (`Ctrl+B`) ហើយបន្ទាប់មក **Help → [en:tran:Keyboard Shortcuts]** — ឬបើកការស្វែងរក ពេលផ្ទាំងនេះកំពុងបើករួចហើយ។ ផ្ទាំងនេះនៅពីលើផ្ទាំងលេចឡើងនៃការស្វែងរក ចំណងជើងរបស់វាប្ដូរទៅជា **[en:tran:Keyboard Shortcuts] · [en:tran:Bible Lookup]** ហើយវារាយតែគ្រាប់ចុចដែលដំណើរការក្នុងការស្វែងរកប៉ុណ្ណោះ៖ ការវាយយោងខគម្ពីរ ការបំពេញវា ការបំបែក ការរក្សាទុក **[en:tran:Close the Bible Lookup popup]** (`Ctrl+Q`) និងគ្រាប់ចុចប្រអប់សន្ទនា។ គ្រាប់ចុចរបស់ទំព័រផ្ទាល់ (`F5`–`F10` និងព្រួញស្លាយ) មិនធ្វើអ្វីទេ ពេលការស្វែងរកកំពុងបើក ដូច្នេះវាមិនត្រូវបានរាយទេ។ បិទការស្វែងរក ហើយផ្ទាំងនឹងត្រឡប់ទៅបញ្ជីរបស់ទំព័រវិញ។
