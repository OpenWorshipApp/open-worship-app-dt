    **ទំព័រអត្ថបទនៃសៀវភៅទំនុកតម្កើង ក៏ដំណើរការដែរ។** ទំព័របែបនេះគ្មានអាកូដសោះ៖ ឃ្លាត្រូវបានបោះពុម្ពជាលេខ `1`, `2`, `3` នៅកណ្ដាលម៉ឺនុយរបស់គេហទំព័រ ហើយព័ត៌មានផ្ទាល់របស់ចម្រៀង នៅក្នុងតារាងមួយនៅខាងក្រោមឆ្ងាយ។ ឃ្លាដែលមានលេខ ត្រូវបានយកជាចម្រៀង ហើយគ្មានអ្វីផ្សេងទៀតទេ ហើយ **ចំណងជើង**, **អ្នកនិពន្ធ** និង **សិទ្ធិអ្នកនិពន្ធ** — _Public Domain_ សម្រាប់ទំនុកតម្កើង — ត្រូវបានអានពីតារាងនោះ ដោយរក្សាអាសយដ្ឋានរបស់ទំព័រជាមួយចម្រៀង ជាប្រភពរបស់វា។ 📸
    **ចម្រៀងដែលបោះពុម្ពជាពីរភាសា នៅតែជាពីរភាសា។** កន្លែងដែលទំព័របោះពុម្ពអត្ថន័យនៅក្រោមបន្ទាត់ដែលត្រូវច្រៀង ទាំងពីរត្រូវបានរក្សាជាគូ ដូច្នេះស្លាយអាចបង្ហាញទាំងពីរ។
    **បន្ទាត់សិទ្ធិអ្នកនិពន្ធនៅលើទំព័រ ត្រូវបានរក្សាទុកជាមួយចម្រៀង** នៅក្នុងវាល `Copyright` របស់វា ដូច្នេះអ្នកណាដែលបើកឯកសារនោះពេលក្រោយ អាចឃើញថាជាចម្រៀងរបស់អ្នកណា។ ទំព័រភាគច្រើនបោះពុម្ពវានៅខាងក្រោមបំផុត ឆ្ងាយពីពាក្យចម្រៀង ហើយវាត្រូវបានអានពីទីនោះ។ **អាសយដ្ឋានរបស់ទំព័រ ក៏ត្រូវបានរក្សាទុកដែរ** នៅក្នុង `Attachments` របស់ចម្រៀង ដូច្នេះអ្នកណាដែលបើកឯកសារនោះ អាចទៅមើលកន្លែងដែលពាក្យចម្រៀងមកពី។
    **អ្នកអាចអានចម្រៀងនោះ មុនពេលអ្នកបង្កើតវា។** អត្ថបទនៃឯកសារលេចឡើងក្នុងប្រអប់មួយនៅខាងលើប៊ូតុងទាំងពីរ ដូចដែលវានឹងត្រូវរក្សាទុកទាំងស្រុង ដូច្នេះគ្មានអ្វីត្រូវបានបង្កើតដោយលាក់កំបាំងទេ។ (ប្រសិនបើអ្នកបានបិទបង្អួចជំនួយ តាំងពីចម្រៀងនោះត្រូវបានព្រាង ប្រអប់នោះនឹងមិនមានទេ — សួរម្ដងទៀត ហើយវានឹងត្រឡប់មកវិញ។) ថាតើព្រះវិហាររបស់អ្នកអាចច្រៀងវាបានឬអត់ គឺជាអាជ្ញាប័ណ្ណ និងការសម្រេចចិត្តផ្ទាល់ខ្លួនរបស់អ្នក — កម្មវិធីមិនចម្លងអ្វីទៅកន្លែងណា ហើយមិនផ្ញើអ្វីទៅនរណាម្នាក់ទេ ហើយគ្មានឯកសារណាត្រូវបានសរសេរទេ រហូតដល់អ្នកចុច **[en:tran:Create]**។
    ដោយសារវាជាការទាយអំពីទំព័ររបស់អ្នកដទៃ ចម្លើយតែងតែប្រាប់ពី **ផ្នែកណានៃទំព័រដែលវាបានប្រើ** ដោយដកស្រង់បន្ទាត់ទីមួយ និងបន្ទាត់ចុងក្រោយដែលវាបានយក និងចំនួនបន្ទាត់ម៉ឺនុយ និងតំណដែលវាបានទុកចោល។ សូមអានបន្ទាត់នោះ។ ប្រសិនបើវាយកច្រើនពេក ឬឈប់លឿនពេក ប្រាប់ដូច្នេះជាពាក្យរបស់អ្នកផ្ទាល់ — _ចម្រៀងចាប់ផ្ដើមនៅ "…" ហើយបញ្ចប់នៅ "…"_ — ហើយសួរម្ដងទៀត។ អ្វីៗផ្សេងទៀត គឺដូចគ្នានឹងការបិទភ្ជាប់ពាក្យចម្រៀងដោយខ្លួនឯង៖ ប៊ូតុងពីរនៅខាងក្រោម ហើយគ្មានអ្វីត្រូវបានសរសេរទៅថាសទេ រហូតដល់អ្នកចុច **[en:tran:Create]**។
