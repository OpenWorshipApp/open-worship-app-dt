# W-22d — ធ្វើឲ្យតារាងកម្មវិធីរង់ចាំ រួចបន្តទៅមុខដោយខ្លួនឯង (Next: Timeout)

**គោលដៅ:** ស្លាយដែលនៅយូរបន្តិច រួចបន្តទៅមុខដោយមិនចាំបាច់មានអ្នក ឬក្ដារជូនដំណឹង ដែលបញ្ចប់ត្រង់ពេល ដែលកម្មវិធីថ្វាយបង្គំចាប់ផ្តើម។

1. **ទុកឲ្យតារាងកម្មវិធីដើរដោយខ្លួនឯង។** នៅក្នុងបញ្ជី **[en:tran:Presenting Flows]** (មិនមែននៅក្នុងផ្ទាំងមើលជាមុនទេ) ចុចកណ្ដុរស្ដាំលើ **តារាងកម្មវិធីខ្លួនឯង** — ជួរដែលមានឈ្មោះរបស់វានៅលើ មិនមែនកន្លែងទំនេរនៃបញ្ជី ហើយក៏មិនមែនបន្ទាត់មួយរបស់វាដែរ — ហើយជ្រើស **[en:tran:Add Action]** → **[en:tran:Next: Timeout]**។ រឿងនោះបន្ថែមបន្ទាត់ **ថ្មី** មួយទៅក្នុងតារាងកម្មវិធី។ វាមិនដែលត្រូវបានបន្ថែម ដោយការចុចកណ្ដុរស្ដាំលើបន្ទាត់ដែលមានរួចហើយនោះទេ។ វាទៅនៅ **ចុងបញ្ចប់** នៃតារាងកម្មវិធី៖ អូសវាឡើងទៅដាក់ភ្លាមនៅក្រោយបន្ទាត់ដែលវាគួរតាម។ វាសួររកចំនួន **[en:tran:Seconds]** ហើយចម្លើយនោះក្លាយជាផ្នែកមួយនៃបន្ទាត់ថ្មី — **⏱ [en:tran:Next: Timeout] (5)** — ដូច្នេះការមើលមួយភ្លែតលើតារាង ប្រាប់អ្នកថាវារង់ចាំយូរប៉ុណ្ណា។ ដាក់ខុសឬ? ចុចកណ្ដុរស្ដាំលើបន្ទាត់ **[en:tran:Next: Timeout]** នោះ → **[en:tran:Change Timing]**។ វាបើកឡើង ដោយបង្ហាញតម្លៃដែលវាកំពុងកាន់ឥឡូវនេះ។ 📸
2. **[en:tran:Next: Timeout]** រង់ចាំតែម្ដង។ ពេលការដំណើរការមកដល់វា វារាប់ថយក្រោយ ហើយបន្ទាប់មក បន្តការដំណើរការទៅមុខដោយខ្លួនឯង — ស្លាយដែលគួរនៅដប់វិនាទី ហើយបន្តទៅមុខ ដោយមិនចាំបាច់មានអ្នក។ **ការទៅកន្លែងផ្សេងដោយខ្លួនឯង នឹងបោះបង់វា**៖ ចុចបន្ទាត់ផ្សេងនៅក្នុងផ្ទាំងមើលជាមុន ឬចុចគ្រាប់ចុចបន្ទាប់ នោះការរង់ចាំត្រូវបានបញ្ចប់ ហើយអ្នកជាអ្នកបញ្ជាម្ដងទៀត។ ការចុចដែលមិននាំទៅណា **មិន** បោះបង់វាទេ៖ ការចុចផ្ទៃខាងក្រោយ ឬប៊ូតុងផ្ទៃខាងមុខ នៅក្នុងផ្ទាំងផ្ទាល់របស់វា ឬការចុចច្រឡំលើផ្ទាំង ទុកឲ្យវាបន្តរាប់ ដូច្នេះការចុចខុសគោលដៅ មិនអាចធ្វើឲ្យអ្នកបាត់ការរង់ចាំ ដោយស្ងាត់ៗបានទេ។
3. **ឬរង់ចាំដល់ម៉ោងណាមួយលើនាឡិកា។** ការរង់ចាំមិនចាំបាច់រាប់ជាវិនាទីទេ។ ប្រអប់តូចដែលសួររកវិនាទី — វាបើកពេលអ្នកបន្ថែមបន្ទាត់ (ជំហាន 1 រួចអូសបន្ទាត់ថ្មីនោះឡើងលើ ទៅបន្ទាប់ពីបន្ទាត់ដែលវាគួរតាម) ហើយម្ដងទៀត ពីការចុចកណ្ដុរស្ដាំ → **[en:tran:Change Timing]** លើបន្ទាត់នោះ — មានកន្លែងជ្រើសមួយនៅខាងឆ្វេងរបស់វា៖ ប្តូរវាពី **[en:tran:Seconds]** ទៅ **[en:tran:At Time]** ហើយវាយម៉ោងដែលអ្នកចង់ឲ្យការដំណើរការបន្តទៅមុខ — `7:05 AM`, `8:30 PM`។ បន្ទាប់មក បន្ទាត់នោះសរសេរថា **⏱ [en:tran:Next: Timeout] (7:05 AM)** ហើយស្លាកតូច (pill) រាប់ថយក្រោយជានាទី និងម៉ោង (`4:58`, `1:12:30`) ជំនួសឲ្យចំនួនវិនាទីដ៏វែង។ ប្រើវាសម្រាប់ក្ដារជូនដំណឹង មុនកម្មវិធីថ្វាយបង្គំ៖ ដាក់វានៅលើការប្រកាសចុងក្រោយ ហើយការដំណើរការនឹងចាកចេញពីវា ត្រង់ពេលកម្មវិធីចាប់ផ្តើម មិនថាអ្នកបានកំណត់វាមុនមួយម៉ោង ឬប្រាំនាទីក៏ដោយ។ ធាតុម៉ឺនុយរបស់វាគឺ **[en:tran:Change Timing]** ជាជាង **[en:tran:Change Seconds]** ហើយវាបើកដោយបង្ហាញផ្នែកណាមួយ ដែលអ្នកបានប្រើកំណត់វា — ផ្នែកទាំងពីរជាជម្រើសជំនួសគ្នា ដូច្នេះការជ្រើសមួយ នឹងលុបមួយទៀត។ ប្រសិនបើម៉ោងដែលអ្នកកំណត់ **បានកន្លងផុតទៅហើយ** កម្មវិធីនឹងប្រាប់ (**[en:tran:The set time is already due]**) ហើយមិនចាប់ផ្តើមអ្វីទេ៖ វានឹងមិនរង់ចាំដោយស្ងាត់ៗ រហូតដល់ថ្ងៃស្អែកទេ។ កំណត់ម៉ោងថ្មី ឬកំណត់វាជាវិនាទី។ 📸
4. **វារាប់តែនៅក្នុងផ្ទាំងមើលជាមុនប៉ុណ្ណោះ។** បន្ទាត់ **[en:tran:Next]៖** មានន័យ តែពេលដែល **ផ្ទាំងមើលជាមុន** របស់តារាងកម្មវិធីនោះកំពុងបើកប៉ុណ្ណោះ (W-22b) — ផ្ទាំងនោះហើយ ដែលដើរតាមតារាងកម្មវិធី៖ ការចុចប៊ូតុងរបស់វានៅទីនោះ ចាប់ផ្តើមការរាប់ថយក្រោយរបស់វា ហើយស្លាកតូចមួយនៅជ្រុងខាងលើខាងស្ដាំនៃផ្ទាំង បង្ហាញវិនាទីដែលនៅសល់ ជាមួយ ⊗ ដើម្បីបញ្ឈប់វា និង ⏸ ដើម្បីផ្អាកវា។ ចុចបន្ទាត់នោះ ពេលផ្ទាំងបិទ ហើយកម្មវិធីនឹងប្រាប់អ្នក (**[en:tran:Open the presenting flow preview to use this action]**) ជាជាងធ្វើហាក់ដូចជាវាបានធ្វើអ្វីមួយ។ វាមិនដែលទៅកាន់អេក្រង់ទេ ដូច្នេះវាគ្មាន **[en:tran:Apply on Screens]** និងគ្មាន **[en:tran:Set Specific Screen]** ហើយគ្មានអ្វីអាចភ្ជាប់ទៅវាបានទេ។
5. **ការរង់ចាំក៏អាចភ្ជាប់ជាមួយបន្ទាត់ផ្សេងបានដែរ។** ភ្ជាប់វាទៅបន្ទាត់មួយ — ស្លាយ ចម្រៀង ខគម្ពីរ — ជា **ធាតុ CC** (W-22g) ហើយបន្ទាត់នោះមានន័យថា "បង្ហាញនេះ ហើយបន្តទៅមុខដោយខ្លួនឯង N វិនាទីក្រោយមក"។ បន្ថែម **[en:tran:Next: Timeout]** តែម្ដង ចុចកណ្ដុរស្ដាំលើបន្ទាត់ដែលអ្នកចង់ដាក់វា → **[en:tran:Add CC Elements]** ហើយជ្រើសវា។ ប៉ុន្តែ សូមទុកបន្ទាត់ **[en:tran:Next: Timeout]** ខ្លួនឯងនៅក្នុងបញ្ជី៖ CC ចង្អុលទៅបន្ទាត់នោះ ជាជាងចម្លងវា ដូច្នេះការលុបបន្ទាត់នោះ នឹងលុបអ្នកតាមទាំងអស់របស់វាផងដែរ (ទុកវាមួយឡែកដោយ **[en:tran:Disable]** ប្រសិនបើការដំណើរការមិនគួរឈប់នៅទីនោះ — អ្នកតាមរបស់វានៅតែដំណើរការ)។ ពេលភ្ជាប់ទៅចម្រៀង **ទាំងមូល** វាធ្វើតាមគ្រប់ស្លាយរបស់ចម្រៀងនោះ ដែលជារបៀបធ្វើឲ្យចម្រៀងមួយ បន្តទៅមុខដោយខ្លួនឯង។ 📸
