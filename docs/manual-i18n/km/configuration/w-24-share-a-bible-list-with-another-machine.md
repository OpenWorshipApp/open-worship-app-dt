# W-24 — ចែករំលែកបញ្ជីព្រះគម្ពីរទៅម៉ាស៊ីនមួយទៀត

បញ្ជីព្រះគម្ពីរ (ខគម្ពីរដែលអ្នកបានរៀបជាជួរសម្រាប់កម្មវិធីថ្វាយបង្គំមួយ) ក៏ផ្ទេរទៅបានតាមរបៀបដូចគ្នាដែរ។

1. នៅក្នុងផ្ទាំង **[en:tran:Bibles]** ចុចកណ្ដុរស្ដាំលើបញ្ជីដែលអ្នកចង់បាន ហើយជ្រើស **[en:tran:Export]**។ ផ្ទាំងតូចមួយសួររក **[en:tran:Password]** និង
   **[en:tran:Confirm Password]** — ទុកទាំងពីរឱ្យនៅទទេ សម្រាប់កញ្ចប់ធម្មតា ឬវាយ
   ពាក្យសម្ងាត់ដូចគ្នានៅក្នុងប្រអប់ទាំងពីរ ដើម្បីចាក់សោវា (W-22 ជំហាន 10a)។ អ្នកនឹងទទួលបាន
   ឯកសារ `<name>.owbible.tar.gz` មួយនៅក្នុងថត **Downloads** របស់អ្នក ឬ `<name>.owbible.enc`
   ប្រសិនបើអ្នកបានដាក់ពាក្យសម្ងាត់។ 📸
2. កញ្ចប់នេះតូច: បញ្ជីព្រះគម្ពីររក្សាទុកតែ _ការយោង_ ខគម្ពីរប៉ុណ្ណោះ មិនមែនអត្ថបទព្រះគម្ពីរទេ ដូច្នេះ
   មានតែបញ្ជីនោះ និងផ្ទៃខាងក្រោយណាមួយដែលអ្នកបានភ្ជាប់ទៅវា (ឬទៅខគម្ពីរណាមួយរបស់វា) ប៉ុណ្ណោះ
   ដែលនៅខាងក្នុង។
3. នៅលើម៉ាស៊ីនមួយទៀត ចុចកណ្ដុរស្ដាំលើកន្លែងទទេនៃផ្ទាំង **[en:tran:Bibles]** → **[en:tran:Import]** ហើយជ្រើសឯកសារនោះ — ឬ **អូសឯកសារ `.owbible.tar.gz` (ឬ `.owbible.enc`) ទៅដាក់លើ
   ផ្ទាំងព្រះគម្ពីរ**; ឯកសារដែលមានការការពារនឹងសួររកពាក្យសម្ងាត់របស់វាជាមុនសិន។ **[en:tran:Import From URL]** ក៏ប្រើបាននៅទីនេះដែរ។ 📸
4. បញ្ជីនោះលេចឡើងក្នុងថតព្រះគម្ពីររបស់ម៉ាស៊ីននោះ ជាមួយខគម្ពីររបស់វា ពណ៌របស់ខគម្ពីរទាំងនោះ និង
   ផ្ទៃខាងក្រោយរបស់វា ត្រៀមរួចជាស្រេចសម្រាប់បង្ហាញ។

> ចំណាំ: **កំណែ** ព្រះគម្ពីរដែលខគម្ពីរទាំងនោះយោងទៅ មិនមែនជាផ្នែកនៃកញ្ចប់ទេ — ពួកវាជា
> ឯកសារធំៗ ដែលត្រូវទាញយកដាច់ដោយឡែក។ ប្រសិនបើម៉ាស៊ីនមួយទៀតមិនទាន់មានកំណែនោះទេ
> សូមទាញយកវានៅទីនោះ (ការកំណត់ → ព្រះគម្ពីរ) នោះខគម្ពីរនឹងបង្ហាញឡើង។ ទំព័រ **[en:tran:Bible Reader]**
> មានថតព្រះគម្ពីរផ្ទាល់ខ្លួន ដូច្នេះការនាំចូលនៅទីនោះ បន្ថែមបញ្ជីទៅក្នុងថតរបស់ទំព័រអាន
> មិនមែនថតរបស់ទំព័រធ្វើបទបង្ហាញទេ។
>
> កញ្ចប់មួយអាចនាំចូលបានតែដោយបញ្ជីដែលវាមកពីប៉ុណ្ណោះ: ការជ្រើសកញ្ចប់ឯកសារនៅក្នុង
> ផ្ទាំងព្រះគម្ពីរ (ឬកញ្ចប់ព្រះគម្ពីរនៅក្នុងបញ្ជីឯកសារ) នឹងត្រូវបដិសេធ ដោយមានសារមួយ
> ប្រាប់ពីអ្វីដែលឯកសារនោះពិតជាមាន ហើយគ្មានអ្វីត្រូវបានសរសេរទេ។
