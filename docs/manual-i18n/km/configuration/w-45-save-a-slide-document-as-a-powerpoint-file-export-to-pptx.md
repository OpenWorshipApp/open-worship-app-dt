# W-45 — រក្សាទុកឯកសារស្លាយជាឯកសារ PowerPoint (បំលែងទៅឯកសារ PPTX)

សម្រាប់ពេលដែលឯកសារស្លាយមួយត្រូវបង្ហាញ ឬកែ នៅកន្លែងដែលគ្មានកម្មវិធីនេះ — កុំព្យូទ័រយួរដៃរបស់អ្នក
អធិប្បាយភ្ញៀវ ព្រះវិហារដែលប្រើ PowerPoint, Google Slides ឬ Keynote។ មិនដូច
**[en:tran:Export]** (W-23) ដែលនាំឯកសារទៅកម្មវិធី Open Worship មួយទៀតទេ ការនេះបង្កើត
ឯកសារ PowerPoint ដែលអ្នកណាក៏អាចបើកបាន។

1. នៅក្នុងបញ្ជី **[en:tran:Documents]** ចុចកណ្ដុរស្ដាំលើឯកសារស្លាយ Open Worship មួយ (ឬចុច
   **⋮** នៅចុងជួររបស់វា) ហើយជ្រើសរើស **[en:tran:Export to PPTX]**។ វានៅ
   ខាងក្រោម **[en:tran:Export]** បន្តិច។ 📸
2. សម្រាប់ចម្រៀង សូមជ្រើសរើសជួររបស់វា ដើម្បីឱ្យ **[en:tran:Stage Previewer]** បើកឡើង។ បន្ថែម ឬដក
   ស្ទែជ រហូតដល់ប្លង់ដែលអ្នកចង់បាន អាចមើលឃើញ បន្ទាប់មកចុច **⋮** នៅក្បាល
   អ្នកមើលជាមុនដំណាក់កាល ហើយជ្រើសរើស **[en:tran:Export to PPTX]**។ កម្មវិធីសរសេរឯកសារស្លាយមួយ សម្រាប់
   ស្ទែជនីមួយៗដែលមើលឃើញ៖ `<song> - Stage 0.pptx`, `<song> - Stage 1.pptx` ជាដើម។ ឯកសារនីមួយៗ
   ប្រើប្លង់ និងរចនាប័ទ្មទំនុកច្រៀងផ្ទាល់របស់ស្ទែជនោះ។ 📸
3. សារ **[en:tran:Export to PPTX]** មួយលេចឡើង ដោយនិយាយថា **[en:tran:Exported to]** និង
   ទីតាំង៖ ឯកសារ `<name>.pptx` នៅក្នុងថត **Downloads** របស់អ្នក ដែលបើកឡើងជាមួយឯកសារនៅក្នុងនោះ។
   ការនាំចេញចម្រៀងជាបាច់ បើកថត Downloads តែម្ដង។ ការនាំចេញម្ដងទៀត បន្ថែមច្បាប់ចម្លងដែលមានលេខ
   នៅក្បែរឯកសារមុនៗ។ 📸
4. បើកវានៅក្នុង PowerPoint។ ស្លាយនីមួយៗមើលទៅដូចដែលអេក្រង់បង្ហាញ៖
   - ពាក្យនៅតែជាពាក្យដែលអ្នកអាចកែបាន ដោយចុះបន្ទាត់ត្រង់កន្លែងដែលកម្មវិធីចុះបន្ទាត់
     ពិតប្រាកដ ក្នុងពុម្ពអក្សរដដែល — ហើយកន្លែងដែលពុម្ពអក្សរនោះគ្មានអក្សរសម្រាប់ផ្នែកណាមួយនៃអត្ថបទ (ភាសា
     អង់គ្លេសនៅក្នុងចំណងជើងខ្មែរ) គឺក្នុងពុម្ពអក្សរដែលកម្មវិធីបានប្រើសម្រាប់ផ្នែកនោះជំនួសវិញ។
   - ប្រអប់អត្ថបទរក្សាពណ៌ ពណ៌ថ្លា និងជ្រុងមូលរបស់វា ហើយប្រអប់ដែល
     ធ្វើឱ្យអ្វីនៅពីក្រោយវាព្រិល មានភាពព្រិលនោះជារូបភាពមួយនៅពីក្រោមវា។
   - រូបភាពរក្សាទីតាំង និងទំហំរបស់វា។ វីដេអូក្លាយជារូបភាពដំបូងរបស់វា ហើយប្រអប់គេហទំព័រ
     ក្លាយជារូបភាពនៃទំព័ររបស់វា។
   - នៅពីក្រោយស្លាយនីមួយៗ គឺជាផ្ទៃខាងក្រោយដែលអេក្រង់នឹងបង្ហាញ៖ ផ្ទៃខាងក្រោយរបស់ស្លាយផ្ទាល់
     បើគ្មាន គឺរបស់ឯកសារ បើគ្មានទៀត គឺផ្ទៃខាងក្រោយដែលស្លាយមុនបានទុកនៅលើអេក្រង់ — ដូច្នេះស្លាយដែល
     មកបន្ទាប់ពីផ្ទៃខាងក្រោយវីដេអូ រក្សាវាទុក ដូចពេលអ្នកបង្ហាញពួកវាតាមលំដាប់ដែរ។ 📸
5. អ្វីដែលអ្នកបានសរសេរនៅក្នុង **[en:tran:Slide Note]** របស់ស្លាយមួយ នឹងនៅក្នុង **Notes** របស់ស្លាយនោះនៅក្នុង
   PowerPoint ហើយស្លាយដែលអ្នកបានបិទ នឹងចេញមកជាស្លាយ **លាក់ (hidden)** ដែលត្រូវរំលងពេល
   បង្ហាញ។
