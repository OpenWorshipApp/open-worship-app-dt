# W-22g — ឲ្យបន្ទាត់មួយនាំបន្ទាត់ផ្សេងទៀតមកជាមួយ (ធាតុ CC)

**គោលដៅ:** នៅពេលឃ្លាទី 1 ឡើងលើអេក្រង់ អក្សររត់ស្វាគមន៍ក៏ឡើងដែរ — ចុចម្ដង បានទាំងពីរ។

1. **ឲ្យបន្ទាត់មួយនាំបន្ទាត់ផ្សេងទៀតមកជាមួយ — ធាតុ CC។** របស់ខ្លះត្រូវទៅ _ជាមួយគ្នា_៖ នៅពេលឃ្លាទី 1 ឡើង អក្សររត់ស្វាគមន៍ត្រូវតែឡើងដែរ។ ភ្ជាប់អក្សររត់នោះទៅបន្ទាត់នោះជា **ធាតុ CC** ហើយការចុចតែម្ដងនឹងធ្វើទាំងពីរ។

   ភ្ជាប់វាតាមវិធីណាមួយក្នុងចំណោមវិធីពីរ៖
   - **ទម្លាក់វាលើបន្ទាត់** — អូសប៊ូតុងអក្សររត់ ផ្ទៃខាងក្រោយ ខគម្ពីរ ឬស្លាយ ចេញពីផ្ទាំងរបស់វា ហើយទម្លាក់វា _លើបន្ទាត់ដែលវាត្រូវនៅជាមួយ_ (បន្ទាត់នោះមានស៊ុមដាច់ៗពណ៌លឿងទុំ ពេលអ្នកអូសពីលើវា)។ ការទម្លាក់លើ **ស្លាយរបស់ឯកសារ** ភ្ជាប់វាទៅស្លាយតែមួយនោះ; ការទម្លាក់លើបន្ទាត់ផ្ទាល់របស់ឯកសារ ភ្ជាប់វាទៅចម្រៀងទាំងមូល។ អ្នកក៏អាចអូសបន្ទាត់មួយដែល **មាននៅក្នុងតារាងកម្មវិធីរួចហើយ** — រួមទាំងសកម្មភាពលុបផងដែរ — ទៅលើបន្ទាត់មួយទៀតបាន។ អ្វីដែលអូសចូលពីផ្ទាំងផ្សេង ក៏ត្រូវបានបន្ថែមជាបន្ទាត់ផ្ទាល់ខ្លួនមួយនៅខាងចុងបញ្ជីដែរ — ព្រោះធាតុ CC ចង្អុលទៅបន្ទាត់មួយនៃតារាងកម្មវិធី — ដូច្នេះសូមទុកបន្ទាត់នោះនៅនឹងកន្លែង៖ ការដកវាចេញ នឹងដកធាតុ CC ចេញជាមួយ។

     **តម្រង់ចំកណ្ដាលបន្ទាត់ដើម្បីភ្ជាប់ ឬចំគែមខាងលើ ឬខាងក្រោមរបស់វាដើម្បីផ្លាស់ទី។** ដើម្បីទម្លាក់បន្ទាត់មួយលើបន្ទាត់មួយទៀត សូមអូសបន្ទាត់នោះផ្ទាល់។ បន្ទាត់មួយនៃតារាងកម្មវិធីធ្វើការងារទាំងពីរ ហើយវាប្រាប់អ្នកថាវាហៀបនឹងធ្វើមួយណា៖ ខ្សែតាមគែមខាងលើ និងខាងក្រោម មានន័យថា "បន្ទាត់នេះផ្លាស់ទីមកទីនេះ" ឯប្រអប់ដាច់ៗព័ទ្ធជុំវិញបន្ទាត់ទាំងមូល មានន័យថា "របស់នេះទៅ _លើ_ បន្ទាត់នោះ"។ ស្លាយ និងបន្ទាត់ CC គ្មានលំដាប់ផ្ទាល់ខ្លួនទេ ដូច្នេះទម្លាក់កន្លែងណាក៏ដោយលើវា គឺភ្ជាប់។

     **ឬប្រាប់ថាអ្នកចង់បានមួយណា ហើយមិនបាច់តម្រង់**៖ សង្កត់ **Ctrl** (⌘ នៅលើ Mac) ពេលអ្នកអូស ហើយការទម្លាក់នឹងយក "កន្លែង" នោះ សង្កត់ **Alt** វានឹង "ភ្ជាប់" ជានិច្ច នៅកន្លែងណាក៏ដោយលើបន្ទាត់។ ចុច ឬលែងគ្រាប់ចុចនោះពាក់កណ្ដាលការអូស ហើយសញ្ញានៅក្រោមទ្រនិចកណ្ដុរនឹងប្ដូរតាម ដូច្នេះអ្នកអាចមើលឃើញថាការទម្លាក់នឹងធ្វើអ្វី មុនពេលអ្នកលែងដៃ។ (បើសង្កត់ទាំងពីរ "កន្លែង" ឈ្នះ។) សម្រាប់បន្ទាត់មួយនៃតារាងកម្មវិធីនេះ "យកកន្លែងនោះ" មានន័យថាវា "ផ្លាស់ទី" ទៅទីនោះ; សម្រាប់អ្វីដែលអូសចូលពីផ្ទាំងផ្សេង វាមានន័យថាវាត្រូវបាន "បញ្ចូល" នៅទីនោះ — ដែលជាវិធីតែមួយគត់ក្នុងការដាក់វានៅកន្លែងណាផ្សេងក្រៅពីចុងបញ្ជី ព្រោះការទម្លាក់លើឈ្មោះតារាងកម្មវិធី បន្ថែមវានៅខាងចុង។

   - ចុចកណ្ដុរស្ដាំលើបន្ទាត់នោះ → **[en:tran:Add CC Elements]** ហើយជ្រើសរើសពីបន្ទាត់ផ្សេងទៀតដែលមាននៅក្នុងតារាងកម្មវិធីនេះរួចហើយ។ 📸

   ធាតុ CC បង្ហាញជាបន្ទាត់ `↳` នៅពីក្រោមបន្ទាត់ដែលវាទៅជាមួយ។ ចាប់ពីពេលនោះ **ការចុចបន្ទាត់នោះ — ឬការទៅដល់វាដោយគ្រាប់ចុចព្រួញ/Space ក្នុងការមើលជាមុន — ដាក់បន្ទាត់នោះ "និង" ធាតុ CC របស់វាលើអេក្រង់ជាមួយគ្នា** នៅលើអេក្រង់ដដែលដែលបន្ទាត់នោះខ្លួនឯងបានទៅ។ អ្នកមិនដែលត្រូវបានសួរ "អេក្រង់មួយណា?" ពីរដងសម្រាប់ការចុចតែម្ដងទេ។

   - ធាតុ CC លើ **បន្ទាត់ឯកសារ** ទៅជាមួយស្លាយ _នីមួយៗ_ នៃចម្រៀងនោះ (បន្ទាត់ឯកសារគ្មានអ្វីផ្ទាល់ខ្លួនសម្រាប់បង្ហាញទេ ដូច្នេះនេះហើយជាន័យនៃ "ទុកអក្សររត់នេះឲ្យនៅលើអេក្រង់សម្រាប់ចម្រៀងនេះ"); ធាតុ CC លើ **ស្លាយមួយ** ទៅជាមួយតែស្លាយនោះប៉ុណ្ណោះ។
   - ធាតុ CC អាចមានអេក្រង់ផ្ទាល់ខ្លួន៖ ចុចកណ្ដុរស្ដាំលើវា → **[en:tran:Set Specific Screen]** ដើម្បីបញ្ជូនវាទៅកន្លែងផ្សេង ខណៈដែលបន្ទាត់របស់វាទៅកន្លែងធម្មតា។ **[en:tran:No Specific Screen]** ឲ្យវាត្រឡប់មកដើរតាមបន្ទាត់វិញ។
   - **ការចុចបន្ទាត់ CC មិនដែលបញ្ចាំងវាទេ។** វារំកិលធាតុដែលវាចង្អុលទៅ ឲ្យមកក្នុងទិដ្ឋភាព ហើយធ្វើឲ្យវាភ្លឹបភ្លែត — ទាំងក្នុងតារាងកម្មវិធី និងក្នុងបង្អួចមើលជាមុនក្នុងពេលតែមួយ — ដូច្នេះអ្នកតែងតែអាចរកឃើញថា ស្លាកខ្លីមួយសំដៅលើអ្វី។
   - ចុចកណ្ដុរស្ដាំលើបន្ទាត់ CC ដើម្បីបាន **[en:tran:Remove CC Element]**។ គ្មាន **[en:tran:Disable]** លើធាតុ CC ទេ៖ ការផ្អាកទុក (parking) ដក _បន្ទាត់_ មួយចេញពីតារាងកម្មវិធី ហើយធាតុ CC មិនមែនជាបន្ទាត់មួយនៃតារាងកម្មវិធីទេ — ធាតុ CC ដែលអ្នកមិនចង់បាន គ្រាន់តែដកវាចេញ។ (ដូច្នេះ ការភ្ជាប់បន្ទាត់ដែលអ្នកបានផ្អាកទុក ផ្ដល់ឲ្យអ្នកនូវធាតុ CC ដែល _ធ្វើការ_ ខណៈដែលបន្ទាត់ដែលបានផ្អាកទុកនោះ នៅតែផ្អាកទុកដដែល។) ឯកសារទាំងមូល និងបទសំឡេង មិនអាចជាធាតុ CC បានទេ — ព្រោះគ្មានមួយណាទៅដល់អេក្រង់ទេ — ហើយកម្មវិធីនឹងប្រាប់អ្នក បើអ្នកសាកល្បង។

   ធាតុមួយអាចមានធាតុ CC ច្រើនតាមដែលអ្នកចង់បាន; ធាតុ CC មិនអាចមានធាតុ CC ផ្ទាល់ខ្លួនបានទេ។
