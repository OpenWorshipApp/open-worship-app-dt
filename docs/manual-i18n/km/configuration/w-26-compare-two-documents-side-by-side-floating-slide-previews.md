# W-26 — ប្រៀបធៀបឯកសារពីរនៅក្បែរគ្នា (ការមើលស្លាយជាមុនក្នុងបង្អួចអណ្ដែត)

**គោលដៅ:** មើលស្លាយរបស់ឯកសារច្រើនជាងមួយក្នុងពេលតែមួយ ដោយមិនបាត់ឯកសារដែលអ្នកបានបើករួចហើយ។

**លក្ខខណ្ឌជាមុន:** មានឯកសារយ៉ាងហោចណាស់ពីរនៅក្នុងបញ្ជី **[en:tran:Documents]**។

ផ្ទាំងកណ្ដាលបង្ហាញការមើលជាមុននៃឯកសារ **តែមួយ** ដែលអ្នកបានជ្រើសរើស។ ដើម្បីមើលឯកសារមួយទៀតផងដែរ សូមឲ្យវាមានបង្អួចផ្ទាល់ខ្លួនមួយ។

1. នៅក្នុងបញ្ជី **[en:tran:Documents]** ខាងឆ្វេង **ចុចកណ្ដុរស្ដាំ** លើឯកសារមួយដែលអ្នកមិនទាន់បានជ្រើសរើស ហើយជ្រើសរើស **[en:tran:Open Slides Preview]**។ បង្អួចមួយដែលមានចំណងជើង **ស្លាយ: ‹ឈ្មោះ›** នឹងលេចឡើងពីលើកម្មវិធី។ 📸 វិធីលឿនជាងនេះ នៅពេលអ្នកស្គាល់វាហើយ៖ សង្កត់ **Ctrl** (**⌘** នៅលើ Mac) ហើយចុចលើជួរនោះ។ លទ្ធផលដូចគ្នា ដោយគ្មានម៉ឺនុយ — ហើយសង្កត់ Ctrl ហើយចុចជួរនោះម្ដងទៀត នឹងបិទបង្អួចនោះ។ ព័ត៌មានជំនួយ (tooltip) របស់ធាតុម៉ឺនុយនោះ រំលឹកអ្នកពីផ្លូវកាត់នេះ។
2. វាជាកម្មវិធីមើលជាមុនពេញលេញ មិនមែនគ្រាន់តែជាជួររូបតូចៗទេ៖ របារ ត្រឡប់ក្រោយ / ធ្វើឡើងវិញ / បោះបង់ការកែប្រែ / រក្សាទុក នៅខាងលើ ស្លាយទាំងឡាយ របារ **[en:tran:Note]** ពណ៌បៃតង (ប្រអប់កំណត់ត្រាបិទនៅពេលដំបូង — ចុចលើវាដើម្បីបើកវា) និងរបាររំកិលពង្រីក/បង្រួម ជាមួយឈ្មោះឯកសារ នៅខាងក្រោម។ អ្វីៗដែលអ្នកអាចធ្វើបាននៅផ្ទាំងកណ្ដាល អ្នកក៏អាចធ្វើបាននៅទីនេះដែរ — ចុចស្លាយមួយដើម្បីដាក់វាលើអេក្រង់ អូសស្លាយមួយដើម្បីប្ដូរលំដាប់វា ទម្លាក់រូបភាព ឬវីដេអូមួយលើវា ចុចកណ្ដុរស្ដាំលើស្លាយមួយដើម្បីបើកម៉ឺនុយរបស់វា។
3. អូសបង្អួចដោយរបារចំណងជើងរបស់វា ដើម្បីផ្លាស់ទីវា អូសគែម ឬជ្រុងណាមួយ ដើម្បីប្ដូរទំហំវា ហើយប្រើ **សញ្ញាព្រួញ (chevron)** ដើម្បីបង្រួមវាឲ្យនៅសល់តែចំណងជើង។ **✕** បិទវា។ **ចុចពីរដងលើរបារចំណងជើង** ដើម្បីពង្រីកបង្អួចឲ្យពេញបង្អួចកម្មវិធីទាំងមូល; ចុចពីរដងម្ដងទៀត ដើម្បីឲ្យវាត្រឡប់ទៅទំហំ និងទីតាំងដូចដើមវិញ។ បង្អួចអណ្ដែតទាំងអស់ក្នុងកម្មវិធី ធ្វើការតាមរបៀបនេះ។
4. ធ្វើជំហានទី 1 ម្ដងទៀតលើឯកសារទីពីរ។ អ្នកនឹងទទួលបានបង្អួច **ទីពីរ** — មួយសម្រាប់ឯកសារនីមួយៗ ច្រើនតាមដែលអ្នកត្រូវការ ហើយបង្អួចនីមួយៗបើកឡើងឃ្លាតបន្តិចពីបង្អួចមុន។ 📸
5. ពង្រីក/បង្រួមបង្អួចមួយដោយរបាររំកិលរបស់វា (ឬសង្កត់ **Ctrl** ហើយរំកិលកង់កណ្ដុរពីលើវា)។ មានតែបង្អួចនោះប៉ុណ្ណោះដែលប្រែប្រួល៖ បង្អួចនីមួយៗ និងផ្ទាំងកណ្ដាល រក្សាកម្រិតពង្រីករៀងៗខ្លួន។
6. ចុចនៅក្នុងតំបន់ស្លាយរបស់បង្អួចមួយ រួចប្រើ **គ្រាប់ចុចព្រួញ / PageUp / PageDown / Space** — គ្រាប់ចុចទាំងនេះផ្លាស់ទីក្នុងឯកសាររបស់បង្អួច **នោះ** មិនមែនឯកសារដែលផ្ទាំងកណ្ដាលកំពុងបង្ហាញទេ។

- បង្អួចនីមួយៗចងចាំ **កន្លែងដែលអ្នកដាក់វា ទំហំដែលអ្នកធ្វើឲ្យវា និងកម្រិតដែលអ្នកពង្រីកវា** តាមឯកសារនីមួយៗ — បើកវាម្ដងទៀតនៅពេលក្រោយ វានឹងមកវិញដូចដើម។
