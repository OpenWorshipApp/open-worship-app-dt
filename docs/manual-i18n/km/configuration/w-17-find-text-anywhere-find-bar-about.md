# W-17 — ស្វែងរកអក្សរនៅគ្រប់ទីកន្លែង (របារស្វែងរក) និង About

- **របារស្វែងរក:** ចុច **Ctrl+F** (**⌘F** នៅលើ macOS) ឬប្រើ **Edit → Find** នៅលើរបារម៉ឺនុយរបស់កម្មវិធី។
  របារស្ដើងមួយនឹងលេចចុះមកនៅ **ជ្រុងខាងលើស្ដាំនៃបង្អួចនោះផ្ទាល់** ហើយស្វែងរកតែក្នុងបង្អួចនោះប៉ុណ្ណោះ។
  បង្អួចទាំងនេះនីមួយៗមានរបាររបស់ខ្លួន: ធ្វើបទបង្ហាញ កែសម្រួលស្លាយ អានព្រះគម្ពីរ Screen Mirror និងការកំណត់
  បង្អួច About និងចែករំលែកតាមបណ្ដាញ កម្មវិធីកែសម្រួលទំព័របណ្ដាញ និងកម្មវិធីកែសម្រួលទំនុកច្រៀង ផ្ទាំងជំនួយ (🤖)
  និង **ផ្ទាំងជជែក AI** (✨) — ដែលនៅទីនោះវាស្វែងរកពាក្យរបស់គេហទំព័រផ្ទាល់ផងដែរ រួមទាំងភាសាខ្មែរ។ អេក្រង់
  (គ្មានអ្វីត្រូវស្វែងរកនៅលើម៉ាស៊ីនបញ្ចាំង) និងកំណត់ត្រាព្រះគម្ពីរ (វាមានការស្វែងរកផ្ទាល់ខ្លួន) មិនមានទេ។ នៅក្នុង
  កម្មវិធីកែសម្រួលទំព័របណ្ដាញ របាររកឃើញតែបន្ទាត់ដែលកម្មវិធីកែកំពុងបង្ហាញប៉ុណ្ណោះ ដូច្នេះសូមរំកិលទៅបន្ទាត់ដែលនៅសល់។ 📸
  - វាយពាក្យ ហើយវាស្វែងរកភ្លាមៗពេលអ្នកកំពុងវាយ; លេខរាប់បង្ហាញ **`<current>/<total>`**។
  - **Enter** លោតទៅកន្លែងត្រូវគ្នាបន្ទាប់ **Shift+Enter** ទៅកន្លែងមុន; ប៊ូតុង **⌃**
    និង **⌄** ធ្វើដូចគ្នា ហើយវិលពីចុងមកដើមវិញ។
  - ប៊ូតុង **Aa** បើក ឬបិទការបែងចែកអក្សរធំ និងអក្សរតូច។ **គ្មានជម្រើសស្វែងរកពាក្យពេញ
    និងគ្មានជម្រើស regex ទេ** — មុខងារស្វែងរកក្នុងទំព័ររបស់ Chromium មិនផ្ដល់ជម្រើសទាំងនេះទេ។
  - អូស **ដងកាន់** នៅខាងឆ្វេង ដើម្បីរុញរបារ **ទៅចំហៀង** ពេលវាបាំងអ្វីដែលអ្នកត្រូវអាន;
    វានៅតែក្នុងបង្អួច ហើយមិនដែលចាកចេញពីផ្នែកខាងលើឡើយ។
  - **Esc** ឬប៊ូតុង **✕** បិទរបារ ហើយលុបការបន្លិចទាំងអស់។ ការចុច
    **Ctrl/⌘+F** ម្ដងទៀត ជ្រើសពាក្យដែលបានស្វែងរកពីមុនឡើងវិញ ជំនួសឱ្យការបើករបារទីពីរ។
  - របារនេះជាផ្នែករបស់កម្មវិធី មិនមែនជាផ្នែកនៃទំព័រទេ: វាត្រូវបានគូរក្នុងផ្ទាំងមើលដាច់ដោយឡែករបស់វា ដូច្នេះ
    ពាក្យដែលអ្នកវាយ មិនដែលត្រូវបានរកឃើញដោយការស្វែងរករបស់អ្នកខ្លួនឯងទេ។
- **About:** បង្ហាញកំណែរបស់កម្មវិធី និងតំណភ្ជាប់របស់គម្រោង។
