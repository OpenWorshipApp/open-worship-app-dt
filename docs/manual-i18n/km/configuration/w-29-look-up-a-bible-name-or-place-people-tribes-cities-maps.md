# W-29 — ស្វែងរកឈ្មោះ ឬទីកន្លែងក្នុងព្រះគម្ពីរ (មនុស្ស កុលសម្ព័ន្ធ ទីក្រុង ផែនទី)

**គោលដៅ:** ស្វែងយល់ថា នរណាម្នាក់ក្នុងព្រះគម្ពីរជានរណា ឬទីកន្លែងមួយនៅឯណា ដោយមិនចាំបាច់ចាកចេញពីការអានព្រះគម្ពីររបស់អ្នក។

1. បើក **[en:tran:Bible Reader]** ឬផ្ទាំងលេចឡើង **[en:tran:Bible Lookup]** ក្នុងទំព័រធ្វើបទបង្ហាញ។ នៅចុងខាងស្ដាំនៃប្រអប់យោងខគម្ពីរ ចុចប៊ូតុងរូបមនុស្ស និងម្ជុលទីតាំង **[en:tran:Names and locations lookup]**។ បង្អួចអណ្ដែតតូចមួយនឹងបើកឡើង។ ការបើកលើកដំបូង ចំណាយពេលពីរបីវិនាទី ពេលវចនានុក្រមកំពុងផ្ទុក។ ពេលបង្អួចនៅបើក វាលឿនភ្លាមៗ។ នៅពេលអ្នកបិទវា វចនានុក្រមត្រូវបានដោះលែង បន្ទាប់ពីប្រហែលដប់វិនាទី ហើយការបើកលើកក្រោយ នឹងរង់ចាំវាម្ដងទៀត។ វាជាបង្អួចអណ្ដែតដូចបង្អួចផ្សេងទៀតដែរ៖ អូសវាដោយរបារចំណងជើង ប្ដូរទំហំវាពីគែមណាក៏បាន ហើយ **ចុចពីរដងលើរបារចំណងជើង** ដើម្បីឱ្យវាពេញបង្អួចកម្មវិធី ពេលអ្នកចង់អានបញ្ជីវែង — ចុចពីរដងម្ដងទៀត ដើម្បីដាក់វាត្រឡប់ទៅកន្លែងដើមវិញ។ 📸
2. **កូដភាសា** តូចនៅក្បែរប៊ូតុងនោះ (`en`) គឺជាភាសាដែលឈ្មោះ និងទីកន្លែងខ្លួនវាត្រូវបានសរសេរ។ ចុចវា ហើយជ្រើសភាសាមួយផ្សេង — `km - Khmer (ភាសាខ្មែរ)` — ហើយបញ្ជីស្វែងរក និងផ្ទាំង "ក្នុងការអានរបស់អ្នក" នឹងប្ដូរទៅភាសានោះភ្លាមៗ ដោយមិនចាំបាច់ផ្ទុកឡើងវិញ។ បង្អួចមនុស្ស និងទីកន្លែងដែលបើករួចហើយ រក្សាភាសារបស់វាផ្ទាល់។ ជម្រើសនេះត្រូវបានចងចាំសម្រាប់លើកក្រោយ ហើយវា **ដាច់ដោយឡែក** ពីភាសារបស់កម្មវិធីផ្ទាល់ (**W-16**)៖ ម៉ឺនុយជាភាសាអង់គ្លេស ជាមួយឈ្មោះជាភាសាខ្មែរ គឺជាការផ្សំធម្មតាទាំងស្រុង។ ឯកសារយោងខគម្ពីរ ដែលធាតុមួយដកស្រង់ ត្រូវបានអានវិញក្នុង **ព្រះគម្ពីរដែលអ្នកកំពុងអាន** ដូច្នេះវាដាក់ឈ្មោះបទគម្ពីរ តាមរបៀបដែលព្រះគម្ពីររបស់អ្នកដាក់។ មានតែឈ្មោះដែលមានបន្ទាត់ពីក្រោម នៅក្នុងខគម្ពីរខ្លួនឯងប៉ុណ្ណោះ ដែលមិនប្ដូរ — ឈ្មោះទាំងនោះធ្វើតាមព្រះគម្ពីរដែលខគម្ពីរនីមួយៗស្ថិតនៅ (King James ជាភាសាអង់គ្លេស ព្រះគម្ពីរខ្មែរជាភាសាខ្មែរ) ដែលនេះហើយធ្វើឱ្យវាអាចរកឃើញបាន មិនមែនការកំណត់នេះទេ។ បញ្ជី បង្អួចធាតុ និងផ្ទាំង "ក្នុងការអានរបស់អ្នក" ក៏ត្រូវបាន **សរសេរជាអក្សរ និងពុម្ពអក្សរផ្ទាល់របស់ភាសានោះ** ដែរ — រួមទាំងឈ្មោះនៅខាងលើបង្អួចធាតុផង — ហើយប្រភេទនៃធាតុនីមួយៗ — **[en:tran:People]**, **[en:tran:Groups]**, **[en:tran:Places]** — ក៏ត្រូវបានដាក់ឈ្មោះជាភាសានោះដែរ ទាំងក្នុងតម្រង និងលើធាតុនីមួយៗ។ ធាតុនីមួយៗក៏មាន **ឈ្មោះភាសាអង់គ្លេសក្នុងវង់ក្រចក** នៅក្បែរឈ្មោះរបស់វាដែរ — _ម៉ូសេ (Moses)_, _យេរូសាឡិម (Jerusalem)_ — ដូចដែលសៀវភៅព្រះគម្ពីរមួយសរសេរថា _លោកុប្បត្តិ (Genesis)_ ដូច្នេះឈ្មោះដែលអ្នកស្គាល់តែជាភាសាអង់គ្លេស នៅតែអាចស្គាល់បាន។ ពេលជ្រើស `en` គ្មានអ្វីត្រូវបន្ថែមទេ៖ ឈ្មោះនោះជាឈ្មោះភាសាអង់គ្លេសរួចហើយ។ 📸
