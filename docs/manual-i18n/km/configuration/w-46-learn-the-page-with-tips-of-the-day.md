# W-46 — រៀនប្រើទំព័រ ជាមួយគន្លឹះប្រចាំថ្ងៃ

1. ប្រាំនាទីបន្ទាប់ពីបង្អួចចាប់ផ្តើម ទំព័រធ្វើការដែលនៅ

   លើកាត បញ្ឈប់របារ និងមួយនាទីនោះជាមួយគ្នា ដូច្នេះគ្មានអ្វី
