# W-54 — ផ្លាស់ទីថតទិន្នន័យរបស់អ្នកចេញពី Desktop (OneDrive)

**គោលដៅ:** រក្សាចម្រៀង ស្លាយ ព្រះគម្ពីរ និងការកំណត់របស់អ្នក នៅកន្លែងដែលកម្មវិធីបម្រុងទុក (backup) មិនអាចយកវាចេញបាន។

ពីមុន កម្មវិធីបង្កើតថតទិន្នន័យរបស់វានៅលើ Desktop គឺ `Desktop\open-worship-data`។ នៅលើ Windows កម្មវិធី Microsoft OneDrive តែងតែបម្រុងទុក Desktop ហើយពេលវាកំពុងធ្វើសមកាលកម្ម វាអាចប្តូរឯកសារទៅជាច្បាប់ចម្លងដែលមានតែនៅលើអ៊ីនធឺណិត ឬយកវាចេញពីកុំព្យូទ័រ — ចម្រៀង ស្លាយ និងការកំណត់ បានបាត់។ ឥឡូវនេះ ថតទិន្នន័យថ្មីត្រូវបានបង្កើតនៅ `.owa\open-worship-data` ក្នុងថតអ្នកប្រើរបស់អ្នក (`~/.owa/open-worship-data` នៅលើ Mac ឬ Linux) ដែលគ្មានកម្មវិធីណាធ្វើសមកាលកម្មទេ។

1. បើកកម្មវិធី។ ដរាបណាថតទិន្នន័យរបស់អ្នកនៅតែជា `Desktop\open-worship-data` រាល់ពេលចាប់ផ្តើម កម្មវិធីនឹងសួរ **[en:tran:Move Your Data Folder Off the Desktop]**។ វាប្រាប់ឈ្មោះថតរបស់អ្នក ហេតុអ្វីវាមានហានិភ័យនៅលើកុំព្យូទ័រនេះ — OneDrive នៅលើ Windows, iCloud Drive នៅលើ Mac — និងកន្លែងដែលវានឹងទៅ។ រហូតដល់វាត្រូវបានផ្លាស់ទី គ្រប់បង្អួចក៏បង្ហាញកាតដែលមានចំណងជើងដូចគ្នា ដែលប្រាប់ថា Desktop មិនមែនជាកន្លែងសុវត្ថិភាពសម្រាប់ថតទិន្នន័យរបស់អ្នកទេ ជាមួយ **[en:tran:Move Now]** និង **[en:tran:Hide for 30 days]**។ 📸
2. ចុច **[en:tran:Move Now]**។ កម្មវិធីបិទ ហើយបើកឡើងវិញ ហើយផ្លាស់ទីថតនោះ មុនពេលវាបើកអ្វីមួយនៅក្នុងនោះ។ ក្រៅពី OneDrive ថតនោះគ្រាន់តែត្រូវបានផ្លាស់ទី។ នៅក្នុង OneDrive ឬពេលឯកសារមួយនៅក្នុងនោះកំពុងត្រូវបានប្រើ ឯកសារទាំងអស់ត្រូវបានចម្លង និងពិនិត្យ ហើយថតចាស់នៅដដែលនៅកន្លែងដើម។
3. **[en:tran:Data Folder Moved]** ប្រាប់ថាទិន្នន័យរបស់អ្នកនៅទីណាឥឡូវនេះ — ហើយបន្ទាប់ពីការចម្លង ប្រាប់ថាច្បាប់ចម្លងចាស់នៅទីណា។ ចុច **[en:tran:Ok]**។ រូបភាព វីដេអូ និងចម្រៀង នៅតែបង្ហាញ៖ តំណដែលចង្អុលទៅកន្លែងចាស់ ធ្វើតាមថតនោះ។ 📸
4. បន្ទាប់ពីការចម្លង រាល់ពេលចាប់ផ្តើម កម្មវិធីបង្ហាញ **[en:tran:Old Copy of Your Data Folder]** ជាមួយថ្ងៃដែលវាត្រូវបានផ្លាស់ទី។ ពិនិត្យថាចម្រៀង និងស្លាយរបស់អ្នកមាននៅទីនោះទាំងអស់ បន្ទាប់មកចុច **[en:tran:Show Folder]** ហើយផ្លាស់ទីថតចាស់ទៅធុងសំរាមដោយខ្លួនឯង — កម្មវិធីមិនដែលលុបវាទេ។ ពេលវាបាត់ហើយ ការរំលឹកនឹងឈប់។ 📸
5. មិនមែនឥឡូវនេះទេ? **[en:tran:Not Now]** នឹងសួរម្តងទៀតនៅពេលចាប់ផ្តើមលើកក្រោយ។ **[en:tran:Hide for 30 days]** មិនសួរសំណួរនេះរយៈពេល 30 ថ្ងៃ។

> កំណត់សម្គាល់៖ `migration-moved-from.txt` នៅក្នុងថតថ្មី ប្រាប់ថាវាមកពីណា និងពេលណា។ `migration-moved-to.txt` នៅក្នុងច្បាប់ចម្លងចាស់ ប្រាប់ថាវាបានទៅណា។
> ការផ្លាស់ទីដែលបរាជ័យ មិនប្តូរអ្វីទេ៖ **[en:tran:Data Folder Not Moved]** ប្រាប់មូលហេតុ កម្មវិធីនៅតែប្រើថតនោះនៅកន្លែងដដែល ហើយនឹងសួរម្តងទៀតនៅពេលចាប់ផ្តើមលើកក្រោយ។
> នៅលើ Mac ឯកសារដែលមានតែនៅក្នុង iCloud Drive នឹងបញ្ឈប់ការផ្លាស់ទី រហូតដល់វាត្រូវបានទាញយក (Finder → **Download Now**)។
> ឈ្មោះថតថ្មីចាប់ផ្តើមដោយចំណុច ដូច្នេះ Finder និងកម្មវិធីគ្រប់គ្រងឯកសារនៅលើ Linux លាក់វា៖ ប្រអប់ជ្រើសថតនៅក្នុងការកំណត់ បង្ហាញវា។

ជំហាន 1–5 ត្រូវបានពិនិត្យផ្ទាល់នៅថ្ងៃ 2026-10-17 លើប្រវត្តិរូប dev សាកល្បង ជាមួយថតសាកល្បងនៅលើ Desktop ជាភាសាអង់គ្លេស និងភាសាខ្មែរ៖ សំណួរជាមួយចម្លើយទាំងបីរបស់វា ការផ្លាស់ទីនៅពេលកម្មវិធីចាប់ផ្តើមម្តងទៀត (ប្តូរទីតាំង រួចចម្លង ពេលឯកសារមួយកំពុងត្រូវបានបើក) លទ្ធផល ការរំលឹកជាមួយកាលបរិច្ឆេទជាលេខខ្មែរ និងការរំលឹកដែលបាត់ ពេលច្បាប់ចម្លងចាស់បាត់។ **[en:tran:Show Folder]** មិនត្រូវបានចុចទេ — វាបើកបង្អួចឯកសាររបស់កុំព្យូទ័រ — ហើយត្រូវបានសាកល្បងដោយតេស្តឯកតា។ មិនទាន់បានឃើញផ្ទាល់៖ OneDrive ខ្លួនឯង (ការចម្លងត្រូវបានបង្ខំដោយឯកសារដែលកំពុងបើក) និង Mac។
