# W-16 — ការកំណត់៖ ភាសា ស្បែក ពុម្ពអក្សរ ថត

**គោលដៅ:** កំណត់រចនាសម្ព័ន្ធកម្មវិធី។

1. ចុច **រូបស្ពឺ** ([en:tran:Setting]) នៅផ្នែកខាងលើ — ការកំណត់នឹងបើកក្នុងបង្អួចដាច់ដោយឡែករបស់វា លើ **[en:tran:Path Settings]** នៅលើកដំបូង ហើយបន្ទាប់មក លើថេបដែលអ្នកបានប្រើចុងក្រោយ។ **[en:tran:App Assistant]** ខាងលើ **[en:tran:Apply Settings]** នៅជ្រុងខាងក្រោមខាងឆ្វេង បើកបង្អួចជំនួយ ដើម្បីសួរអំពីការកំណត់ណាមួយ។ 📸
2. ថេប **[en:tran:General]**៖
   - **[en:tran:Language]:** ចុច **English**, **ខ្មែរ** ឬ **Français**។ ភាសានីមួយៗត្រូវបានរាយក្រោមឈ្មោះ **ផ្ទាល់ខ្លួន** របស់វា មិនថាអ្នកកំពុងប្រើភាសាអ្វីក៏ដោយ — ដូច្នេះប្រសិនបើការចុចខុស ធ្វើឱ្យអ្នកជាប់ក្នុងអក្សរដែលអ្នកមិនអាចអានបាន ផ្លូវត្រឡប់មកវិញ នៅតែអាចអានបាន។ (ដាក់កណ្ដុរលើប៊ូតុងមួយ ហើយ `title` របស់វាប្រាប់ឈ្មោះជាភាសាអង់គ្លេស។) ស្លាកខ្លះប្ដូរភ្លាមៗ ប៉ុន្តែការប្ដូរនឹងពេញលេញ តែនៅពេលអ្នកចុច **[en:tran:Apply Settings]** នៅជ្រុងខាងក្រោមផ្នែកខាងឆ្វេងប៉ុណ្ណោះ — វានឹងផ្ទុកបង្អួចដែលបើកទាំងអស់ឡើងវិញ។ ការកែសម្រួលដែលមិនទាន់រក្សាទុក ក្នុងកែសម្រួលស្លាយ មិនបាត់ទេ។ ភាសាជារបស់កុំព្យូទ័រនេះ មិនមែនរបស់ថតទិន្នន័យទេ៖ ប្ដូរទៅថតទិន្នន័យផ្សេង ហើយកម្មវិធីនៅតែប្រើភាសាដែលអ្នកបានជ្រើស។
   - **[en:tran:Theme]:** តាមប្រព័ន្ធ / ភ្លឺ / ងងឹត។
   - **[en:tran:Font Family]:** ពុម្ពអក្សរដែលបង្អួចរបស់កម្មវិធីខ្លួនឯងប្រើ — មិនមែនអក្សរនៅលើអេក្រង់សម្រាប់អ្នកចូលរួមទេ។ ពុម្ពអក្សរដែលមានសម្គាល់ `(Missing)` គឺត្រូវបានកំណត់ ប៉ុន្តែមិនបានដំឡើងនៅលើកុំព្យូទ័រនេះទេ។ នៅពេលពុម្ពអក្សរដែលបានជ្រើស មានកម្រាស់ច្រើនជាងមួយ បញ្ជីទីពីរនៅក្បែរវា អនុញ្ញាតឱ្យជ្រើសមួយ (`400 Regular`, `700 Bold`…)៖ **[en:tran:Default]** រក្សាកម្រាស់ដើមរបស់ពុម្ពអក្សរ។
   - **ប៊ូតុងកំណត់ឡើងវិញ** (`Clear All Settings`)៖
     **ប៊ូតុងនេះលុបការកំណត់ចោល សូមប្រើដោយប្រុងប្រយ័ត្ន។** វាសួរបញ្ជាក់ជាមុនសិន។
   - **[en:tran:Show Tips of the Day automatically]:** កំណត់ថា តើបង្អួចនីមួយៗរបស់កម្មវិធី បង្ហាញគន្លឹះស្វ័យប្រវត្តិរបស់ខ្លួន បន្ទាប់ពីបើកកម្មវិធីលើកក្រោយឬអត់។
   - ទំហំផ្ទាំងលែងកំណត់ឡើងវិញពីទីនេះទៀតហើយ — មើល **W-31**។
2a. ថេប **[en:tran:Path Settings]** (នៅក្បែរ **[en:tran:General]**)៖ កន្លែងដែលអ្វីៗទាំងអស់
    រស់នៅលើថាស។
   - **ថតឯកសារ:** កន្លែងដែលឯកសារ ទំនុកចម្រៀង និងព្រះគម្ពីរ ត្រូវបានរក្សាទុកនៅលើថាស។ ត្រូវតែមានថតទិន្នន័យ៖ អ្វីៗទាំងអស់ដែលអ្នកបង្កើត និងរៀបចំ — ចម្រៀង ស្លាយ ព្រះគម្ពីរ កំណត់ត្រា និងការកំណត់ភាគច្រើន — ត្រូវបានរក្សាទុកនៅក្នុងវា ដូច្នេះវាអាចបម្រុងទុក យកទៅលើ USB និងរកឃើញវិញបាន។ រហូតដល់ពេលជ្រើសរើសមួយ គ្រប់បង្អួចក្រៅពីការកំណត់ បង្ហាញតែ **[en:tran:No Parent Directory Selected]** **[en:tran:Go to Settings]** និង **[en:tran:App Assistant]** ហើយការកំណត់បើកលើផ្ទាំងនេះដោយខ្លួនឯង ដោយមានតែ **[en:tran:General]** (ភាសា និងស្បែក) និង **[en:tran:AI Providers]** នៅក្បែរ។ នៅក្រោម **[en:tran:Parent Directory:]**, **[en:tran:Suggested]** ផ្តល់ `.owa\open-worship-data` នៅក្នុងថតអ្នកប្រើរបស់អ្នក៖ **[en:tran:Use This Folder]** បង្កើតវាប្រសិនបើមិនទាន់មាន ហើយប្រើវា។ **[en:tran:Found Data Folders]** រាយថតទិន្នន័យនៅកំពូលដ្រាយរបស់កុំព្យូទ័រនេះ — មួយនៅលើ USB — នីមួយៗមាន **[en:tran:Switch]**។ គ្មានថតណាត្រូវបានជ្រើសរើសជំនួសអ្នកទេ។ ថតដែលបានជ្រើសរើសតែមិនមាន — USB មិនទាន់ដោត — រាប់ថាគ្មាន៖ ដោតវាចូល ហើយចុច **[en:tran:Apply Settings]**។ ថតទិន្នន័យនៅលើ Desktop មិនដែលត្រូវបានណែនាំទេ៖ ពេលកំពុងប្រើមួយ គ្រប់បង្អួចបង្ហាញកាត **[en:tran:Move Your Data Folder Off the Desktop]** ដែលប្រាប់ថា Desktop មិនមែនជាកន្លែងសុវត្ថិភាពសម្រាប់វាទេ ជាមួយ **[en:tran:Move Now]** និង **[en:tran:Hide for 30 days]** — មើល **W-54**។
   - **[en:tran:Copy Data Folder]** (នៅក្រោម **[en:tran:Parent Directory:]**, ពេលកំពុងប្រើថតមួយ)៖ ជ្រើសរើស USB ដ្រាយផ្សេង ឬថតណាមួយ ហើយច្បាប់ចម្លងពេញលេញត្រូវបានធ្វើនៅទីនោះជា `open-worship-data` រាល់ឯកសារត្រូវបានរាប់ និងពិនិត្យ។ តំណនៅក្នុងវាចង្អុលទៅច្បាប់ចម្លងខ្លួនឯង ដូច្នេះច្បាប់ចម្លងមិនដែលអាន ឬកែប្រែចម្រៀង និងរូបភាពរបស់ថតដើមទេ។ ថតដែលកំពុងប្រើមិនត្រូវបានប្តូរទេ៖ បន្ទាប់មកកម្មវិធីផ្តល់ឱ្យ **[en:tran:Switch]** ទៅច្បាប់ចម្លង។
   - **ដើម្បីទុកអ្វីៗទាំងអស់នៅកន្លែងផ្សេង** សូមចុចបន្ទាត់ថតនៅក្រោម **[en:tran:Parent Directory:]** (ថតដែលកំពុងប្រើ) ហើយប្រអប់មួយបើកនៅក្រោមវា៖ វាយផ្លូវពេញរបស់ថតនោះ (ចាប់ផ្តើមដោយដ្រាយ ដូចជា `D:\` ឬដោយ `/`) ហើយចុច Enter ឬចុច **[en:tran:Choose a folder]** ហើយជ្រើសវា។ ថតដែលបានវាយ ហើយមិនទាន់មាន នឹងត្រូវបានសួរជាមុនសិន (**[en:tran:Create Data Folder]**) ហើយត្រូវបានបង្កើតតែពេលចុច **[en:tran:Create]** ប៉ុណ្ណោះ៖ ការលុបប្រអប់ឱ្យទទេ មិនប្តូរអ្វីទេ។ កម្មវិធីសួរ **[en:tran:Set according paths]** តែម្តង ហើយ **[en:tran:Yes]** បង្កើតថតស្តង់ដារ (ឯកសារ វីដេអូ រូបភាព និងថតផ្សេងទៀត) នៅក្នុងវា ប្រើពួកវា ហើយផ្ទុកឡើងវិញ។ អ្វីដែលអ្នកមានរួចហើយ មិនត្រូវបានផ្លាស់ទីទេ។ វានៅតែនៅក្នុងថតចាស់ ដែល **[en:tran:Recent Folders]** ខាងក្រោមនាំអ្នកត្រឡប់ទៅវិញ ឬការបម្រុងទុកមួយនាំវាមកជាមួយ (W-25)។
