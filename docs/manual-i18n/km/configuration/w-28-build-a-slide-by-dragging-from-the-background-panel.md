# W-28 — បង្កើតស្លាយដោយអូសពីផ្ទាំងផ្ទៃខាងក្រោយ

**គោលដៅ:** ដាក់រូបភាព វីដេអូ ចម្រៀង គេហទំព័រ កាមេរ៉ា ឬពណ៌ លើស្លាយ ដោយមិនបាច់ដើររកក្នុងម៉ឺនុយ Insert — គ្រាន់តែអូសវាចេញពីផ្ទាំងដែលអ្នកកំពុងមើលស្រាប់។

**លក្ខខណ្ឌជាមុន:** ឯកសារស្លាយមួយបើកក្នុង **[en:tran:Slide Editor]** ហើយផ្ទាំង **[en:tran:Background]** នៅខាងក្រោម កំពុងបង្ហាញ។

1. ជ្រើសថេបមួយក្នុងផ្ទាំង **[en:tran:Background]** នៅខាងក្រោម — **[en:tran:Colors]**, **[en:tran:Images]**, **[en:tran:Videos]**, **[en:tran:Cameras]** ឬ **[en:tran:Webs]**។ នៅចុងខាងស្ដាំនៃជួរដដែលនោះ **[en:tran:Audios]** បើកបញ្ជីសំឡេងនៅក្បែរពួកវា។ 📸
2. អូសធាតុមួយចេញពីផ្ទាំង ហើយសង្កត់វាពីលើផ្ទាំងក្រណាត់។ ផ្ទាំងក្រណាត់នឹង **ស្រអាប់បន្តិច** ដើម្បីបង្ហាញថា វានឹងទទួលយកការទម្លាក់នោះ។ (វានៅភ្លឺដដែល សម្រាប់អ្វីដែលវាមិនអាចប្រើបាន — ឧទាហរណ៍ ខគម្ពីរមួយ។) 📸
3. លែងដៃ។ ប្រអប់មួយនឹងលេចឡើង **ចំកណ្ដាលកន្លែងដែលអ្នកបានទម្លាក់វា**៖

4. **ពណ៌គឺជាករណីពិសេស។** ទម្លាក់ពណ៌មួយ **ពីលើប្រអប់ដែលមានស្រាប់** នោះវានឹង **លាបពណ៌ប្រអប់នោះឡើងវិញ** — គ្មានប្រអប់ថ្មីត្រូវបានបន្ថែមទេ។ ទម្លាក់វាលើ **ផ្ទាំងក្រណាត់ទទេ** នោះអ្នកនឹងទទួលបានចតុកោណពណ៌ថ្មីមួយជំនួសវិញ។ ចតុកោណនោះ តាមពិតជាប្រអប់អត្ថបទធម្មតា ដូច្នេះអ្នកអាចចុចពីរដងលើវា ហើយវាយអក្សរចូលនៅពេលក្រោយ។ ប្រអប់ដែល **ចាក់សោ** (🔒) រក្សាពណ៌របស់វា៖ កម្មវិធីនឹងប្រាប់ថា _ធាតុនេះត្រូវបានចាក់សោ_ ហើយមិនបន្ថែមអ្វីទេ — សូមដោះសោវាជាមុនសិន។ 📸
5. អ្វីៗដែលអ្នកទម្លាក់ចូល គឺជាប្រអប់ធម្មតា៖ ផ្លាស់ទីវា ប្ដូរទំហំវា ប្ដូរលំដាប់វា ហើយ **[en:tran:Undo]** (Ctrl+Z) នឹងដកវាចេញវិញភ្លាម។ រក្សាទុកដោយ **Ctrl+S**។

ព័ត៌មានជំនួយ៖

- ការទម្លាក់លើប្រអប់ មានន័យតែចំពោះ **ពណ៌** ប៉ុណ្ណោះ។ ប្រភេទផ្សេងទៀតទាំងអស់ នឹងចូលជាប្រអប់ថ្មី នៅកន្លែងដែលទ្រនិចកណ្ដុរនៅ ពីលើអ្វីក៏ដោយដែលនៅខាងក្រោម។
- នេះគឺជាការអូសដូចគ្នានឹងការកំណត់ផ្ទៃខាងក្រោយអេក្រង់ដែរ — ធាតុក្នុងផ្ទាំងមិនផ្លាស់ប្ដូរទេ អ្នកគ្រាន់តែធ្វើច្បាប់ចម្លងរបស់វាលើស្លាយប៉ុណ្ណោះ។
- ប្រអប់កាមេរ៉ាចងចាំថា **កាមេរ៉ាណា** តាមឈ្មោះ ក៏ដូចជាតាមលេខសម្គាល់ ដូច្នេះវានៅតែរកឃើញឧបករណ៍ត្រឹមត្រូវ បន្ទាប់ពីបើកកម្មវិធីឡើងវិញ។
