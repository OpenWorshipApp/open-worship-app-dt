# W-19 — គូរ និងបញ្ចាំងពន្លឺលើកម្មវិធីខ្លួនឯង (ការគ្រប់គ្រងការបង្ហាញ)

**គោលដៅ:** គូសចំណាំលើ **បង្អួចកម្មវិធី** — មិនមែនអេក្រង់សម្រាប់អ្នកចូលរួមទេ — ពេលកំពុងបង្ហាញកម្មវិធីទៅអ្នកដទៃ (វគ្គបណ្ដុះបណ្ដាល ការចែករំលែកអេក្រង់ ម៉ាស៊ីនបញ្ចាំងដែលបង្ហាញដូចកុំព្យូទ័រយួរដៃរបស់អ្នក)។ អេក្រង់សម្រាប់អ្នកចូលរួម មានឧបករណ៍គូរ និងផ្ដោតផ្ទាល់ខ្លួន នៅលើកាតអេក្រង់តូច (W-10)។ នេះគឺជាឧបករណ៍ពីរដដែលនោះ ដែលចង្អុលទៅលើកម្មវិធីវិញ។

1. បើកម៉ឺនុយ **Tools** → **[en:tran:Start Controlling]** ឬចុច **Ctrl+Shift+P** ជំនួសវិញ (**⌘+Shift+P** នៅលើ Mac) — មួយណាក៏បាន។ **គ្រប់បង្អួចរបស់កម្មវិធីឆ្លើយតបនឹងវា** — ធ្វើបទបង្ហាញ អានព្រះគម្ពីរ កែសម្រួលស្លាយ កំណត់ត្រាព្រះគម្ពីរ ការកំណត់ កម្មវិធីកែសម្រួលទំព័របណ្ដាញ កម្មវិធីកែសម្រួលទំនុកច្រៀង និងចែករំលែកតាមបណ្ដាញមូលដ្ឋាន — ហើយបង្អួចដែលអ្នកកំពុងមើល គឺជាបង្អួចដែលទទួលបានផ្ទាំងនោះ។ (បង្អួចបញ្ចេញទៅម៉ាស៊ីនបញ្ចាំង ប្រអប់ About និងរបារស្វែងរក (Find) ចេតនាមិនឆ្លើយតបទេ៖ ការគ្របពីលើអ្វីដែលក្រុមជំនុំមើលឃើញ គឺជាកន្លែងតែមួយគត់ ដែលរឿងនេះមិនត្រូវលេចឡើងដាច់ខាត។) របារម៉ឺនុយត្រូវបានលាក់ នៅលើបង្អួចតូចៗ ដូច្នេះផ្លូវកាត់ គឺជាផ្លូវចូលនៅទីនោះ។
   ផ្ទាំងអណ្ដែត **[en:tran:Presenting Control]** មួយនឹងលេចឡើង — អូសវាដោយរបារចំណងជើង ប្ដូរទំហំវាពីគែម ឬជ្រុងណាក៏បាន ចុចពីរដងលើរបារចំណងជើង ដើម្បីឱ្យវាពេញបង្អួច (ហើយចុចពីរដងម្ដងទៀត ដើម្បីដាក់វាត្រឡប់វិញ) ហើយបង្រួមវាដោយសញ្ញាព្រួញ នៅពេលឧបករណ៍ដែលមានការកំណត់កំពុងបង្ហាញ។ វាបើកម្ដងទៀត នៅកន្លែង និងតាមរបៀបដែលអ្នកបានទុកវាចុងក្រោយ។ 📸
2. **របារចំណងជើង** មានអ្វីៗទាំងអស់ដែលអ្នកត្រូវប្រើ ពេលកំពុងបង្ហាញ៖ ឧបករណ៍បួននៅខាងឆ្វេង បន្ទាប់មកកុងតាក់ **ការបង្ហាញគ្រាប់ចុច** (W-20) និង **[en:tran:Undo]** / **[en:tran:Redo]** / **[en:tran:Clear drawing]** នៅខាងស្ដាំ។ មានតែការកំណត់ប៉ុណ្ណោះ ដែលនៅក្នុងតួផ្ទាំង ដូច្នេះការបង្រួមផ្ទាំងដោយសញ្ញាព្រួញ នៅតែទុកក្រុមនីមួយៗឱ្យនៅជិតដៃ ត្រឹមតែការចុចម្ដង — រមូរវាឡើង ដើម្បីដករបាររំកិលចេញពីផ្លូវ ហើយបន្តគូរ។
3. ផ្ទាំងបើកឡើងលើឧបករណ៍ **ព្រួញ** — កម្មវិធីនៅតែអាចប្រើបានពេញលេញ ហើយអ្វីដែលបានគូររួច នៅតែមើលឃើញពីលើវា។ ព្រួញគ្មានការកំណត់ផ្ទាល់ខ្លួនទេ ដូច្នេះពេលនៅលើវា ផ្ទាំងនេះ **គ្រាន់តែជារបារចំណងជើងរបស់វា**៖ គ្មានតួទទេដែលនៅពីលើកម្មវិធី ដែលអ្នកទើបតែសុំយកមកវិញទេ ហើយក៏គ្មានសញ្ញាព្រួញដែរ ព្រោះគ្មានអ្វីត្រូវរមូរឡើង។ ជ្រើសជក់ ជ័រលុប ឬពន្លឺបញ្ចាំង ហើយតួផ្ទាំងនឹងបើកម្ដងទៀត តាមទំហំដែលអ្នកបានទុកវាចុងក្រោយ។
4. ចុច **ជក់** ដើម្បីគូរ។ ស៊ុមពណ៌បៃតងខៀវស្ដើងមួយជុំវិញបង្អួច បង្ហាញថាកម្មវិធីលែងទទួលការចុចហើយ។ អូសនៅកន្លែងណាក៏បាន ដើម្បីគូរ។ ជ្រើស **[en:tran:Color]**, **[en:tran:Size]** (`[` / `]`) និង **[en:tran:Opacity]** (`-` / `=`) ហើយប្ដូររចនាប័ទ្មខ្សែ ដោយ **[en:tran:Straight]** (`S`), **[en:tran:3D]** (`3`) ឬ **[en:tran:Dots]** (`D`)។ **[en:tran:HQ]** (`Q`) ប្ដូរភាពរលោង យកល្បឿនវិញ សម្រាប់ម៉ាស៊ីនខ្សោយ។ 📸
5. ចុច **ជ័រលុប** ដើម្បីលុបផ្នែកខ្លះនៃគំនូរ ហើយប្រើ **[en:tran:Undo]** / **[en:tran:Redo]** (`Ctrl+Z` / `Ctrl+Shift+Z`) នៅលើរបារចំណងជើង ដើម្បីថយក្រោយ ឬ **[en:tran:Clear drawing]** ពណ៌ក្រហម (`C`) ដើម្បីលុបវាទាំងអស់ — ការចុចត្រឡប់ក្រោយម្ដង នាំការលុបដែលចុចខុសមកវិញ។ ប៊ូតុងទាំងបីនឹងប្រែពណ៌ប្រផេះ ពេលគ្មានអ្វីត្រូវត្រឡប់ក្រោយ ធ្វើឡើងវិញ ឬលុប ហើយគ្រាប់ចុចទាំងបី ដំណើរការពីឧបករណ៍ណាមួយដែល **កំពុងប្រើ** (ជក់ ជ័រលុប ឬពន្លឺបញ្ចាំង) និងពេលផ្ទាំង **ត្រូវបានបង្រួម**។ នៅលើឧបករណ៍ព្រួញ គ្រាប់ចុចទាំងនោះទៅកម្មវិធីវិញ ហើយមានតែប៊ូតុងប៉ុណ្ណោះ ដែលធ្វើសកម្មភាពលើគំនូរ។
6. ចុច **ពន្លឺបញ្ចាំង** ដើម្បីធ្វើឱ្យកម្មវិធីទាំងមូលស្រអាប់ លើកលែងតែរង្វង់មួយ។ ក្នុង **[en:tran:Follow]** (លំនាំដើម) រង្វង់គ្រាន់តែតាមទ្រនិចរបស់អ្នក។ ចុចប៊ូតុង **[en:tran:Follow]** នោះផ្ទាល់ (`H`) ហើយវានឹងប្ដូរទៅជា **[en:tran:Hold]** ដែលធ្វើឱ្យស្រអាប់ តែពេលអ្នកសង្កត់ប៊ូតុងកណ្ដុរប៉ុណ្ណោះ។ **[en:tran:Contrast]** (`X`) បញ្ច្រាសវា — រង្វង់ក្លាយជាតំបន់ដែលត្រូវបាំងវិញ។ ទំហំ **[en:tran:Dim color]** កម្រិតស្រអាប់ និង **ភាពព្រិលគែម** (`,` / `.`) សុទ្ធតែមានរបាររំកិល។ 📸
7. **កាមេរ៉ា** នៅចុងរបារចំណងជើង ថតរូបកម្មវិធី **ដូចដែលវាមើលទៅឥឡូវនេះ** — រួមទាំងគំនូរ និងពន្លឺបញ្ចាំងរបស់អ្នក — ហើយសួរថាត្រូវធ្វើអ្វីជាមួយរូបនោះ៖ **[en:tran:Ask the assistant about this]** បើកបង្អួចជំនួយ ដែលមានរូបភាពភ្ជាប់រួចហើយ ដូច្នេះការសួរថា "នេះជាអ្វី?" គ្រាន់តែចុចម្ដង និងសរសេរមួយប្រយោគ។ **[en:tran:Copy]** ដាក់វាក្នុងក្ដារតម្បៀតខ្ទាស់។ **[en:tran:Save into your images]** ដាក់វាក្នុងថតរូបភាពផ្ទៃខាងក្រោយ ដែលពីទីនោះ វាអាចត្រូវបានបង្ហាញដូចរូបភាពផ្សេងទៀតដែរ។ បង្អួចជំនួយខ្លួនវា មិនដែលលេចឡើងក្នុងរូបថតទេ ទោះបីជាវានៅពីលើកម្មវិធីក៏ដោយ។ 📸
8. ចុច **Escape** (ឬចុចព្រួញ) ដើម្បីប្រគល់កម្មវិធីមកវិញ ខណៈដែលនៅរក្សាគំនូរលើអេក្រង់។ ផ្លាស់ទីផ្ទាំង ប្រសិនបើវាបាំងអ្វីដែលអ្នកកំពុងចង្អុល។
9. ចុច **✕** នៅក្បាលផ្ទាំង ដើម្បីបញ្ចប់។ គំនូរត្រូវបានបោះបង់ចោល៖ វាមិនត្រូវបានរក្សាទុក ពីវគ្គមួយទៅវគ្គមួយទេ។ **Ctrl+Shift+P** និង **Tools → [en:tran:Start Controlling]** ដើរតួជាកុងតាក់បិទបើក៖ ចុចម្ដងទៀត ពេលផ្ទាំងកំពុងបើក វានឹងបិទផ្ទាំងនោះ — ហើយគំនូរក៏ទៅជាមួយដែរ ដូចការចុច **✕** ដែរ។ ពេលឧបករណ៍គូរកំពុងប្រើ ផ្លូវកាត់នេះមិនធ្វើអ្វីទេ — ក្ដារចុចជារបស់ការគូរនៅពេលនោះ៖ ចុច **Escape** ជាមុនសិន ឬប្រើធាតុម៉ឺនុយ ដែលបិទផ្ទាំងទោះក្នុងករណីណាក៏ដោយ។

> ចំណាំ៖ ផ្ទាំងនេះកាន់ក្ដារចុច តែពេលឧបករណ៍មួយ **កំពុងប្រើ** ប៉ុណ្ណោះ — គឺពេលដដែលដែលវាកាន់ទ្រនិចកណ្ដុរ។ នៅលើឧបករណ៍ **ព្រួញ**
> កម្មវិធីរក្សាគ្រាប់ចុចទាំងអស់ដែលវាមានជាធម្មតា (Enter និង Escape របស់ការស្វែងរកព្រះគម្ពីរ `F5`–`F10`, `Ctrl+B`, `Ctrl+Z` ការប្ដូរស្លាយ)
> ខណៈដែល `V` `B` `E` `F` `K` នៅតែអាចជ្រើសឧបករណ៍បាន។ អ្វីដែលកំពុងកាន់ក្ដារចុច នៅតែឈ្នះ ពោលគឺអក្សរឧបករណ៍ផ្ដល់ផ្លូវឱ្យ ពេលអ្នកកំពុងវាយក្នុងប្រអប់
> និងពេលស្រទាប់គូរ/ពន្លឺបញ្ចាំងផ្ទាល់ របស់ការមើលអេក្រង់ជាមុនមួយ កំពុងត្រូវបានជ្រើស។ ដាក់ឧបករណ៍មួយឱ្យដំណើរការ ហើយស្ថានភាពនឹងបញ្ច្រាស៖
> ស្រទាប់គ្របនោះគ្រប **បង្អួចទាំងមូល** ហើយកម្មវិធីមិនទទួល **អ្វីទាំងអស់** — មិនទាំងការចុច មិនទាំងគ្រាប់ចុច។ គ្រប់ការចុចគ្រាប់ចុច ត្រូវបានលេបចោល
> មុនពេលកម្មវិធីឃើញវា សូម្បីតែគ្រាប់ចុចធម្មតាដែលគ្មានមុខងារអ្វី៖ ការវាយអក្សរមិនទៅណាទេ `Space` និងព្រួញឈប់រមូរ `Tab` ឈប់ផ្លាស់ទីពីប្រអប់មួយទៅប្រអប់មួយ
> ហើយប្រអប់សន្ទនានៅពីក្រោយស្រទាប់គ្រប នៅស្ងៀម។ មានតែគ្រាប់ចុចផ្ទាល់របស់ផ្ទាំងប៉ុណ្ណោះ ដែលនៅដំណើរការ (`V` `B` `E` `F`, `Escape`,
> `Ctrl+Z` / `Ctrl+Shift+Z` / `C` ដែលឥឡូវធ្វើសកម្មភាពលើ **គំនូរ**) រួមទាំងអ្វីដែលវាយក្នុងរបាររំកិល និងប្រអប់ពណ៌របស់ផ្ទាំងផ្ទាល់។
> Escape ឬឧបករណ៍ព្រួញ ប្រគល់អ្វីៗទាំងអស់មកវិញភ្លាម។ **ប៊ូតុង** ត្រឡប់ក្រោយ / ធ្វើឡើងវិញ / លុបគំនូរ ដំណើរការនៅគ្រប់ឧបករណ៍ទាំងអស់ មិនថាករណីណាក៏ដោយ។
