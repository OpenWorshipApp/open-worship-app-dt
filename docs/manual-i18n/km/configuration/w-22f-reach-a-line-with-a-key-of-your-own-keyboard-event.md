# W-22f — ទៅដល់បន្ទាត់មួយដោយគ្រាប់ចុចដែលអ្នកកំណត់ខ្លួនឯង (ព្រឹត្តិការណ៍ក្តារចុច)

**គោលដៅ:** ផ្លូវកាត់មួយ ដែលបញ្ជូនការដំណើរការតារាងកម្មវិធីទៅបន្ទាត់មួយ ហើយដាក់បន្ទាត់នោះ — និងអ្វីៗទាំងអស់ដែលភ្ជាប់ជាមួយវា — លើអេក្រង់ក្នុងពេលតែមួយ មិនថាការដំណើរការបានទៅដល់ត្រង់ណាក៏ដោយ។

1. **ទៅដល់បន្ទាត់មួយដោយគ្រាប់ចុចផ្ទាល់ខ្លួនរបស់អ្នក។** **[en:tran:Keyboard Event]** គឺជាផ្លូវកាត់ដែលអ្នកកំណត់ដោយខ្លួនឯង។ បន្ថែមវាពីម៉ឺនុយនៃតារាងកម្មវិធី (ចុចកណ្ដុរស្ដាំលើតារាងកម្មវិធីខ្លួនវាផ្ទាល់ → **[en:tran:Add Action]** → **[en:tran:Keyboard Event]**)៖ វានឹងសួររកផ្លូវកាត់ ហើយអ្នកឆ្លើយដោយ **ចុចផ្លូវកាត់នោះ** — មិនមែនវាយអក្សរចូលក្នុងប្រអប់ទេ។ សង្កត់ **Ctrl** ឬ **Shift** (មានតែគ្រាប់ចុចទាំងពីរនេះប៉ុណ្ណោះ ហើយយ៉ាងហោចណាស់មួយក្នុងចំណោមវា ដើម្បីឱ្យផ្លូវកាត់មានន័យដូចគ្នានៅលើម៉ាស៊ីនណាក៏ដោយ ហើយមិនអាចយកគ្រាប់ចុចដែលតារាងកម្មវិធីប្រើរួចហើយ) រួចចុចគ្រាប់ចុចនោះ។ បន្ទាប់មក បន្ទាត់នោះនឹងសរសេរថា **⌨ [en:tran:Keyboard Event] (Shift+A)**។ ក្រោយមក អ្នកអាចកំណត់វាឡើងវិញពី **[en:tran:Change Shortcut]**។ បន្ទាត់ពីរមិនអាចប្រើផ្លូវកាត់តែមួយបានទេ — បន្ទាត់ទីពីរនឹងត្រូវបដិសេធ ដោយមានសារប្រាប់យ៉ាងច្បាស់ — ហើយការចម្លងបន្ទាត់មួយ ធ្វើឱ្យច្បាប់ចម្លងនោះគ្មានផ្លូវកាត់។ 📸
2. **ភ្ជាប់អ្វីដែលវាគួរដាក់បង្ហាញ ហើយទុកផ្ទាំងមើលជាមុនឲ្យបើក៖ គ្រាប់ចុចដំណើរការតែពេលវាបើកប៉ុណ្ណោះ។** ចុចកណ្ដុរស្ដាំលើបន្ទាត់ថ្មីនោះ → **[en:tran:Add CC Elements]** — ច្រើនប៉ុន្មានក៏បាន ហើយនេះហើយដែលធ្វើឱ្យគ្រាប់ចុចមួយមានតម្លៃជាងការចុចម្ដង៖ ឧទាហរណ៍ ស្លាយមួយ _និង_ អក្សររត់របស់វាជាមួយគ្នា។ បន្ទាប់មក ពេលផ្ទាំងមើលជាមុនកំពុងបើក (W-22b) ការចុច **Shift+A** នឹងបញ្ជូនការដំណើរការទៅបន្ទាត់នោះ ហើយដាក់អ្វីៗទាំងអស់នោះលើអេក្រង់ក្នុងពេលតែមួយ មិនថាការដំណើរការបានទៅដល់ត្រង់ណាក៏ដោយ។ ភ្ជាប់បន្ទាត់នោះទៅអេក្រង់មួយ ដោយប្រើ **[en:tran:Set Specific Screen]** ប្រសិនបើវាគួរតែទៅអេក្រង់ដដែលជានិច្ច។ ផ្លូវកាត់នេះឆ្លើយតប តែពេលផ្ទាំងមើលជាមុនកំពុងកាន់ក្ដារចុចប៉ុណ្ណោះ ដូចគ្រាប់ចុចព្រួញរបស់វាដែរ — ផ្ទាំងនោះយកក្ដារចុចភ្លាមៗ ពេលអ្នកបើកវា ដូច្នេះមិនចាំបាច់ចុចអ្វីជាមុនទេ។ បើមិនទាន់មានអ្វីភ្ជាប់ទេ វានឹងប្រាប់អ្នក ជាជាងនៅស្ងៀមមិនធ្វើអ្វីសោះ។ 📸
