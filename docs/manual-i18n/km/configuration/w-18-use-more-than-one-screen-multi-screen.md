# W-18 — ប្រើអេក្រង់ច្រើនជាងមួយ (អេក្រង់ច្រើន)

**គោលដៅ:** បញ្ចាំងខ្លឹមសារផ្សេងៗគ្នា (ឬដូចគ្នា) ទៅកាន់ម៉ូនីទ័រច្រើន។

1. **ចុចកណ្ដុរស្ដាំ** លើកន្លែងទំនេរនៃផ្ទាំងអេក្រង់តូច ហើយជ្រើស **[en:tran:Add New Screen]** — កាតមើលជាមុនទីពីរលេចឡើង ដោយមានលេខ និងពណ៌ផ្ទាល់ខ្លួនរបស់វា។ 📸
2. ចង្អុលកាតថ្មីទៅម៉ូនីទ័រដែលវាត្រូវបញ្ចាំង ដោយ **ប៊ូតុងម៉ូនីទ័រ** នៅបាតកាតរបស់វា (W-10) រួចបើកវាដោយប៊ូតុងបង្ហាញ/លាក់ផ្ទាល់ខ្លួនរបស់វា។ កាតនីមួយៗក៏មានប៊ូតុងសម្អាត ការផ្លាស់ប្តូរ និងការចាក់សោ ផ្ទាល់ខ្លួនរបស់វាដែរ។
3. ខ្លឹមសារទៅកាន់គ្រប់អេក្រង់ដែល **បានជ្រើសរើស**។ ដើម្បីឲ្យអេក្រង់មួយឈប់ទទួលខ្លឹមសារ ដោយមិនលុបវាចោល ចុចកណ្ដុរស្ដាំលើកាតរបស់វា ហើយជ្រើស **[en:tran:Deselect]** ហើយ **[en:tran:Select]** នៅកន្លែងដដែល យកវាមកវិញ។ **[en:tran:Solo]** ធ្វើរឿងផ្សេង។ វាធ្វើឲ្យកាតនោះជាកាតតែមួយគត់ដែលបានជ្រើសរើស ដូច្នេះអេក្រង់ផ្សេងទៀតទាំងអស់ឈប់ទទួល។ អេក្រង់ដែលមិនបានជ្រើសរើស រក្សាអ្វីដែលវាបានបង្ហាញចុងក្រោយ ហើយនោះ ឬធាតុដែលបានទម្លាក់លើកាតតែមួយ (ជំហានទី 4) ជាហេតុដែលអេក្រង់ពីរអាចបង្ហាញរបស់ផ្សេងគ្នា។ ជ្រើសរើសគ្រប់កាត — ចុចកណ្ដុរស្ដាំលើកាតដែលមិនទាន់បានជ្រើស ហើយជ្រើស **[en:tran:Select]** — ហើយបង្ហាញធាតុនោះម្ដងទៀត ដើម្បីដាក់របស់ដូចគ្នានៅលើអេក្រង់ទាំងអស់។
4. អ្នកក៏អាច **អូស** ស្លាយ ធាតុផ្ទៃខាងក្រោយ ឬប៊ូតុងបង្ហាញរបស់ផ្ទៃខាងមុខ ហើយ **ទម្លាក់វាលើកាតជាក់លាក់មួយ** ដើម្បីបង្ហាញវានៅលើអេក្រង់នោះតែមួយ។ 📸
5. បទគម្ពីរដែលបង្ហាញច្រើនកំណែ ត្រូវបានគូរជាជួរឈរមួយសម្រាប់កំណែនីមួយៗ ហើយជួរឈរទាំងនោះទៅជាមួយគ្នា៖ រំកិលជួរឈរមួយនៅលើកាត — ដោយកង់កណ្ដុរ របាររំកិលរបស់វា ឬប៊ូតុងរំកិលស្វ័យប្រវត្តិ — ហើយជួរឈរផ្សេងទៀតនឹងរំកិលទៅខគម្ពីរដដែល ទាំងនៅលើអេក្រង់ដែលកាតនោះបង្ហាញផងដែរ។ ដើម្បីតម្រៀបកំណែទាំងនោះខមួយៗ ជាជួរដេក ចុចកណ្ដុរស្ដាំលើកាតរបស់អេក្រង់ដែលកំពុងបង្ហាញវា ហើយជ្រើស **[en:tran:Set Line Sync]** — អេក្រង់មួយគឺគ្រប់គ្រាន់ ហើយអេក្រង់ដែលកំពុងបង្ហាញរួចហើយ ទទួលជួរដេកទាំងនោះ តែពេលវាត្រូវបានលាក់ ហើយបង្ហាញម្ដងទៀតប៉ុណ្ណោះ — ហើយ **[en:tran:Unset Line Sync]** ត្រឡប់ទៅជួរឈរវិញ។ ការរំកិលរបស់វា ធ្វើតាមកាតជានិច្ច។
6. ចុចកណ្ដុរស្ដាំលើកាត → **[en:tran:Delete]** ដើម្បីលុបអេក្រង់ដែលអ្នកលែងត្រូវការ (អេក្រង់មួយមិនអាចលុបបានទេ ពេលវាជាអេក្រង់តែមួយគត់)។
