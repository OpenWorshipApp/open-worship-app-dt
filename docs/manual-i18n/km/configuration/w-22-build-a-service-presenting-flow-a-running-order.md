# W-22 — រៀបចំតារាងកម្មវិធីសម្រាប់ការថ្វាយបង្គំ (លំដាប់កម្មវិធី)

**គោលដៅ:** ប្រមូលអ្វីៗទាំងអស់ដែលកម្មវិធីថ្វាយបង្គំមួយត្រូវការ — ចម្រៀង ស្លាយ ខគម្ពីរ ផ្ទៃខាងក្រោយ និងការកំណត់ផ្ទៃខាងមុខដែលរៀបចំទុកជាមុន — ចូលទៅក្នុងតារាងកម្មវិធីតែមួយ ដែលអ្នកអាចធ្វើតាមម្ដងមួយៗ ពេលកម្មវិធីកំពុងប្រព្រឹត្តទៅ។

1. រកផ្ទាំង **[en:tran:Presenting Flows]** — វាជាបញ្ជីខាងក្រោម ក្នុងចំណោមបញ្ជីទាំងពីរនៅខាងឆ្វេង នៅក្រោម **[en:tran:Documents]**។ ប្រសិនបើបញ្ជីទទេ ចុចកណ្ដុរស្ដាំលើកន្លែងទំនេររបស់វា (ឬប្រើប៊ូតុង **⋮ [en:tran:More Options]** នៅលើរបារចំណងជើងរបស់វា) → **[en:tran:New File]** ដើម្បីបង្កើតមួយ។ 📸
2. **អូសអ្វីៗទៅលើជួរឈ្មោះរបស់តារាងកម្មវិធី ដើម្បីបន្ថែមវា។** ជួរឈ្មោះ គឺជាជួរផ្ទាល់របស់តារាងកម្មវិធីនៅក្នុងបញ្ជី — ជួរដែលមានឈ្មោះរបស់វានៅលើ។ មិនមែនកន្លែងទំនេរនៃបញ្ជីទេ ហើយក៏មិនមែនបន្ទាត់មួយ នៅក្នុងតារាងកម្មវិធីដែលកំពុងបើកដែរ (ការទម្លាក់លើ _បន្ទាត់_ មួយ ធ្វើរឿងផ្សេង — វាភ្ជាប់៖ សូមមើល W-22g)។ ដូច្នេះ ដើម្បីបន្ថែមចម្រៀង ឬខគម្ពីរ៖ ចាប់ជួររបស់វា — នៅក្នុងបញ្ជីឯកសារ ឬនៅក្នុងបញ្ជីព្រះគម្ពីរ — អូសវាទៅបញ្ជីតារាងកម្មវិធី ហើយលែងវានៅលើជួរដែលបង្ហាញឈ្មោះតារាងកម្មវិធី។ វាត្រូវបានបន្ថែមនៅខាងចុង។ អ្វីៗដែលអ្នកអាចបង្ហាញបាន អាចដាក់ចូលបាន៖
   - **ផ្ទៃខាងក្រោយ** — ពណ៌ រូបភាព វីដេអូ កាមេរ៉ា ឬគេហទំព័រ។
   - **ឯកសារ** — ឯកសារស្លាយ ឬ **ចម្រៀង** (ចម្រៀងក៏ជាឯកសារដែរ)៖ អូសជួររបស់វាចេញពីបញ្ជីឯកសារ។
   - **ស្លាយតែមួយ** — ពីកម្មវិធីមើលជាមុន ឬពីឯកសារដែលមាននៅក្នុងតារាងកម្មវិធីរួចហើយ។
   - **ខគម្ពីរ** — ពីបញ្ជីព្រះគម្ពីរ។
   - **ការកំណត់ផ្ទៃខាងមុខដែលរៀបចំទុក** — អូសប៊ូតុងពណ៌ខៀវ **[en:tran:Show Marquee Top]** / **[en:tran:Start Countdown]** / **[en:tran:Show Time]** ខ្លួនឯង។ អ្វីដែលអ្នកបានវាយ និងរចនា នឹងទៅជាមួយវា ដូច្នេះតារាងកម្មវិធីចងចាំការប្រកាស _នោះ_ មិនមែនគ្រាន់តែ "អក្សររត់មួយ" ទេ។ 📸
   - **បទសំឡេង** — អូសវាចេញពីផ្នែក **[en:tran:Audios]**។
3. ចុចឈ្មោះតារាងកម្មវិធី ដើម្បី **បើកវា**។ ធាតុនីមួយៗជាបន្ទាត់ខ្លីមួយ៖ រូបតំណាងបង្ហាញថាវាជាអ្វី លេខសម្គាល់ (id) របស់វា និងឈ្មោះរបស់វា។ បន្ទាត់ **ឯកសារ** មានព្រួញផ្ទាល់ខ្លួននៅចុងខាងឆ្វេងរបស់វា — ចម្រៀងក៏ជាឯកសារដែរ។ ចុចលើ **ព្រួញ** មិនមែនលើបន្ទាត់ទេ ដើម្បីមើលស្លាយរបស់ឯកសារនោះនៅខាងក្រោម។ ការចុចលើបន្ទាត់ខ្លួនឯង បើកឯកសារនោះក្នុងកម្មវិធីមើលជាមុន។ 📸
4. **បន្ទាត់ចម្រៀង ឬឯកសារ បើកផ្ទាំងមើលជាមុនរបស់វា។** ដើម្បីបង្ហាញស្លាយមួយរបស់វា ចុចស្លាយនោះក្នុងផ្ទាំងមើលជាមុន ឬចុចព្រួញរបស់ឯកសារដើម្បីពង្រីក រួចចុចស្លាយមួយនៅខាងក្រោម។ **បទសំឡេង** បើកផ្នែក **[en:tran:Audios]** ហើយធ្វើឱ្យបទនោះភ្លឹបភ្លែតនៅទីនោះ។ ប្រើប៊ូតុងចាក់ក្នុងផ្ទាំងនោះដើម្បីចាក់វា។ ចុច **ស្លាយតែមួយ** ខគម្ពីរ ផ្ទៃខាងក្រោយ ឬការកំណត់ផ្ទៃខាងមុខដែលរៀបចំទុក ដើម្បីដាក់វាលើអេក្រង់។ អ្នកក៏អាច **អូសធាតុមួយទៅលើអេក្រង់តូច** ឬ **ចុចកណ្ដុរស្ដាំ → [en:tran:Show on Screens]** ដើម្បីជ្រើសអេក្រង់។
5. ចុចកណ្ដុរស្ដាំលើធាតុមួយ សម្រាប់ **[en:tran:Move up]** / **[en:tran:Move down]**, **[en:tran:Choose Color]** ដើម្បីដាក់តារាងកម្មវិធីរបស់អ្នកជាក្រុមតាមពណ៌ ឬ **[en:tran:Remove from Presenting Flow]**។ ដើម្បីផ្លាស់ទីបន្ទាត់មួយទៅឆ្ងាយ ប្រើ **[en:tran:Move to Top]** ឬ **[en:tran:Move to Bottom]** ជំនួសឲ្យការចុច **[en:tran:Move up]** ម្ដងហើយម្ដងទៀត — បន្ទាត់នោះលោតទៅចុងនោះភ្លាម ហើយអ្វីៗផ្សេងទៀត រក្សាលំដាប់របស់វា។ (បន្ទាត់ដែលនៅខាងលើគេរួចហើយ មិនមានជម្រើស **[en:tran:Move up]** ឬ **[en:tran:Move to Top]** ទេ ហើយបន្ទាត់ដែលនៅខាងក្រោមគេរួចហើយ មិនមានជម្រើស **[en:tran:Move down]** ឬ **[en:tran:Move to Bottom]** ទេ។) **[en:tran:Duplicate]** ដាក់ច្បាប់ចម្លងនៃបន្ទាត់នោះ **នៅខាងក្រោមវាភ្លាម** ដោយមានពណ៌របស់វា អេក្រង់ដែលបានខ្ទាស់ និងស្លាយដែលបានទុកមួយឡែករបស់វា នៅលើច្បាប់ចម្លងរួចជាស្រេច — ជាវិធីរហ័សដើម្បីច្រៀងចម្រៀងមួយពីរដង ក្នុងកម្មវិធីថ្វាយបង្គំតែមួយ បន្ទាប់មកប្តូរតែច្បាប់ទីពីរ។ ច្បាប់ទាំងពីរដាច់ដោយឡែកពីគ្នា ចាប់ពីពេលនោះទៅ៖ ការទុកមួយឡែក ឬការប្តូរពណ៌មួយ មិនប៉ះពាល់មួយទៀតទេ។ 📸 អ្នកក៏អាចអូសបន្ទាត់មួយឡើងលើ ឬចុះក្រោម **នៅក្នុងតារាងកម្មវិធីដដែល** (ការអូសបន្ទាត់ទៅក្នុងតារាងកម្មវិធី _ផ្សេង_ មិនធ្វើអ្វីទេ — សូមបន្ថែមវានៅទីនោះ ពីបញ្ជីផ្ទាល់របស់វាជំនួសវិញ)។ ពណ៌បង្ហាញជាឆ្នូតតាមបណ្ដោយគែមខាងឆ្វេងនៃបន្ទាត់ និងចំណុចមួយនៅចុងខាងស្ដាំរបស់វា។ បន្ទាត់ទាំងនោះនៅតាមលំដាប់តារាងកម្មវិធីរបស់អ្នក — វាមិនដែលត្រូវបានតម្រៀបឡើងវិញជាក្រុមពណ៌ទេ ព្រោះលំដាប់ _គឺជា_ អត្ថន័យនៅទីនេះ។ ពណ៌ជារបស់តារាងកម្មវិធីនោះតែមួយ ដូច្នេះចម្រៀងដដែល អាចត្រូវបានសម្គាល់ខុសគ្នា នៅក្នុងកម្មវិធីថ្វាយបង្គំពីរ។ ការផ្លាស់ប្តូរត្រូវបានរក្សាទុកភ្លាមៗ ពេលអ្នកធ្វើ — **គ្មានប៊ូតុងរក្សាទុក** នៅកន្លែងណាមួយក្នុងផ្ទាំងនេះទេ។
6. អ្វីដែល **កំពុងនៅលើអេក្រង់ឥឡូវនេះ** ត្រូវបានសម្គាល់ដោយ `●` ពណ៌ស្វាយក្រហម (magenta) — នៅលើធាតុខ្លួនឯង នៅលើឯកសារដែលវាជាផ្នែក នៅលើតារាងកម្មវិធី និងនៅលើក្បាល **[en:tran:Presenting Flows]** — ដូច្នេះអ្នកអាចមើលឃើញភ្លាមៗ ថាអ្នកនៅត្រង់ណាក្នុងតារាងកម្មវិធី។
7. មិនប្រាកដថា "5.jpg" មួយណា ដែលបន្ទាត់មួយសំដៅទៅ? ចុចកណ្ដុរស្ដាំលើវា → **[en:tran:Reveal Original]** — កម្មវិធីរំកិលទៅធាតុពិតនៅកន្លែងផ្សេងក្នុងបង្អួច ហើយធ្វើឲ្យវាភ្លឹបភ្លែត។ រឿងនេះក៏ដំណើរការលើស្លាយ នៅក្នុងឯកសារដែលបានបើកដែរ។ ពណ៌ ឬកាមេរ៉ា គ្មានធាតុដើមសម្រាប់ចង្អុលទៅទេ ហើយផ្ទាំងដែលមានធាតុដើម ត្រូវតែបើករួចជាស្រេច។

**តើតារាងកម្មវិធីអាចធ្វើអ្វីទៀតបាន** — នីមួយៗមានទំព័រផ្ទាល់ខ្លួន៖

- ដំណើរការពីផ្ទាំងអណ្ដែតតែមួយ ដោយប្រើក្ដារចុច (W-22b)។
- មានបន្ទាត់ដែលលុបអ្វីៗចេញពីអេក្រង់ ឬបង្ហាញ ឬលាក់អេក្រង់ (W-22c)។
- រង់ចាំលើបន្ទាត់មួយ ហើយបន្ទាប់មកបន្តទៅមុខដោយខ្លួនឯង (W-22d) វិលជុំសំណុំស្លាយមួយ ឬលោតត្រឡប់ក្រោយ (W-22e) ឆ្លើយតបនឹងគ្រាប់ចុចដែលអ្នកកំណត់ខ្លួនឯង (W-22f)។
- ធ្វើឲ្យបន្ទាត់មួយ នាំបន្ទាត់ផ្សេងទៀតឡើងមកជាមួយ (W-22g) ឬចាក់វីដេអូនៅក្នុងស្លាយ (W-22h)។
- បញ្ជូនបន្ទាត់មួយទៅអេក្រង់ជាក់លាក់មួយរាល់ពេល ឬទុកបន្ទាត់មួយមួយឡែក (W-22i)។
- ត្រូវបានប្រគល់ទៅម៉ាស៊ីនផ្សេង ជាឯកសារតែមួយ (W-22j)។
