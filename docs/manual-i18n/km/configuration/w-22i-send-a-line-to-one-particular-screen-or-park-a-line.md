# W-22i — ផ្ញើធាតុមួយ ទៅអេក្រង់ជាក់លាក់មួយ ឬផ្អាកធាតុមួយ

**គោលដៅ:** ទំនុកច្រៀងដែលតែងតែទៅអេក្រង់សម្រាប់វេទិកា ដោយមិនចាំបាច់អូសវាទៅទីនោះ និង
ធាតុដែលអ្នកមិនអាចប្រតិបត្តិដោយចៃដន្យបាន។

1. **ផ្ញើធាតុមួយ ទៅអេក្រង់ជាក់លាក់មួយ រាល់ពេល។** ប្រសិនបើទំនុកច្រៀងមួយ តែងតែស្ថិតនៅលើ
   អេក្រង់សម្រាប់វេទិកា ហើយស្លាយធម្មទេសនា នៅលើអេក្រង់ធំ អ្នកមិនចាំបាច់អូសពួកវាទៅទីនោះ
   ម្តងហើយម្តងទៀតទេ។ ចុចកណ្ដុរស្ដាំលើធាតុ → **[en:tran:Set Specific Screen]** ហើយ
   ធីកអេក្រង់ដែលវាគួរទៅ — `Screen id: 0`, `Screen id: 1`, … ម៉ឺនុយនៅតែបើក
   ដូច្នេះអ្នកអាចធីកច្រើនជាងមួយ ហើយធាតុនោះ បន្ទាប់មកបង្ហាញ 📌 តូចមួយ ជាមួយលេខទាំងនោះ —
   **លេខនីមួយៗ ក្នុងពណ៌អេក្រង់ផ្ទាល់របស់វា** ពណ៌ដូចគ្នាទាំងស្រុង នឹងស្លាកអេក្រង់តូចរបស់អេក្រង់នោះ
   ដូច្នេះអ្នកអាចដឹងភ្លាមៗថា ធាតុមួយទៅណា ដោយមិនចាំបាច់អានលេខ។
   (ប្រអប់ធីកក្នុងម៉ឺនុយ ក៏មានពណ៌ដូចគ្នាដែរ។) 📸
   ចាប់ពីពេលនោះ **ការចុចធាតុនោះ មិនខ្វល់ពីអេក្រង់តូចណាដែលត្រូវបានជ្រើសរើសទេ**
   ហើយទៅអេក្រង់ផ្ទាល់របស់វាតែម្តង។ គ្រាប់ចុចព្រួញ/Space នៅក្នុងផ្ទាំងមើលជាមុន ក៏ដូចគ្នាដែរ។ ដោះធីក
   ពួកវាចេញ ឬជ្រើសរើស **[en:tran:No Specific Screen]** ដើម្បីប្រគល់វាទៅ
   ឥរិយាបថធម្មតាវិញ។

   របស់ពីរ នៅតែឈ្នះលើការខ្ទាស់ដោយចេតនា ដូច្នេះអ្នកមិនដែលជាប់គាំងទេ: **ការអូស**
   ធាតុទៅលើអេក្រង់តូចមួយ ដាក់វានៅលើអេក្រង់ _នោះ_ សម្រាប់តែម្តងនេះ ហើយចុចកណ្ដុរស្ដាំ →
   **[en:tran:Show on Screens]** នៅតែសួរថា អ្នកចង់បានអេក្រង់ណា។ ប្រសិនបើអេក្រង់ដែលបានខ្ទាស់ ត្រូវបាន
   បិទ គ្មានអ្វីត្រូវបានបញ្ចាំងនៅកន្លែងណាទេ ហើយកម្មវិធីប្រាប់អ្នកដូច្នោះ
   («សូមប្រាកដថាអេក្រង់ត្រូវបានបើក») ជាជាងប្រើអេក្រង់ផ្សេងដោយស្ងាត់ៗ។
2. ធាតុ **ឯកសារ** ក៏អាចខ្ទាស់បានដែរ — ស្លាយទាំងអស់របស់វា បន្ទាប់មកធ្វើតាមវា — ហើយអ្នកអាចខ្ទាស់
   **ស្លាយមួយដោយឡែក**: បើកសញ្ញាព្រួញរបស់ឯកសារ ចុចកណ្ដុរស្ដាំលើស្លាយ ហើយកំណត់
   អេក្រង់របស់វា។ ស្លាយនោះឈ្នះលើឯកសារ។ ស្លាយជិតខាងរបស់វា នៅតែធ្វើតាមឯកសារ។
   ស្លាយដែលបានខ្ទាស់ដោយខ្លួនវាផ្ទាល់ បង្ហាញ 📌 នៅលើបន្ទាត់ផ្ទាល់របស់វា
   **និងនៅជ្រុងខាងក្រោមស្ដាំ នៃរូបតូចរបស់វា នៅក្នុងផ្ទាំងមើលជាមុន** ដូច្នេះតារាងកម្មវិធីដែលអ្នកកំពុងអានជា
   រូបភាព នៅតែប្រាប់អ្នកថា ស្លាយណាបំបែកចេញពីឯកសាររបស់វា។ ការដកវាចេញ ប្រគល់
   ស្លាយនោះទៅឯកសារវិញ ជាជាងខ្ទាស់វាទៅគ្មានអ្វីសោះ។ ការចុចកណ្ដុរស្ដាំដដែល
   មាននៅលើរូបតូចស្លាយ នៅក្នុងផ្ទាំងមើលជាមុនដែរ។
3. **ផ្អាកធាតុដែលអ្នកមិនចង់ឲ្យប៉ះ។** ធាតុដែលអ្នកអាចចុចដោយចៃដន្យ — ខគម្ពីរ
   ជំនួស សេចក្តីជូនដំណឹងសប្តាហ៍មុន ចម្រៀងដែលអ្នកប្រហែលជាទៅដល់ ឬមិនទៅដល់ — អាចត្រូវបានដកចេញ
   ពីតារាងកម្មវិធី ដោយមិនលុបវាចោល: ចុចកណ្ដុរស្ដាំលើវា → **[en:tran:Disable]**។ ធាតុនោះស្រអាប់ សរសេរជាអក្សរទ្រេត **ត្រូវបានគូសឆូត** ហើយមាន
   🚫 ពណ៌លឿងទុំតូចមួយ នៅចុងខាងស្ដាំរបស់វា ហើយចាប់ពីពេលនោះ **ការចុចវា មិនធ្វើអ្វីទាល់តែសោះ** — គ្មានអ្វី
   ត្រូវបានបញ្ចាំងទេ ហើយធាតុឯកសារ ក៏មិនបើកដែរ។ ការអូសវាទៅលើអេក្រង់តូចមួយ មិនដាក់អ្វីនៅទីនោះទេ
   ហើយគ្រាប់ចុចព្រួញ/Space នៅក្នុងផ្ទាំងមើលជាមុន រំលងវាត្រង់ៗ។ ចុចកណ្ដុរស្ដាំ →
   **[en:tran:Enable]** ដាក់វាត្រឡប់មកវិញ។ (ខណៈធាតុមួយត្រូវបានផ្អាក ម៉ឺនុយរបស់វាដក
   **[en:tran:Show on Screens]** ចេញ — ជម្រើសដែលលែងអាចធ្វើអ្វីបានទៀត — ប៉ុន្តែអ្វីៗផ្សេងទៀត
   នៅដដែល ដូច្នេះអ្នកនៅតែអាចប្ដូរពណ៌វា ផ្លាស់ទីវា ឬបើកវាឡើងវិញ។) 📸
   អ្នកអាចផ្អាក **ស្លាយមួយនៃឯកសារ** តាមរបៀបដដែល: បើកសញ្ញាព្រួញរបស់ឯកសារ ហើយ
   ចុចកណ្ដុរស្ដាំលើស្លាយ។ ផ្អាក **ឯកសារខ្លួនឯង** ហើយគ្រប់ស្លាយនៅក្រោមវា ត្រូវបានផ្អាក
   ជាមួយ។ ធាតុដែលបានផ្អាក នៅតែអាចអូសឡើងចុះ ដើម្បីរៀបចំតារាងកម្មវិធីរបស់អ្នក ហើយ
   ការផ្អាកត្រូវបានចងចាំ តែក្នុងតារាងកម្មវិធីនោះប៉ុណ្ណោះ — ចម្រៀងដដែល នៅតែដំណើរការក្នុងពិធី
   ផ្សេងទៀតរបស់អ្នក។
4. **ធាតុពណ៌ប្រផេះមានពីរប្រភេទ ហើយឥឡូវវាមើលទៅខុសគ្នា។** ធាតុដែល អ្នក បានផ្អាកនៅទីនេះ
   ត្រូវបានគូសឆូត ហើយមាន 🚫 ពណ៌លឿងទុំ ("ធាតុនេះត្រូវបានបិទនៅក្នុងតារាងកម្មវិធីនេះ")។ ស្លាយ
   ដែលពណ៌ប្រផេះ ព្រោះ **ឯកសារខ្លួនឯង** លាក់វា _មិន_ ត្រូវបានគូសឆូតទេ ហើយ
   មាន 👁‍🗨 ពណ៌ប្រផេះធម្មតា ("ធាតុនេះត្រូវបានបិទនៅក្នុងឯកសាររបស់វា") — ការចុចកណ្ដុរស្ដាំលើ
   វា នឹងមិននាំវាត្រឡប់មកវិញទេ ព្រោះតារាងកម្មវិធី មិនអាចបើកឡើងវិញនូវអ្វីដែលឯកសារ
   បានបិទទេ។ បើកឯកសារ ហើយបើកស្លាយនៅទីនោះ។ នៅក្នុងផ្ទាំងមើលជាមុន សញ្ញាទាំងពីរដដែល
   ស្ថិតនៅ **ជ្រុងខាងក្រោមឆ្វេង** នៃរូបតូចដែលស្រអាប់នីមួយៗ។ 📸
