# W-11 — អានព្រះគម្ពីរ (ការយោង ទំហំអក្សរ ប្រវត្តិ កំណែ)

**គោលដៅ:** រក និងអានខគម្ពីរមួយនៅក្នុងទំព័រអានព្រះគម្ពីរ — អានបានស៊ីជម្រៅជាងការស្វែងរករហ័ស ហើយជាកន្លែងដែលអ្នករកខគម្ពីរ នៅពេលអ្នកមិនកំពុងធ្វើបទបង្ហាញ។
**ទីតាំង:** ទំព័រ **[en:tran:Bible Reader]**។ បើអ្នកនៅទំព័រធ្វើបទបង្ហាញ សូមចុចថេប **[en:tran:Bible Reader]** នៅរបារខាងលើរបស់វា ដើម្បីមកទីនេះ; ទំព័រអានព្រះគម្ពីរផ្ទាល់គ្មានថេបនៅរបារខាងលើទេ។

1. នៅក្នុង **[en:tran:Bible Reader]** ចុចប្រអប់ **[en:tran:Bible Reference]** នៅខាងលើ។ បើវាមានការយោងរួចហើយ សូមចុច **[en:tran:Clear input]**។ ចុចកណ្ឌគម្ពីរ បន្ទាប់មកជំពូក បន្ទាប់មកខ ពីប៊ូតុងដែលលេចឡើង; បទគម្ពីរនឹងបើកឡើង។ នេះជាវិធីដែលគួរប្រើសម្រាប់ព្រះគម្ពីរដែលមិនមែនភាសាអង់គ្លេស ព្រោះប៊ូតុងទាំងនោះប្រើឈ្មោះ និងលេខផ្ទាល់របស់ព្រះគម្ពីរនោះ។ 📸

   **បទគម្ពីរដែលបន្តទៅជំពូកក្រោយៗនៃកណ្ឌគម្ពីរដដែល។** វាយខទីមួយ និងខចុងក្រោយរបស់វា ដោយមានជំពូករបស់ខនីមួយៗ៖ `John 1:50-6:3` គឺជាបទគម្ពីរតែមួយ ពី John 1:50 ដល់ John 6:3។ `John 1-3` យកជំពូក 1 ដល់ 3 ទាំងមូល `John 1:-2:` ចាប់ពី 1:1 ដល់ចុងជំពូក 2 ហើយសញ្ញាចុច (.) ធ្វើដូចសញ្ញាចុចពីរ (:) ដែរ (`យ៉ូហាន ១៨.៣៩-១៩.១៦`)។ ជំពូកនីមួយៗរបស់វា ចាប់ផ្ដើមនៅក្រោមបន្ទាត់មួយដែលមានលេខជំពូក `─ 2 ─────`។ បទគម្ពីរដែលលើសពីបីជំពូក បើកឡើងជាមួយជំពូកបីដំបូង និងប៊ូតុង **...** មួយនៅក្រោមពួកវា (**[en:tran:Show the next chapter]**)៖ ការចុចម្ដងៗ បន្ថែមជំពូកបន្ទាប់ ហើយប៊ូតុងនោះបាត់ទៅ នៅពេលជំពូកចុងក្រោយត្រូវបានបង្ហាញ។ 📸
   **បើកការយោងនៅក្នុងចំណងជើងផ្នែក។** ព្រះគម្ពីរខ្លះបោះពុម្ពការយោងនៅក្នុងចំណងជើងផ្នែករបស់វា — `(… យ៉ូហាន ១៨.៣៩-១៩.១៦)` នៅក្រោមចំណងជើងមួយនៃ Mark 15។ ចុចលើវា ហើយបទគម្ពីរទាំងមូលដែលវាសំដៅ គ្រប់ជំពូករបស់វា នឹងបើកក្នុងផ្ទាំងអណ្ដែតតូចមួយ; បទគម្ពីរដែលអ្នកកំពុងអាន នៅដដែល។
2. បើអក្សរតូចពេក សូមចុចសញ្ញា **⋯** តូច នៅជ្រុងខាងក្រោមខាងឆ្វេងនៃបទគម្ពីរ ដើម្បីបើកប៊ូតុងដែលលាក់។ បន្ទាប់មក ចុចសង្កត់លើរបាររំកិល **[en:tran:Font Size]** រំកិលវាទៅខាងស្ដាំ ហើយលែងដៃ នៅពេលអក្សរធំល្មម។
3. ដើម្បីអានព្រះគម្ពីរពីរកំណែនៅក្បែរគ្នា ក្នុងផ្ទាំងតែមួយ សូមចុច **[en:tran:Add Extra Bible]** នៅក្បែរឈ្មោះកំណែ រួចចុចកំណែដែលអ្នកចង់បាន។ 📸
4. **ផ្ទាំងដែលមានពណ៌ដូចគ្នា រំកិលជាមួយគ្នា។** នៅក្នុងទំព័រអានព្រះគម្ពីរ សូមចុចចំណុចនៅដើមក្បាលផ្ទាំងបទគម្ពីរ (**[en:tran:Color Note]**) ហើយជ្រើសពណ៌មួយ។ ដាក់កណ្ដុរលើក្បាលផ្ទាំងនោះ ដើម្បីឱ្យប៊ូតុងលេចឡើង ចុច **[en:tran:Split Horizontal to]** ឬ **[en:tran:Split Vertical to]** រួចជ្រើសកំណែព្រះគម្ពីរមួយទៀត។ ផ្ទាំងថ្មីចូលក្នុងក្រុមពណ៌ដូចគ្នា។ រំកិលផ្ទាំងណាមួយ៖ កំណែផ្សេងទៀតរំកិលតាមខដដែល។ បើវាមិនរំកិលតាមទេ សូមបើក **[en:tran:Sync group scrolling]** ដោយប្រើព្រួញឡើង/ចុះតូចៗ នៅក្រោមចំណុចពណ៌ផ្ទាល់។ រូបតំណាងពណ៌ រំកិលស្របគ្នា និងសំឡេង មើលទៅស្រអាប់ រហូតដល់អ្នកដាក់កណ្ដុរពីលើក្រុមរបស់វា ឬទៅដល់មួយក្នុងចំណោមវាដោយក្ដារចុច។ វាបើកតាំងពីដំបូង៖ រំកិលផ្ទាំងណាមួយ ហើយការបកប្រែផ្សេងទៀតរំកិលតាមវា យ៉ាងរលូន និងជាប់ៗគ្នា ដោយរក្សាខដដែលនៅកម្ពស់ដដែល។ នៅពេលវាទៅដល់ខាងលើ ឬខាងចុងនៃបទគម្ពីរ ផ្ទាំងផ្សេងទៀតក៏ទៅដល់ដែរ។ រំកិលផ្ទាំងមួយផ្សេងទៀតក្នុងក្រុម ដើម្បីឲ្យវាដឹកនាំ; ផ្ទាំងផ្សេងទៀតរំកិលតាមវាយ៉ាងរលូន ជំនួសឲ្យការលោតភ្លាមៗ។ ចុចព្រួញនៅក្នុងផ្ទាំងណាមួយក្នុងក្រុម ដើម្បីបិទការរំកិលតាមសម្រាប់ក្រុមនោះ; ការរំកិលបែបមុននៅដដែល។ ចុចម្ដងទៀតដើម្បីបើកវាវិញ៖ ក្រុមនោះនឹងរំកិលមកតម្រង់នឹងផ្ទាំងដែលអ្នកបានចុចភ្លាមៗ ដោយមិនចាំបាច់រំកិលម្ដងទៀត។ ជម្រើសនេះត្រូវបានចងចាំសម្រាប់ក្រុមពណ៌នោះ ហើយប៊ូតុងបិទ/បើកនេះ លេចឡើងតែនៅពេលក្រុមនោះមានផ្ទាំងយ៉ាងហោចណាស់ពីរប៉ុណ្ណោះ។
