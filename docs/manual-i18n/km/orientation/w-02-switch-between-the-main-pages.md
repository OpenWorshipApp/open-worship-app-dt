# W-02 — ប្ដូររវាងទំព័រសំខាន់ៗ

**គោលដៅ:** ផ្លាស់ទីរវាងទំព័រ ធ្វើបទបង្ហាញ អានព្រះគម្ពីរ និងកែសម្រួលស្លាយ។

1. ចុចថេបមួយនៅផ្នែកខាងលើ — បង្អួចនឹងប្ដូរទៅទំព័រនោះនៅនឹងកន្លែង។ ទំព័រនីមួយៗគ្មានថេបសម្រាប់ខ្លួនឯងទេ ហើយទំព័រអានព្រះគម្ពីរគ្មានថេបសោះ៖ ដើម្បីត្រឡប់មកវិញពីទំព័រនោះ សូមចុចប៊ូតុង 🖥️ **[en:tran:Go Back to Presenter]** របស់វា។
2. ថេប **[en:tran:Slide Editor]** បើកកម្មវិធីកែសម្រួល សម្រាប់តែឯកសារស្លាយដែលបានជ្រើសរើសប៉ុណ្ណោះ៖ សូមជ្រើសរើសឯកសារមួយក្នុងបញ្ជីខាងឆ្វេងជាមុនសិន (W-03) រួចចុចថេបនោះ។ បើមិនទាន់បានជ្រើសរើសអ្វីទេ កម្មវិធីនឹងបង្ហាញសារព្រមាន ("[en:tran:No slide selected]") ហើយនៅទំព័រដដែល។
