# W-01b — ប៊ូតុង `⋮`: អ្វីៗទាំងអស់ដែលធាតុមួយអាចធ្វើបាន

**គោលដៅ:** រកសកម្មភាពដែលពីមុនលាក់នៅពីក្រោយការចុចកណ្ដុរស្ដាំ។

ស្ទើរតែគ្រប់អ្វីៗក្នុងកម្មវិធី — ឯកសារមួយក្នុងបញ្ជី ខគម្ពីរមួយក្នុងបញ្ជីអានរបស់អ្នក
កំណត់ត្រាមួយ ស្លាយមួយ ផ្ទៃខាងក្រោយមួយ បន្ទាត់មួយនៃតារាងកម្មវិធី ការមើលអេក្រង់ជាមុនមួយ ថតមួយក្នុង
**[en:tran:Resources]** ប្រអប់មួយក្នុងក្រាហ្វទំនាក់ទំនង — អាចធ្វើអ្វីបានច្រើនជាងអ្វីដែលការចុចលើវា
ធ្វើ។ មុខងារបន្ថែមទាំងនោះស្ថិតនៅក្នុងម៉ឺនុយតូចមួយ។

1. មើលនៅចុងខាងស្ដាំនៃជួរ ឬជ្រុងខាងលើស្ដាំនៃកាត។ នៅទីនោះមាន **`⋮`** មួយដែលស្រាលខ្លាំង
   — ស្ងាត់ដូចចំណុចពណ៌សម្គាល់ដែលនៅក្បែរវា ហើយវាឡើងដិតពេញភ្លាម នៅពេលអ្នកដាក់កណ្ដុរលើវា។ ក្នុងបញ្ជីមួយ
   ពួកវាតម្រៀបជាជួរឈរត្រង់ចុះតាមគែមខាងស្ដាំ នីមួយៗស្មើនឹងជួរដែលវាជាកម្មសិទ្ធិ; ថតមួយមាន `⋮`
   ផ្ទាល់ខ្លួននៅលើឈ្មោះរបស់វា នៅក្បែរ `⋮` របស់ឯកសារដែលនៅខាងក្នុងវា។ 📸
2. **ចុចវា។** ម៉ឺនុយបើកនៅត្រង់ប៊ូតុងតែម្ដង — ជាម៉ឺនុយដូចគ្នានឹងម៉ឺនុយដែលអ្នកទទួលបានដោយ
   **ចុចកណ្ដុរស្ដាំ** លើជួរនោះផ្ទាល់ ដែលនៅតែដំណើរការដូចមុនទាំងស្រុង។
   ម៉ឺនុយរំកិលចូលមកក្នុងផ្ទៃដែលមើលឃើញ ហើយអាចប្រើកម្ពស់ពេញបង្អួច មិនថាអ្នកចុចនៅទីណាទេ។
   **ម៉ឺនុយវែងរំកិល តែនៅពេលវាខ្ពស់ជាងបង្អួចទាំងមូលប៉ុណ្ណោះ។** ធាតុរបស់វារំកិលនៅខាងក្នុងវា តែនៅពេលពួកវាលើសកម្ពស់បង្អួច
   ឬនៅពេលម៉ឺនុយមានដែនកំណត់កម្ពស់តូចជាងរបស់ខ្លួន។
   > ការចុច `⋮` មិនធ្វើអ្វីដែលការចុចលើជួរធ្វើ ក្នុងពេលតែមួយនោះទេ: ឯកសារដែលអ្នកបើកម៉ឺនុយលើវា
   > មិនត្រូវបានជ្រើសរើស ហើយស្លាយក៏មិនត្រូវបានផ្ញើទៅអេក្រង់ដែរ។
3. ជ្រើសធាតុមួយ ឬចុចកន្លែងផ្សេង ដើម្បីបិទម៉ឺនុយដោយមិនជ្រើសអ្វីទាំងអស់។

> **ហេតុអ្វីបានជាវានៅទីនោះ។** ការចុចកណ្ដុរស្ដាំមិនអាចធ្វើបាននៅលើអេក្រង់ប៉ះទេ ហើយម៉ាស៊ីន
> និងកម្មវិធីរុករកខ្លះ ទុកប៊ូតុងនោះសម្រាប់ម៉ឺនុយរបស់ខ្លួន។ `⋮` គឺជាម៉ឺនុយដដែលនោះ
