# W-43 — ដកចម្រៀង ឯកសារ ឬហ្វាល់ណាមួយចេញ (ផ្លាស់ទីទៅធុងសំរាម)

**គោលដៅ:** ដកហ្វាល់ដែលអ្នកលែងចង់បានចេញ — ចម្រៀង ឯកសារស្លាយ PDF រូបភាព ឬវីដេអូផ្ទៃខាងក្រោយ តារាងកម្មវិធី ឬកំណត់ត្រាព្រះគម្ពីរ — ដោយមិនបាត់បង់វាជារៀងរហូត។

គ្មានជួរហ្វាល់ណាមួយមាន **[en:tran:Delete]** ទេ។ ជួរហ្វាល់នីមួយៗមាន **[en:tran:Move to Trash]** ជំនួសវិញ ហើយវាធ្វើដូចឈ្មោះរបស់វាមែន៖ ហ្វាល់នោះទៅកាន់ធុងសំរាម (Recycle Bin) របស់កុំព្យូទ័រអ្នកផ្ទាល់ (Trash នៅលើ Mac) ដែលអ្នកអាចយកវាមកវិញបាន បើអ្នកប្ដូរចិត្ត។

1. រកជួរនោះនៅក្នុងបញ្ជីរបស់វា — ចម្រៀង ឬឯកសារស្លាយ នៅក្នុង **[en:tran:Documents]** រូបភាព ឬវីដេអូ នៅក្នុងផ្ទាំង **[en:tran:Background]** តារាងកម្មវិធី នៅក្នុង **[en:tran:Presenting Flows]**។ 📸
2. ចុចកណ្ដុរស្ដាំលើជួរនោះ ឬចុចសញ្ញា **⋮** ដែលមើលឃើញស្រអាប់ៗ នៅចុងខាងស្ដាំរបស់វា (W-01b)។ ម៉ឺនុយរបស់ជួរនោះនឹងបើកឡើង។
3. ជ្រើសរើស **[en:tran:Move to Trash]** — ធាតុចុងក្រោយគេ ដែលមានរូបធុងសំរាមពណ៌ក្រហម។ 📸
4. បង្អួចតូចមួយសួរថា **[en:tran:Moving File to Trash]** — _តើអ្នកពិតជាចង់ផ្លាស់ទី "…" ទៅធុងសំរាម?_ ចុច **[en:tran:Yes]**។ (**[en:tran:No]** ទុកអ្វីៗនៅដដែល។)
   USB នៅលើ Windows គ្មានធុងសំរាម (Recycle Bin) ទេ៖ នៅទីនោះ បង្អួចទីពីរ
   **[en:tran:Delete Permanently]** សួរថា តើត្រូវលុបហ្វាល់នោះចោលជារៀងរហូតជំនួសវិញឬទេ —
   ការនោះមិនអាចត្រឡប់វិញបានទេ ហើយ **[en:tran:Cancel]** រក្សាវាទុក។
5. ជួរនោះបាត់ពីបញ្ជី។ ហ្វាល់នោះ ព្រមទាំងហ្វាល់តូចៗនៅក្បែរវា ដែលចងចាំផ្ទៃខាងក្រោយ និងការផ្លាស់ប្តូររបស់វា ស្ថិតនៅក្នុងធុងសំរាម (Recycle Bin / Trash) — សូមបើកវាពីផ្ទៃតុ (desktop) របស់អ្នក ដើម្បីយកវាមកវិញ។

**រកមិនឃើញ?** ធាតុផ្ទៃខាងក្រោយដែល **កំពុងនៅលើអេក្រង់ឥឡូវនេះ** គ្មាន **[en:tran:Move to Trash]** នៅក្នុងម៉ឺនុយរបស់វាទេ — សូមលុបវាចេញពីអេក្រង់ជាមុនសិន (**[en:tran:Clear Background]** នៅលើផ្ទាំងអេក្រង់តូច, W-10) រួចសាកម្ដងទៀត។ ស្លាយ "នៅក្នុង" ឯកសារមួយ មិនមែនជាហ្វាល់ទេ៖ ដើម្បីដកវាចេញ សូមបើកឯកសារនោះក្នុង **[en:tran:Slide Editor]** ហើយចុចកណ្ដុរស្ដាំលើស្លាយនោះក្នុងបញ្ជីខាងឆ្វេង (W-15)។ ហ្វាល់នៅក្នុងផ្ទាំង **[en:tran:Resources]** គ្មានធាតុនោះទាល់តែសោះ៖ សូមដកវាចេញពីថតរបស់វា នៅលើកុំព្យូទ័ររបស់អ្នក។
