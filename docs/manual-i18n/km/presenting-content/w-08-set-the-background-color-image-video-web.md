នៅក្បែរវា (**[en:tran:Thumbnail View]**) ប្ដូរត្រឡប់មកវិញ។ 📸 បញ្ជីនេះបង្ហាញឈ្មោះពេញរបស់ឯកសារនីមួយៗ (ជាមួយកន្ទុយរបស់វា) អេក្រង់ណាខ្លះដែលវា
