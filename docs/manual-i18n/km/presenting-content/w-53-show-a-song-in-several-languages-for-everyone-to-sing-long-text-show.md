# W-53 — បង្ហាញចម្រៀងជាច្រើនភាសា ដើម្បីឱ្យគ្រប់គ្នាច្រៀងជាមួយគ្នា (ការបង្ហាញអត្ថបទវែង)

**គោលដៅ:** ដាក់អត្ថបទមួយ — ជាធម្មតាជាចម្រៀង — លើអេក្រង់ជាពីរភាសា ឬច្រើនជាងនេះ នៅក្បែរគ្នា ដោយផ្នែកនីមួយៗនៅក្បែរការបកប្រែរបស់វា ហើយឱ្យវារមូរទៅ ពេលអ្នកទាំងអស់គ្នាកំពុងច្រៀង។

**វិធីលឿនបំផុតសម្រាប់ចម្រៀងមួយ:** ចុចកណ្ដុរស្ដាំលើចម្រៀងនោះ ក្នុងបញ្ជី **ឯកសារ** ហើយជ្រើស **[en:tran:Long Text Show]**។ ផ្ទាំងនឹងបើកលើវគ្គថ្មីមួយ ដែលដាក់ឈ្មោះតាមចម្រៀងនោះ ហើយមានចម្រៀងនោះជាកាត **EN** ដែលអានចេញពី **[en:tran:Lyric File]** របស់វា ហើយ **[en:tran:Show Long Text]** អាចចុចបានភ្លាម នៅពេលកាតនោះបានអានចម្រៀងរួច — បន្តនៅជំហាន 5 ឬនៅជំហាន 2 ដើម្បីដាក់ការបកប្រែនៅក្បែរវា។ ការចុចម្ដងៗ បង្កើតវគ្គមួយទៀត។ វគ្គដែលអ្នកលែងត្រូវការ អាចលុបចេញពីម៉ឺនុយនៃថេបរបស់វា។

1. បើកថេប **[en:tran:Foreground]** ហើយជ្រើស **[en:tran:Long Text Show]** ក្នុងម៉ឺនុយ។ ផ្ទាំងរបស់វានឹងបើកឡើង។
2. **បន្ថែមភាសា។** ចុច **[en:tran:Add Language]** ហើយជ្រើសមួយ។ ចុចវាម្ដងទៀត សម្រាប់ភាសាបន្ទាប់។ ភាសានីមួយៗមានកាតផ្ទាល់ខ្លួន ដែលដាក់ឈ្មោះតាមកូដរបស់វា (KM, EN) ហើយភាសាមួយអាចមាននៅក្នុងបញ្ជីបានតែម្ដងប៉ុណ្ណោះ។ កាតខាងលើបង្អស់ គឺជាជួរឈរខាងឆ្វេងនៅលើអេក្រង់។ ព្រួញនៅលើកាតមួយ ផ្លាស់ទីកាតនោះ ហើយ ✕ របស់វា ដកភាសានោះចេញ។
3. **ផ្ដល់ពាក្យឱ្យភាសានីមួយៗ** តាមវិធីមួយក្នុងចំណោមពីរ ដែលជ្រើសនៅលើកាតរបស់វា៖
   - **[en:tran:Raw Text]** — វាយ **[en:tran:Title]** បន្ទាប់មកប្រអប់មួយសម្រាប់ផ្នែកនីមួយៗ (ឃ្លាមួយ បន្ទរមួយ)។ **[en:tran:Add Section]** បន្ថែមប្រអប់បន្ទាប់។ ✕ នៅក្បែរប្រអប់មួយ លុបប្រអប់នោះចេញ ហើយព្រួញផ្លាស់ទីវា។ ការចុះបន្ទាត់ក្នុងប្រអប់ គឺជាការចុះបន្ទាត់នៅលើអេក្រង់។
   - **[en:tran:Lyric File]** — ចុច **[en:tran:Choose Lyric]** ហើយជ្រើសចម្រៀងមួយ ក្នុងបញ្ជីឯកសាររបស់អ្នក។ បន្ទាប់មក កាតនឹងបង្ហាញចំណងជើងចម្រៀង និងចំនួនផ្នែកដែលវាច្រៀង។ ពាក្យទាំងនោះមកពីចម្រៀង តាមលំដាប់ដែលវា **ត្រូវបានច្រៀង** ដូច្នេះបន្ទរដែលច្រៀងបីដង នឹងមាននៅទីនោះបីដង។ អាកូដត្រូវបានទុកចោល ហើយផ្នែកដែលមានអាកូដ តែគ្មានពាក្យ (ភ្លេងបើក ភ្លេងសុទ្ធ) ក៏ត្រូវបានទុកចោលដែរ។
4. **ភាសាទាំងអស់ត្រូវតែត្រូវគ្នា។** រហូតដល់ពួកវាត្រូវគ្នា **[en:tran:Show Long Text]** នៅតែមិនអាចចុចបាន ហើយផ្ទាំងប្រាប់ពីចំណុចដំបូងដែលមិនត្រូវគ្នា៖ ភាសាដែលវាយផ្ទាល់ ត្រូវមានចំនួនផ្នែកស្មើគ្នា ហើយគ្មានផ្នែកណាទទេ ហើយចម្រៀងពីរ ត្រូវមានផ្នែកដូចគ្នា តាមលំដាប់ដូចគ្នា។ វាអានដូចនេះ៖ _ចំរៀងទាំងនេះមានរចនាសម្ព័ន្ធមិនដូចគ្នា: 1. KM Verse 1 ≠ EN Intro_។
5. ធីកអេក្រង់ក្នុងផ្ទាំងអេក្រង់តូច ហើយចុច **[en:tran:Show Long Text]**។ ភាសានីមួយៗ គឺជាជួរឈរមួយនៅក្រោមចំណងជើងរបស់វា ហើយផ្នែកនីមួយៗ គឺជាជួរដេកមួយដែលមានលេខ ដូច្នេះឃ្លាមួយនៅក្បែរការបកប្រែរបស់វា។ 📸
   វាជំនួសបទគម្ពីរ ឬស្លាយ នៅលើអេក្រង់នោះ។
6. **ឱ្យវារមូរ។** នៅលើកាតអេក្រង់តូច ចុចព្រួញទ្វេ នៅជ្រុងខាងក្រោមផ្នែកខាងស្ដាំនៃរូបភាព៖ អត្ថបទចាប់ផ្ដើមរំកិលឡើងលើដោយខ្លួនឯង នៅលើអេក្រង់ផងដែរ។
7. **លោតទៅផ្នែកមួយ។** កាតនីមួយៗរាយផ្នែករបស់វាជាប៊ូតុង — `1 Verse 1`, `2 Chorus` … នៅលើចម្រៀង ឬលេខផ្ទាល់របស់ផ្នែក នៅលើអត្ថបទដែលវាយផ្ទាល់។ ពេលអត្ថបទកំពុងនៅលើអេក្រង់ ចុចប៊ូតុងមួយ ហើយជួរនោះនឹងត្រូវបានសម្គាល់ស្រាលៗ ហើយនាំមកកណ្ដាលអេក្រង់ ក្នុងគ្រប់ភាសា។ ប៊ូតុងដែលអ្នកបានចុច នៅតែភ្លឺ នៅលើកាតរបស់គ្រប់ភាសា ដូច្នេះផ្ទាំងបង្ហាញថាចម្រៀងបានទៅដល់ណាហើយ។ បន្ទរដែលច្រៀងពីរដង មានប៊ូតុងពីរ ហើយប៊ូតុងនីមួយៗទៅជួររបស់វាផ្ទាល់។ នៅលើកាតរបស់ចម្រៀង ផ្នែកនីមួយៗចាប់ផ្ដើមជាកាតមួយ ដែលមានពាក្យរបស់ផ្នែកនោះ សរសេរបន្តគ្នាជាបន្ទាត់តែមួយ ដោយមានសញ្ញា / នៅចន្លោះបន្ទាត់នីមួយៗ សម្រាប់តាមដានចម្រៀងតាមពាក្យរបស់វា — ចុចកន្លែងណាក៏បាននៅលើកាតមួយ ដើម្បីនាំវាមកកណ្ដាល។ ប៊ូតុងទីមួយនៃជួរនោះ **[en:tran:View as Text Cards]** ប្ដូរកាតទាំងនោះទៅជាប៊ូតុងតូចៗ ដែលមានតែឈ្មោះផ្នែក ហើយប្ដូរត្រឡប់វិញ។ កាតនោះចងចាំថាអ្នកបានជ្រើសមួយណា។

   **ប្ដូរផ្នែកដោយគ្រាប់ចុច។** នៅពេលអ្នកបានចុចផ្នែកមួយ ប៊ូតុងរបស់វាទទួលគ្រាប់ចុច ដូចស្លាយដែរ៖ **Space**, **→**, **↓** ឬ **Page Down** ចុចប៊ូតុងរបស់ផ្នែកបន្ទាប់ ហើយ **Shift+Space**, **←**, **↑** ឬ **Page Up** ចុចប៊ូតុងមុន។ ពន្លឺ និងគ្រាប់ចុច ផ្លាស់ទីទៅជាមួយវា នៅលើកាតដែលអ្នកបានចុច ដូច្នេះអ្នកអាចតាមដានចម្រៀងពីក្ដារចុច ឬពីឧបករណ៍បញ្ជាពីចម្ងាយ។ វាឈប់នៅផ្នែកចុងក្រោយ និងនៅផ្នែកដំបូង៖ វាមិនដែលវិលត្រឡប់ទៅដើមវិញទេ។ ផ្នែកដែលមិនភ្លឺ រក្សាគ្រាប់ចុចរបស់វាផ្ទាល់ — **Space** ចុចផ្នែកនោះ។
8. **ផ្ដល់រូបរាងផ្ទាល់ខ្លួនដល់ភាសាមួយ។** បើក **[en:tran:Properties]** នៅលើកាតរបស់វា៖ **[en:tran:Font Family]**, **[en:tran:Text Color]**, **[en:tran:Text Size (%)]** (ទំហំរបស់វាធៀបនឹងភាសាផ្សេងទៀត — 80 ធ្វើឱ្យវាតូចជាងបន្តិច) និង **[en:tran:Text Align]**។ ការផ្លាស់ប្ដូរមួយ ទៅដល់អត្ថបទដែលកំពុងបង្ហាញ ប្រហែលកន្លះវិនាទី បន្ទាប់ពីអ្នកឈប់កែ។ អ្វីដែលអ្នកមិនប៉ះ នឹងធ្វើតាមរចនាប័ទ្មអត្ថបទព្រះគម្ពីររបស់អេក្រង់ផ្ទាល់។
9. **ប្ដូរពាក្យ។** កែសម្រួលកាតមួយ ហើយចុច **[en:tran:Show Long Text]** ម្ដងទៀត៖ អ្វីដែលនៅលើអេក្រង់ គឺជាអត្ថបទដូចដែលវាមាន នៅពេលអ្នកចុចចុងក្រោយ។
10. **ដកវាចេញ។** **[en:tran:Hide Long Text]** នៅក្បែរប៊ូតុងបង្ហាញ ឬ **[en:tran:Clear Long Text]** (ប៊ូតុង **LT**) ឬ **[en:tran:Clear Foreground]** (**FG**) នៅលើកាតអេក្រង់តូច។
