# W-10 — គ្រប់គ្រងអ្វីដែលអ្នកទស្សនាឃើញ (អេក្រង់តូច + ប៊ូតុងលុប)

**គោលដៅ:** គ្រប់គ្រងអ្វីដែលកំពុងបញ្ចាំងផ្ទាល់ ពីកាតមើលជាមុនរបស់អេក្រង់។

- ផ្ទាំង **អេក្រង់តូច** (ជួរឈរខាងស្ដាំ ផ្នែកខាងក្រោម) បង្ហាញដូចអ្វីដែលអ្នកទស្សនាឃើញ; របាររំកិលពង្រីក/បង្រួមនៅក្រោមវា គ្រាន់តែប្ដូរទំហំការមើលជាមុនរបស់អ្នកប៉ុណ្ណោះ មិនមែនអ្វីដែលបញ្ចាំងចេញទេ។ 📸
- នៅពីក្រោយអ្វីៗទាំងអស់ដែលកាតនោះគូរ គឺ **រូបផ្ទៃតុ (wallpaper) ផ្ទាល់របស់ម៉ូនីទ័រនោះ**។ អេក្រង់អ្នកទស្សនាជាបង្អួចថ្លា ដូច្នេះកន្លែងណាដែលអ្នកមិនបានដាក់អ្វីបង្ហាញ នេះពិតជាអ្វីដែលអ្នកក្នុងបន្ទប់នឹងឃើញមែន។ ចុចកណ្ដុរស្ដាំលើកន្លែងទទេនៃផ្ទាំងអេក្រង់តូច (ឬចុច **⋮** នៅជ្រុងខាងក្រោមខាងស្ដាំរបស់វា) → **[en:tran:Show Monitor Wallpaper]** ដើម្បីបិទវា ហើយដាក់លំនាំក្រឡាអុកធម្មតាមកវិញ — ប៉ុណ្ណឹងគឺគ្រប់គ្រាន់ហើយ។ **[en:tran:Refresh Preview]** នៅក្នុងម៉ឺនុយដដែល គឺសម្រាប់រឿងផ្សេង៖ វាអានរូបផ្ទៃតុឡើងវិញ បន្ទាប់ពីអ្នកប្ដូររូបផ្ទៃតុរបស់អ្នក។ ម៉ាស៊ីនដែលមិនប្រាប់ថារូបផ្ទៃតុរបស់វាជាអ្វី នឹងរក្សាលំនាំក្រឡាអុកដដែល។
- អេក្រង់នីមួយៗមានកាតមើលជាមុនផ្ទាល់ខ្លួន ដែលមាន **របារខាងលើ** និង **របារខាងក្រោម** នៃប៊ូតុងបញ្ជា៖
- **បង្ហាញ / លាក់អេក្រង់** (របារខាងលើ ឆ្វេងបំផុត — ឬចុច **F5**)៖ បើក ឬបិទការបញ្ចាំងទៅម៉ូនីទ័រពិត។ ប៊ូតុងបិទ/បើកនេះ ធ្វើការលើអេក្រង់របស់វាផ្ទាល់; **F5** ធ្វើការលើអេក្រង់ដែល **បានជ្រើសរើស** (អេក្រង់ទាំងអស់ បើគ្មានអេក្រង់ណាត្រូវបានជ្រើសរើស) ហើយប្ដូរពួកវាទាំងអស់ទៅតាមរបៀបតែមួយ៖ បើក តែនៅពេលពួកវាទាំងអស់បិទ បើមិនដូច្នោះទេ បិទទាំងអស់។ អេក្រង់ដែលមិនបានជ្រើសរើសនៅដដែល ពេលមានអេក្រង់ផ្សេងទៀតត្រូវបានជ្រើសរើស។ រូបតំណាងនឹងពេញ ហើយភ្លឺជាងមុន ពេលកំពុងបង្ហាញ។ វាគឺជាប៊ូតុងដែលមានឈ្មោះ **[en:tran:Toggle showing screen]** — សូមនិយាយពាក្យទាំងនេះ ពេលប្រាប់អ្នកណាម្នាក់ថាត្រូវចុចមួយណា ព្រោះមានរបស់ផ្សេងទៀតជាច្រើនក្នុងបង្អួចនេះ ក៏មានឈ្មោះថា "បង្ហាញ" ដែរ។ 📸
- **លាក់អេក្រង់ទាំងអស់។** នៅក្នុងផ្ទាំងអេក្រង់តូចរបស់ទំព័រធ្វើបទបង្ហាញ (ខាងក្រោមស្ដាំ) សូមពិនិត្យ
  កាតអេក្រង់ទាំងអស់ រួមទាំងកាតដែលមិនបានជ្រើសរើស។ នៅលើកាតនីមួយៗដែលប៊ូតុង
  **[en:tran:Toggle showing screen]** ឆ្វេងបំផុតនៃរបារខាងលើ មានរូបពេញ ហើយភ្លឺ សូមចុចវាម្ដង
  ដើម្បីលាក់អេក្រង់នោះ; ទុកប៊ូតុងដែលមិនភ្លឺនៅដដែល។ ពេលប៊ូតុងទាំងអស់នោះមិនភ្លឺ
  អេក្រង់ទាំងអស់ត្រូវបានលាក់ ហើយខ្លឹមសាររបស់វានៅរក្សាទុក។ **F5** បិទ/បើកអេក្រង់ដែលបានជ្រើសរើស ដូច្នេះសូមប្រើប៊ូតុងនីមួយៗទាំងនេះ ដើម្បីលាក់អេក្រង់ទាំងអស់ដោយសុវត្ថិភាព។
- **ប៊ូតុងលុប** (របារខាងលើ — ប៊ូតុងនីមួយៗក៏មានគ្រាប់ចុចមុខងារមួយដែរ)៖ **លុបទាំងអស់ `F6` / BG `F7` / SL `F8` / LT `F9` / FG `F10`** ([en:tran:Clear All] / [en:tran:Clear Background] / [en:tran:Clear Slide] / [en:tran:Clear Long Text] / [en:tran:Clear Foreground])។ ប៊ូតុងមួយភ្លឺតែនៅពេលស្រទាប់របស់វាមានអ្វីដែលត្រូវលុប។ **LT** គឺជាស្រទាប់អត្ថបទវែង៖ បទគម្ពីរ ឬអត្ថបទរបស់ **[en:tran:Long Text Show]**។
- **ឈប់គូរការមើលជាមុន** (របារខាងលើ រូបភ្នែកនៅបន្ទាប់ពី **FG** — **[en:tran:Stop rendering preview]**)៖ សម្រាប់កុំព្យូទ័រយឺត។ ចុចវា ហើយកាតនោះឈប់គូរ៖ ផ្ទៃរបស់វាប្រែជាលំនាំឆ្នូតៗ ដែលសរសេរថា **[en:tran:No rendering]** ខណៈដែលអេក្រង់អ្នកទស្សនានៅតែបង្ហាញអ្វីៗទាំងអស់។ ប៊ូតុងផ្សេងៗទៀតនៅលើកាតនៅតែដំណើរការ ប៊ូតុងលុបនៅតែភ្លឺ ហើយអ្វីដែលអ្នកបង្ហាញពីបញ្ជីនានា នៅតែទៅដល់អេក្រង់ — មានតែរូបភាពរបស់វានៅទីនេះទេដែលបាត់ ហើយការងារគូរវាពីរដងក៏បាត់ទៅជាមួយដែរ។ វីដេអូ ឬសំឡេងរបស់ស្លាយ នៅតែចាក់សំឡេងដូចមុន ប៉ុន្តែប៊ូតុងចាក់របស់វាជាផ្នែកមួយនៃរូបភាព៖ ចុចរូបភ្នែកដែលមានឆ្នូតកាត់ (**[en:tran:Resume rendering preview]**) ដើម្បីយករូបភាពមកវិញ ហើយចាប់ផ្ដើមចាក់មួយដោយដៃ — កាតនោះនឹងបង្ហាញអ្វីដែលនៅលើអេក្រង់ពិតប្រាកដ ហើយឃ្លីបដែលកំពុងចាក់ នៅតែបន្តចាក់។ កាតនោះចងចាំជម្រើសនេះសម្រាប់អេក្រង់នោះ សូម្បីតែក្រោយពេលចាប់ផ្ដើមកម្មវិធីឡើងវិញ។ 📸
- **[en:tran:Lock]** (របារខាងលើ រូបសោ)៖ ពេលចាក់សោ (ពណ៌ក្រហម) អេក្រង់បដិសេធការប្ដូរស្លាយ — មានប្រយោជន៍ក្នុងពេលសំខាន់ដែលកំពុងផ្សាយផ្ទាល់; ចុចម្ដងទៀត (ពណ៌បៃតង) ដើម្បីដោះសោ។ ការប្ដូរដែលវាបដិសេធ បង្ហាញថា _[en:tran:Screen Manager is locked]_ ក្នុងសារមួយដែលមានប៊ូតុង **[en:tran:Unlock]** ផ្ទាល់ខ្លួន៖ ការចុចវា ដោះសោអេក្រង់ ហើយបិទសារនោះ។
- **ម៉ូនីទ័រ** (របារខាងក្រោម ឧ. `(0):2678…`)៖ ចុចដើម្បីជ្រើសរើស **ម៉ូនីទ័រពិតមួយណា** ដែលអេក្រង់នេះបញ្ចាំងទៅ — ម៉ឺនុយនោះរាយម៉ូនីទ័រនីមួយៗ ជាមួយកម្រិតភាពច្បាស់របស់វា ហើយសម្គាល់ម៉ូនីទ័របច្ចុប្បន្នដោយ `*` និងម៉ូនីទ័រចម្បងដោយ `(primary)`។
