# W-07 — រចនាអត្ថបទព្រះគម្ពីរនៅលើអេក្រង់

**គោលដៅ:** ប្តូររបៀបដែលខគម្ពីរមើលទៅនៅលើអេក្រង់ — ទំហំ ពណ៌ និងគែម ឬស្រមោល ដែលធ្វើឲ្យវាអានបានច្បាស់ ពីលើរូបភាព។

1. នៅក្នុងផ្ទាំង **[en:tran:Mini Screen]** ចុច **[en:tran:Reveal Hidden Controls]** — ចំណុចបី **⋯** នៅគែមខាងក្រោមរបស់វា។ ប៊ូតុងនៅក្រោមអេក្រង់តូច ត្រូវបានលាក់ រហូតដល់អ្នកចុចវា ហើយវានៅបង្ហាញ ពេលកណ្ដុរនៅលើវា។ បទគម្ពីរនៅក្នុងថេប **[en:tran:Bibles]** នៅកណ្ដាល ក៏មាន **⋯** ដូចគ្នានៅខាងក្រោមវា ជាមួយប៊ូតុងដដែលនៅពីក្រោយវា។
2. នៅក្នុងជួរប៊ូតុងដែលលេចឡើង ចុច **[en:tran:Bible Properties]** — ប៊ូតុងដែលមានរូបសៀវភៅ និងស្ពឺ។ ផ្ទាំងអណ្ដែតមួយបើកឡើង។ មិនមានកាតណាត្រូវបើកនៅខាងក្នុងវាទេ ហើយក៏គ្មានពណ៌ដាច់ដោយឡែក សម្រាប់លេខខគម្ពីរដែរ។ 📸
3. **ប្រាប់ថាមានអ្វីនៅពីក្រោយពាក្យ។** ផ្នែកខាងលើនៃផ្ទាំង បង្ហាញខគម្ពីរមួយនៅលើផ្ទៃខាងក្រោយ។ ចុច **[en:tran:Dark]** ពេលពាក្យនៅពីលើរូបភាព ឬវីដេអូងងឹត — វាប្រែជាពណ៌ស — ឬ **[en:tran:Light]** សម្រាប់ផ្ទៃខាងក្រោយភ្លឺ — វាប្រែជាពណ៌ខ្មៅ។ រូបរាងដែលអ្នកមាន នៅតែដដែល ប៉ុន្តែគែមត្រូវបានប្តូរទៅពណ៌ផ្ទុយវិញ។
4. **ជ្រើសរូបរាងមួយ។** ក្រឡានីមួយៗនៅក្រោមខគម្ពីរ គឺជាអក្សរពីរតួ ដែលពាក់រូបរាងនោះ៖ **[en:tran:Normal]** គឺជាពាក្យធម្មតា។ **[en:tran:Thin Outline]**, **[en:tran:Outline]** និង **[en:tran:Heavy Outline]** ដាក់គែមជុំវិញអក្សរ។ **[en:tran:Soft Shadow]**, **[en:tran:Deep Shadow]** និង **[en:tran:Hard Shadow]** ដាក់ស្រមោលនៅពីក្រោយវា។ **[en:tran:Lifted]** ធ្វើទាំងពីរ។ **[en:tran:Glow]**, **[en:tran:Haze]**, **[en:tran:Halo]** និង **[en:tran:Blue Edge]** ដាក់ពន្លឺស្រាលនៅពីក្រោយពាក្យ ដើម្បីឲ្យអាចអានបាន ពីលើរូបភាពដែលរញ៉េរញ៉ៃ។ ការចុចតែម្ដង ប្តូរគ្រប់អេក្រង់ក្នុងពេលតែមួយ ហើយក្រឡាដែលកំពុងប្រើ មានរង្វង់ព័ទ្ធជុំវិញ។
5. **ប្តូរទំហំ។** អូស **[en:tran:Font Size]** ឬវាយលេខក្នុងប្រអប់នៅក្បែរវា។
6. **ប្តូរពណ៌។** ចុចការ៉េតូចនៅចុងជួរ **[en:tran:Text Color]**។ ផ្ទាំងជ្រើសពណ៌បើកនៅក្រោមវា។ ជ្រើសពណ៌មួយ ហើយពាក្យនៅលើអេក្រង់ប្តូរភ្លាមៗ។ ចុចការ៉េនោះម្ដងទៀត ដើម្បីបិទផ្ទាំងជ្រើសពណ៌។
7. **ប្តូររបៀបរៀបពាក្យ។** **[en:tran:Font Family]** គឺជាបញ្ជីពុម្ពអក្សរនៅលើកុំព្យូទ័រនេះ៖ ជ្រើសមួយ ហើយគ្រប់ខគម្ពីរត្រូវបានគូរដោយពុម្ពអក្សរនោះ។ ជ្រើសបន្ទាត់ទីមួយនៃបញ្ជី `--` ដើម្បីត្រឡប់ទៅពុម្ពអក្សរផ្ទាល់របស់ព្រះគម្ពីរនីមួយៗវិញ។ អក្សរដែលពុម្ពអក្សរដែលអ្នកជ្រើសមិនមាន — អក្សរខ្មែរក្រោមពុម្ពអក្សរអង់គ្លេស — នៅតែប្រើពុម្ពអក្សររបស់ព្រះគម្ពីរផ្ទាល់។ **[en:tran:Text Style]** មាន **[en:tran:Bold]** និង **[en:tran:Italic]**។ **[en:tran:Text Align]** ដាក់បន្ទាត់នៅខាងឆ្វេង កណ្ដាល ខាងស្ដាំ ឬតម្រឹមសងខាង។ **[en:tran:Line Height]** និង **[en:tran:Letter Spacing]** ពង្រីកចន្លោះបន្ទាត់ និងចន្លោះអក្សរ។
8. **បង្កើតរូបរាងផ្ទាល់ខ្លួន។** **[en:tran:Outline]** គឺជាកម្រាស់នៃគែម។ **[en:tran:Shadow Blur]**, **[en:tran:Shadow Offset X]** និង **[en:tran:Shadow Offset Y]** ធ្វើឲ្យស្រមោលស្រាល និងផ្លាស់ទីវា។ **[en:tran:Glow]** គឺជាទំហំនៃពន្លឺនៅពីក្រោយពាក្យ។ នីមួយៗមានការ៉េមួយ សម្រាប់ពណ៌ផ្ទាល់ខ្លួនរបស់វា ហើយការជ្រើសពណ៌មួយ បើកផ្នែកនោះឲ្យដំណើរការ។ អ្នកដែលចេះ CSS អាចវាយ `text-shadow` ក្នុងប្រអប់ **[en:tran:Text Shadow]** ជំនួសវិញ។
9. **រក្សាទុកវា។** ចុច **[en:tran:Save as Preset]** — ក្រឡាចុងក្រោយ ដែលមានសញ្ញាបូក — វាយឈ្មោះ ហើយបញ្ជាក់។ រូបរាងនោះ រួមទាំងទំហំ និងពណ៌របស់វា ក្លាយជាក្រឡាមួយផ្ទាល់ខ្លួន ហើយការចុចក្រឡានោះពេលក្រោយ នឹងដាក់វាទាំងអស់មកវិញ។ ចុចកណ្ដុរស្ដាំលើក្រឡាដែលបានរក្សាទុក សម្រាប់ **[en:tran:Rename Preset]**, **[en:tran:Replace with Current Look]** និង **[en:tran:Remove Preset]**។
10. **[en:tran:Reset]** នៅខាងក្រោម ត្រឡប់ទៅពាក្យធម្មតាវិញ ហើយរក្សាទំហំដដែល។ ពុម្ពអក្សរត្រឡប់ទៅពុម្ពអក្សរផ្ទាល់របស់ព្រះគម្ពីរនីមួយៗវិញ។
