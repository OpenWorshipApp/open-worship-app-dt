# W-09 — ចាក់សំឡេង និងធាតុបន្ថែមផ្ទៃខាងមុខ (រាប់ថយក្រោយ នាឡិកា អក្សររត់ខាងក្រោម…)

**គោលដៅ:** ដំណើរការធាតុបន្ថែមសម្រាប់កម្មវិធីថ្វាយបង្គំ។

**សំឡេង:** នៅក្នុងផ្ទាំងផ្ទៃខាងក្រោយ ចុចបើកថេប **[en:tran:Audios]** ចុចបទមួយ ដើម្បីបើកកម្មវិធីចាក់របស់វា ហើយចុចចាក់ — ថេបនោះមានសញ្ញាសម្គាល់ ពេលកំពុងចាក់។ ផ្អាកវា ដើម្បីបញ្ចប់។ 📸

**ធាតុផ្ទៃខាងមុខ** — ចុចថេប **[en:tran:Foreground]** នៅកណ្ដាល ហើយម៉ឺនុយមួយបើកឡើង **នៅត្រង់ទ្រនិចកណ្ដុរ** ដោយរាយសមាសធាតុទាំងអស់។ ជ្រើសមួយ ហើយវាបើកក្នុង **ផ្ទាំងអណ្ដែតផ្ទាល់ខ្លួនរបស់វា** ដែលចងចាំទំហំ និងទីតាំងរបស់វា ទោះបីបិទបើកកម្មវិធីឡើងវិញក៏ដោយ។ ម៉ឺនុយបិទដោយខ្លួនឯង។ បើកប៉ុន្មានក៏បានតាមចិត្ត នៅក្បែរៗគ្នា — ផ្ទាំងទាំងនោះឯករាជ្យពីគ្នា។ ម៉ឺនុយនេះក៏ជាក្ដារបង្ហាញស្ថានភាពដែរ៖ ប្រអប់ដែលបានធីក សម្គាល់ផ្ទាំងដែលបើករួចហើយ សមាសធាតុដែលមានអ្វីមួយនៅលើអេក្រង់ ត្រូវបានសម្គាល់ដូចថេបដែរ **ហើយមានលេខនៃអេក្រង់នីមួយៗ ដែលវាកំពុងនៅ** ហើយ ▶ ពណ៌ខៀវ សម្គាល់សមាសធាតុដែលការបង្ហាញស្លាយរបស់វាកំពុងដំណើរការ — នោះជារបៀបដែលអ្នករកឃើញការបង្ហាញស្លាយ ដែលនៅតែបន្តដំណើរការ នៅពីក្រោយផ្ទាំងដែលគ្មាននរណាបើក។ ផ្ទាំងខ្លួនឯង គ្មានរបារចំណងជើងទីពីរសម្រាប់បង្រួមទេ៖ ក្បាលរបស់វាផ្ទាល់ មានឈ្មោះ សញ្ញាសម្គាល់នៅលើអេក្រង់ និងប៊ូតុងបិទ។ ផ្ទាំងនីមួយៗមានប៊ូតុងបញ្ជាផ្ទាល់ខ្លួន និងប៊ូតុងបង្ហាញ/ចាប់ផ្តើម៖

- **[en:tran:Countdown]:** មានពីររបៀប។ _ទៅកាន់កាលបរិច្ឆេទ/ម៉ោង_៖ កំណត់កាលបរិច្ឆេទ និងម៉ោង ហើយចុច **[en:tran:Start Countdown to DateTime]** — វាចាប់ផ្តើមភ្លាម ហើយរាប់ទៅកាន់ម៉ោងនោះជានិច្ច។ _សម្រាប់រយៈពេលមួយ_៖ កំណត់ប្រអប់ **h** (ម៉ោង), **m** (នាទី) និង **s** (វិនាទី) (លើសពី 24 ម៉ោងក៏បាន៖ 25 ម៉ោង បង្ហាញជា `25:00:00`) ហើយចុច **[en:tran:Show Countdown]** — វាឡើងទៅលើអេក្រង់ក្នុងស្ថានភាព **ឈប់** ដោយបង្ហាញរយៈពេលពេញរបស់វា (`00:05:00`) ដូច្នេះវាអាចដាក់ឡើងមុន ហើយចាប់ផ្តើមពេលដល់ពេល។ ពេលវានៅលើអេក្រង់ **[en:tran:Start]**, **[en:tran:Pause]** / **[en:tran:Resume]** និង **[en:tran:Reset]** (ត្រឡប់ទៅរយៈពេលពេញ ក្នុងស្ថានភាពឈប់) នៅខាងក្រោមប៊ូតុង ជាមួយពាក្យមួយប្រាប់ថាវា _[en:tran:Not started]_, _[en:tran:Running]_ ឬ _[en:tran:Paused]_។ បើក **[en:tran:Auto-start]** ហើយប៊ូតុងនឹងសរសេរថា **[en:tran:Start Countdown]** ហើយវាចាប់ផ្តើមរាប់ ភ្លាមពេលវាត្រូវបានបង្ហាញ។ ពេលវាដល់សូន្យ លេខភ្លឹបភ្លែតពណ៌ក្រហមប្រាំដង (ប្រហែលដប់វិនាទី) ហើយបន្ទាប់មក នៅពណ៌ក្រហមដដែល។ វានៅ `00:00:00` មួយវិនាទី បន្ទាប់មករាប់ពេល **លើស** នៅពីក្រោយសញ្ញា **+** (`+00:01:23`) រហូតដល់អ្នកលាក់វា។ អ្នកទស្សនាឃើញតែលេខប៉ុណ្ណោះ — ការរាប់ថយក្រោយដែលបានផ្អាក គ្រាន់តែឈប់។ លាក់វាដោយប៊ូតុងលាក់របស់វា។ 📸
- **[en:tran:Stopwatch]:** ប៊ូតុងបញ្ជាដូចគ្នា។ **[en:tran:Show Stopwatch]** ដាក់វាឡើងនៅ `00:00:00` ក្នុងស្ថានភាពឈប់ (ដំណើរការភ្លាមជាមួយ **[en:tran:Auto-start]**) បន្ទាប់មក **[en:tran:Start]** / **[en:tran:Pause]** / **[en:tran:Resume]** / **[en:tran:Reset]** (ត្រឡប់ទៅសូន្យ)។ **[en:tran:Reset]** **រក្សាទុក** ពេលវេលាដែលវាបានបង្ហាញជាមុនសិន ទៅក្នុងបញ្ជី **[en:tran:History]** នៅក្រោមប៊ូតុង — ថ្មីបំផុតនៅខាងលើ មានលេខរៀង ជាមួយម៉ោងនៃថ្ងៃដែលវាត្រូវបានកំណត់ឡើងវិញ (ជាភាសារបស់កម្មវិធី ហើយជាភាសាខ្មែរ ជាលេខ ឧទាហរណ៍ `04/10 07:57`) — ដូច្នេះរយៈពេល 7:42 នៃទីបន្ទាល់មួយ មិនបាត់ទៅជាមួយលេខសូន្យទេ។ វគ្គនីមួយៗរក្សាបញ្ជីផ្ទាល់ខ្លួន (20 ចុងក្រោយ ហើយការកំណត់ឡើងវិញក្រោមមួយវិនាទី មិនត្រូវបានរក្សាទុកទេ) ហើយ **[en:tran:Clear]** នៅក្បែរវា សម្អាតបញ្ជីនោះ បន្ទាប់ពីបញ្ជាក់។

- **[en:tran:Effects]** គឺជាផ្នែកបត់មួយនៅក្រោម _លក្ខណសម្បត្តិ_ លើ **គ្រប់** សមាសធាតុ ហើយវាតុបតែងធាតុផ្ទៃខាងមុខ៖ **[en:tran:Border]** (រចនាប័ទ្ម កម្រាស់ ពណ៌) **[en:tran:Shadow]** (ស្រាល / មធ្យម / ខ្លាំង / ពន្លឺរស្មី ជាមួយពណ៌ផ្ទាល់ខ្លួន) និង **[en:tran:Padding]** — ចន្លោះរវាងអ្វីដែលបង្ហាញ និងគែមនៃប្រអប់របស់វា ដែលវាស់ជាទំហំអក្សរ ដូច្នេះវារក្សាសមាមាត្ររបស់វា ពេលអ្នកប្តូរទំហំតួអក្សរ។ នៅលើសមាសធាតុដែលដាក់ **ពាក្យ** នៅលើអេក្រង់ មានច្រើនទៀត៖ **[en:tran:Text Align]**, **[en:tran:Line Height]**, **[en:tran:Letter Spacing]**, **[en:tran:Text Shadow]** (ស្រាល / ពន្លឺរស្មី / គែមអក្សរ) — ដែលធ្វើឲ្យការជូនដំណឹងអាចអានបាន ពីលើរូបភាពរញ៉េរញ៉ៃ ឬវីដេអូដែលកំពុងចាក់ — និង **[en:tran:Text Style]**៖ អក្សរទ្រេត គូសបន្ទាត់ក្រោម អក្សរធំ (UPPERCASE)។ ផ្នែកបត់នោះមានចំណុចមួយ ពេលមានអ្វីមួយនៅខាងក្នុងត្រូវបានកំណត់ ដូច្នេះរូបរាងដែលអ្នករកមិនឃើញ មិនដែលជាហេតុផលដែលសារមើលទៅខុសទេ។ 📸
