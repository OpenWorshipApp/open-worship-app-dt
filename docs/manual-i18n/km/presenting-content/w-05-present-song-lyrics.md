# W-05 — បង្ហាញទំនុកចម្រៀង

**គោលដៅ:** ដាក់ទំនុកចម្រៀងរបស់ចម្រៀងមួយ លើអេក្រង់។

1. នៅក្នុងជួរឈរខាងឆ្វេង សូមចុចចម្រៀងមួយ ក្នុងបញ្ជី **[en:tran:Documents]** — ចម្រៀងមាន
   រូបណូតភ្លេង។ ថេប **[en:tran:Documents]** នៅកណ្ដាល ប្ដូរទៅទិដ្ឋភាពចម្រៀង: **[en:tran:Previewer]**
   នៃទំនុកច្រៀងនៅខាងលើ និងឃ្លានៃ **[en:tran:Stage Previewer]** នៅខាងក្រោមវា។ មានតែឯកសារមួយក្នុង
   បញ្ជីប៉ុណ្ណោះ ដែលត្រូវបានបន្លិចម្ដងៗ ដូច្នេះការជ្រើសរើសចម្រៀងមួយ នឹងលែងជ្រើសរើសអ្វីដែលបានជ្រើសពីមុន។
   ផ្ទាំងទាំងពីរនោះ បង្ហាញថាចម្រៀងនឹងមើលទៅយ៉ាងណានៅលើអេក្រង់។ គ្មានអ្វីទៅដល់អេក្រង់ទេ
   រហូតដល់អ្នកចុចឃ្លាមួយ។ 📸
2. **ចុច** ឃ្លាមួយ ដើម្បីផ្ញើវាទៅអេក្រង់។
3. ចុច **F8** / ប៊ូតុងលុប (`SL`) នៅក្បាលអេក្រង់តូច ដើម្បីដកវាចេញ។
4. ដើម្បីភ្ជាប់តំណទៅចម្រៀងមួយ — អាសយដ្ឋានវេប ឬឯកសារនៅលើកុំព្យូទ័រនេះ ដែលសរសេរជា `file:///C:/…` — សូមបើកវានៅក្នុង **កម្មវិធីកែសម្រួលទំនុកច្រៀង** (ចុចកណ្ដុរស្ដាំលើចម្រៀង →
   **[en:tran:Edit]**) ហើយបន្ថែមវាល **`- Attachments:`** ទៅប្លុក `ol:Config` របស់វា តំណមួយក្នុងមួយបន្ទាត់។
   តំណនីមួយៗ ក៏ក្លាយជា **ស្លាយផ្ទាល់ខ្លួនរបស់វា នៅខាងចុង** នៃ អ្នកមើលជាមុនដំណាក់កាល
   ដែលមានឈ្មោះតាមតំណនោះ។ តំណ YouTube ក្លាយជាវីដេអូដែលអាចចាក់បាន តំណរូបភាព / វីដេអូ /
   សំឡេង ក្លាយជាមេឌៀនោះ ហើយអាសយដ្ឋានបណ្ដាញផ្សេងទៀត ក្លាយជាទំព័រនោះផ្ទាល់។
   នីមួយៗពេញស្លាយទាំងមូល។ បង្ហាញវាតាមរបៀបដូចដែលអ្នកបង្ហាញឃ្លាមួយ។ តំណទៅ
   ឯកសារនៅលើកុំព្យូទ័រនេះ ក៏ដំណើរការដែរ (សរសេរជា `file:///C:/…`) ដែលជារបៀបដែលតារាងអាកូដ ឬ
   បទភ្លេងអម ធ្វើដំណើរជាមួយចម្រៀង។ 📸
5. តំណដែលកម្មវិធីមិនអាចបង្ហាញបាន — PDF ឬបន្ទាត់ដែលមិនមែនជាអាសយដ្ឋានបណ្ដាញ — នៅតែទទួលបាន
   ស្លាយដែលមានឈ្មោះរបស់វា គ្រាន់តែជាស្លាយទទេ។
6. **ចម្រៀងមួយ អាចត្រូវបានមើលជាមុននៅស្ទែជច្រើន ក្នុងពេលតែមួយ។** **[en:tran:Add Stage]** នៅ
    ក្បាលរបស់ អ្នកមើលជាមុនដំណាក់កាល បើកម៉ឺនុយដដែល ដែលស្លាក **St:** របស់អេក្រង់តូចបើក:
    **[en:tran:Stage] 0** ដល់ **[en:tran:Stage] 5** — ស្ទែជដែលមាននៅលើអេក្រង់រួចហើយ ត្រូវបានរាយ ប៉ុន្តែជាពណ៌ប្រផេះ — និង
    **[en:tran:Increment] · [en:tran:Stage] N** នៅខាងក្រោម ដែលបន្ថែមស្ទែជមួយ លើសពីស្ទែជខ្ពស់បំផុតដែលអ្នកមាន។
    ជម្រើស បន្ថែម គឺជារបៀបដែលអ្នកទៅហួស ស្ទែជ 5 ហើយវាជាអ្វីដែលត្រូវគ្នានឹងអេក្រង់ ដែលលេខ **St:**
    របស់វា អ្នកបានដំឡើងដល់ទីនោះរួចហើយ។ ស្ទែជនីមួយៗ មកដល់ជាបន្ទះ (chip) ផ្ទាល់ខ្លួន និង
    ផ្ទាំងផ្ទាល់ខ្លួន ក្នុងពណ៌ផ្ទាល់ខ្លួន។ សញ្ញា **×** នៅលើបន្ទះ (**[en:tran:Hide Stage] N**) លាក់
    ផ្ទាំងរបស់ស្ទែជនោះម្តងទៀត — រូបរាងរបស់វានៅក្រោម **⚙** ត្រូវបានរក្សាទុក សម្រាប់ពេលអ្នកបន្ថែមវាមកវិញ — ហើយ
    **[en:tran:Stage] 0** ដែលមានរូបសោ នៅតែនៅ។ 📸
7. ដើម្បីផ្លាស់ប្ដូររបៀបដែលស្លាយរបស់ស្ទែជមួយ **មើលទៅ** សូមចុច **⚙** នៅលើបន្ទះរបស់ស្ទែជនោះ

8. ការកំណត់ទាំងនេះ ជារបស់ **ស្ទែជ** មិនមែនរបស់ចម្រៀងទេ — គ្រប់ចម្រៀងដែលអ្នកបើក ប្រើ
   វា ដែលជាហេតុផលដែលផ្ទាំងនេះនិយាយថា _[en:tran:Applies to every song]_។
   **លេខស្ទែជនីមួយៗ រក្សាការកំណត់ផ្ទាល់ខ្លួនរបស់វា** ដូច្នេះអ្នកអាចទុកស្ទែជដែលបញ្ចាំងឲ្យធម្មតា ធ្វើឲ្យស្ទែជអាកូដ
   ធំជាង ហើយផ្ដល់រចនាប័ទ្មងងឹតដល់ស្ទែជទីបី សម្រាប់អ្នកនៅតុសំឡេង។ ស្ទែជ 0
   គឺជារូបរាងធម្មតា ដែលមានតែទំនុកច្រៀង ហើយស្ទែជ 4 ក៏ដូច្នោះដែរ។ ស្ទែជផ្សេងទៀតទាំងអស់ ចាប់ផ្តើមពីរូបរាងដែលមានអាកូដ និងកំណត់ចំណាំ
   ហើយស្ទែជដែលលើសពី 5 ខុសពីស្ទែជ 1 តែដោយអ្វីដែលអ្នកកំណត់នៅទីនេះប៉ុណ្ណោះ។ CSS ផ្ទាល់ខ្លួន ត្រូវបាន **បន្ថែមលើ** រូបរាង
   ដើមរបស់ស្ទែជ ជាជាងជំនួសវា ដូច្នេះស្ទែជ 0 នៅតែលាក់អាកូដរបស់វា។
   **ស្ទែជ 2 ដល់ 5 បង្ហាញអ្វីដែលមកបន្ទាប់** ជុំវិញឃ្លាដែលកំពុងច្រៀង: 2 ឃ្លាបន្ទាប់
   នៅខាងក្រោមវា 3 ឃ្លាពីរបន្ទាប់ 4 ដូច 2 ប៉ុន្តែក្នុងរូបរាងធម្មតា 5 ឃ្លាមុន នៅខាងលើឆ្វេង និង
   ឃ្លាបន្ទាប់ នៅខាងក្រោមស្ដាំ។ ឃ្លាដែលនឹងមកដល់ មាន **ពន្លឺពេញ** មិនស្រអាប់ទេ ហើយ
   នៅលើស្ទែជ 2 ដល់ 4 ឃ្លាស្ថិតនៅជាប់ជ្រុងខាងលើឆ្វេងនៃអេក្រង់ ជាមួយឃ្លាបន្ទាប់ នៅជាប់ខាងឆ្វេង
   នៅខាងក្រោមវា ប៉ះនឹងវា — គ្មានគម្លាតជុំវិញពួកវា ហើយគ្មានចន្លោះរវាងពួកវា ទោះ **[en:tran:Slide Padding (%)]** និយាយយ៉ាងណាក៏ដោយ (គម្លាតនៅ
   ខាងក្នុងប្រអប់ផ្ទាល់របស់ឃ្លានីមួយៗ)។ អេក្រង់ដែលបានប្ដូរទៅស្ទែជណាមួយ លើសពី 0 មាន **[en:tran:Slide]:**
