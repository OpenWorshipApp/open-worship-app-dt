# W-47 — ដាក់សារនៅលើអេក្រង់

**គោលដៅ:** ដាក់ពាក្យដែលអ្នករាល់គ្នាត្រូវអាន នៅជុំវិញពេលកម្មវិធីថ្វាយបង្គំ ដែលមិនមែនជាស្លាយ — ការជូនដំណឹងអំពីចំណតរថយន្ត ការជូនដំណឹងអំពីតង្វាយ ការហៅអ្នកនិយាយបន្ទាប់។

1. បើកថេប **[en:tran:Foreground]**។ អ្វីដែលបើកឡើង គឺជាម៉ឺនុយនៃសមាសធាតុនានា ហើយជួរទីមួយនៅក្នុងនោះគឺ **[en:tran:Messages]** — វានៅលំដាប់ទីមួយ ព្រោះវាជាអ្វីដែលអ្នកបើក ពេលប្រញាប់។
2. **សរសេរសាររបស់អ្នក។** ចុច **[en:tran:Add Message]** សម្រាប់សារនីមួយៗ។ សារនីមួយៗមានប្រអប់ផ្ទាល់ខ្លួន ហើយអាចមាន **ប៉ុន្មានបន្ទាត់ក៏បានតាមចិត្ត** — ការចុះបន្ទាត់ក្នុងប្រអប់ គឺជាការចុះបន្ទាត់នៅលើអេក្រង់។ ក្រោយពីវាយក្នុងប្រអប់ទីពីរ សារទីមួយនៅតែមានពាក្យដែលអ្នកបានសរសេរ។ ព្រួញនៅក្បែរប្រអប់ ផ្លាស់ទីសារនោះឡើងលើ ឬចុះក្រោមក្នុងបញ្ជី — ហើយនៅលើអេក្រង់ផងដែរ ប្រសិនបើវាកំពុងបង្ហាញ។ ប៊ូតុង ✕ លុបវាចេញ។
3. **ដាក់សារមួយឡើង។** ចុចប៊ូតុងអេក្រង់ នៅលើជួររបស់សារនោះផ្ទាល់។ វាលេចឡើងពីលើអ្វីដែលមាននៅលើអេក្រង់រួចហើយ — ស្លាយ ខគម្ពីរ ផ្ទៃខាងក្រោយ — ហើយវា **នៅទីនោះរហូតដល់អ្នកដកវាចេញ**។ គ្មានការពន្យារពេល និងគ្មានការរាប់ថយក្រោយទេ៖ គ្មានអ្វីដកវាចេញក្រៅពីអ្នកឡើយ។ ចុចប៊ូតុងដដែលម្ដងទៀត ដើម្បីដកវាចេញ។ ពេលនេះវាសរសេរថា _លាក់_។
4. **ច្រើនក្នុងពេលតែមួយ។** បង្ហាញសារទីពីរ ហើយវានឹងនៅ **ខាងក្រោម** សារទីមួយ មិនមែនពីលើវាទេ ទោះបីសារនីមួយៗមានប៉ុន្មានបន្ទាត់ក៏ដោយ — បន្ទាត់វែងដែលអេក្រង់បំបែកជាពីរ រាប់ជាពីរបន្ទាត់។ លាក់សារខាងលើ ហើយសារខាងក្រោមនឹងរំកិលឡើង បិទចន្លោះនោះ។ ប្រសិនបើសារទាំងនោះនឹងហួសពីបាតអេក្រង់ វានឹងត្រូវបានបង្រួមតូចទាំងអស់គ្នា រហូតដល់វាសម។ នេះជារបៀបដែលអ្នកដាក់ការជូនដំណឹងអំពីចំណតរថយន្ត និងការជូនដំណឹងអំពីតង្វាយ ឡើងជាមួយគ្នា។
5. **សារទាំងអស់។** **[en:tran:Show All Messages]** ដាក់សារទាំងអស់ឡើងក្នុងពេលតែមួយ ជាប្លុកតែមួយ — ក៏ត្រូវបានបង្រួមតូចដែរ ប្រសិនបើវាមិនសមនឹងអេក្រង់។ វាជំនួសសារណាមួយដែលអ្នកបានបង្ហាញម្ដងមួយៗ ហើយការបង្ហាញសារមួយម្ដងទៀត ដកប្លុកនោះចេញ ដូច្នេះពាក្យដដែលមិនដែលនៅលើជញ្ជាំងពីរដងទេ។ ធីក **[en:tran:Rotate]** ជាមុនសិន ហើយប្រអប់វិនាទីនឹងលេចឡើង៖ ពេលនេះ ប៊ូតុងដដែលបង្ហាញសារ **ម្ដងមួយៗ** វិលជុំ រហូតដល់អ្នកលាក់វា។ នោះហើយជាក្ដារជូនដំណឹងមុនពេលកម្មវិធីថ្វាយបង្គំ។
6. **ធ្វើឲ្យវាមើលទៅដូចជាការជូនដំណឹង។** បើក **[en:tran:Properties]** បន្ទាប់មកបើកផ្នែកបត់ **[en:tran:Effects]** នៅខាងក្រោមវា។ **[en:tran:Padding]** គឺជាចន្លោះរវាងពាក្យរបស់អ្នក និងគែមនៃប្រអប់ពណ៌នៅពីក្រោយវា — វាចាប់ផ្តើមនៅមួយភាគបួននៃទំហំអក្សរ ហើយដោយសារវាត្រូវបានវាស់ជាទំហំអក្សរ ប្រអប់នោះរក្សារាងរបស់វា ពេលអ្នកប្តូរ **[en:tran:Font Size]**។ បន្ថែម **[en:tran:Border]** ដើម្បីដាក់ស៊ុមវា **[en:tran:Shadow]** ដើម្បីលើកវាចេញពីរូបភាព **[en:tran:Text Align]** ដើម្បីដាក់វានៅកណ្ដាល និង **[en:tran:Text Shadow]** ប្រភេទ **[en:tran:Outline]** ពេលសារត្រូវអានពីលើរូបថតដែលរញ៉េរញ៉ៃ ឬវីដេអូដែលកំពុងចាក់។ ការប្តូរណាមួយក្នុងចំណោមទាំងនេះ ពេលសារកំពុងបង្ហាញ នឹងកែរចនាពួកវានៅកន្លែងដដែល ហើយរក្សាវាតម្រៀបពីលើគ្នាដដែល។ 📸
7. **F4** គឺជាផ្លូវកាត់ ពេលផ្ទាំង **[en:tran:Messages]** កំពុងបើក៖ ពេលមានអេក្រង់ត្រូវបានធីក វាដាក់វគ្គនោះឡើង ហើយការចុចវាម្ដងទៀត ដកអ្វីៗទាំងអស់ចេញ។ ប្រសិនបើគ្មានអេក្រង់ណាត្រូវបានធីកទេ វាប្រាប់អ្នក ជាជាងទាយ។
8. អត្ថបទគឺជាអត្ថបទធម្មតា។ ការវាយ `<b>loud</b>` នឹងដាក់សញ្ញាតង្កៀបមុំទាំងនោះនៅលើអេក្រង់ ដូចដែលអ្នកបានវាយយ៉ាងពិតប្រាកដ។ សារមិនដែលត្រូវបានចាត់ទុកជាការធ្វើទម្រង់អក្សរឡើយ។ ប្រើប៊ូតុងរក្សាទុកនៅខាងលើ ដើម្បីរក្សាទុកវគ្គទាំងមូល — គ្រប់សារនៅក្នុងនោះ — ហើយជ្រើសវាមកវិញនៅសប្តាហ៍ក្រោយ។
