# W-36 — នាំចូលចម្រៀងកម្មសិទ្ធិសាធារណៈ (មិនចាំបាច់មានគណនី)

កម្មវិធីនេះភ្ជាប់មកជាមួយសៀវភៅទំនុកតម្កើងតូចមួយ ដែលមានចម្រៀងបុរាណជាភាសាអង់គ្លេស ជាកម្មសិទ្ធិសាធារណៈ — Amazing Grace, It Is Well with My Soul, Holy Holy Holy និងប្រហែល 36 បទទៀត។ ចម្រៀងទាំងនោះនាំចូលជាឯកសារទំនុកចម្រៀង ដោយ **មិនចាំបាច់ចូលគណនី មិនចាំបាច់មានព័ត៌មានសម្ងាត់ និងមិនចាំបាច់មានអ៊ីនធឺណិត** ដូច្នេះវាដំណើរការលើកុំព្យូទ័រដែលទើបដំឡើងថ្មី នៅកន្លែងណាក៏បាន។

1. នៅក្នុងទំព័រធ្វើបទបង្ហាញ បើក **⋮ [en:tran:More Options]** នៃបញ្ជី **[en:tran:Documents]** → **[en:tran:Import From Public Domain Songs]**។ ខុសពីធាតុ SongSelect (W-35) ធាតុនេះ _តែងតែ_ មាននៅទីនោះ។ 📸
2. ផ្ទាំងអណ្ដែតមួយបើកឡើង ហើយបង្ហាញបញ្ជីចម្រៀងទាំងមូលភ្លាមៗ — ជួរនីមួយៗបង្ហាញចំណងជើង អ្នកនិពន្ធ ឆ្នាំ និងបន្ទាត់ទីមួយនៃចម្រៀង ដោយមានចំនួនសរុបនៅជ្រុងខាងលើខាងស្ដាំនៃប្រអប់ស្វែងរក (36 បទ នៅពេលសរសេរនេះ)។ រំកិលដើម្បីមើល ឬវាយក្នុង **[en:tran:Search songs]** ដើម្បីត្រងភ្លាមៗតាមចំណងជើង ឬអ្នកនិពន្ធ — ចំនួនក៏ប្រែប្រួលតាម។ 📸
3. ចុចប៊ូតុងទាញយក ☁⬇ របស់ចម្រៀងមួយ។ កម្មវិធីបញ្ជាក់ថា **[en:tran:Lyric document created successfully]** ហើយចម្រៀងនោះលេចឡើងក្នុងបញ្ជី **[en:tran:Documents]** របស់អ្នក ជាទំនុកចម្រៀង (♪) ដែលមានឈ្មោះតាមចំណងជើងរបស់វា។ ផ្ទាំងនៅតែបើក ដូច្នេះអ្នកអាចនាំចូលបន្តទៀតបាន។
4. ចុចជួរថ្មីនោះ៖ វាបង្ហាញស្លាយ **Info** (ព័ត៌មាន៖ ចំណងជើង អ្នកនិពន្ធ `Public Domain` ជាមួយឆ្នាំ) ជាមុន ហើយបន្ទាប់មកចម្រៀងតាម **លំដាប់ច្រៀងពិតប្រាកដ** — ទំនុកតម្កើងដែលមានបន្ទរ បង្ហាញស្លាយ **Chorus** (បន្ទរ) ម្ដងទៀត បន្ទាប់ពីឃ្លានីមួយៗ (Blessed Assurance បង្ហាញ Verse 1, Chorus, Verse 2, Chorus, Verse 3, Chorus)។ បង្ហាញវាដូចទំនុកចម្រៀងផ្សេងទៀតដែរ (W-04) ឬកែពាក្យក្នុងកម្មវិធីកែសម្រួលទំនុកច្រៀងជាមុនសិន — វាជាឯកសារទំនុកចម្រៀងធម្មតា ដែលអាចកែបាន។ 📸
5. រំកិលទៅ **ចុងបញ្ចប់** នៃការមើលជាមុននោះ៖ បន្ទាប់ពីឃ្លាចុងក្រោយ មានស្លាយមួយទៀតឈ្មោះ **Hymnary.org** — ជាទំព័រដែលពាក្យរបស់ចម្រៀងត្រូវបានយកមក ដែលរក្សាទុកជាមួយឯកសារ ជាឯកសារភ្ជាប់ ដូច្នេះអ្នកអាចផ្ទៀងផ្ទាត់ពាក្យជាមួយប្រភពបានជានិច្ច។ វាដំណើរការដូចស្លាយផ្សេងទៀតដែរ (អ្នកអាចបង្ហាញវា ឬគ្រាន់តែទុកវានៅចុងបញ្ចប់)។ 📸
