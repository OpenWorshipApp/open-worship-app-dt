# W-52 — ផ្ទេរការកំណត់របស់អ្នកទៅកុំព្យូទ័រផ្សេង (នាំចេញ / នាំចូលការកំណត់)

**File → [en:tran:Export Data]** ផ្ទេរឯកសាររបស់អ្នក — ចម្រៀង ស្លាយ មេឌៀ។ វិធីនេះផ្ទេររបៀបដែលកម្មវិធីត្រូវបាន **រៀបចំ**៖ ភាសា និងស្បែក របៀបដែលព្រះគម្ពីរមើលទៅនៅលើអេក្រង់ អក្សររត់ និងនាឡិការាប់ពេល ទំហំផ្ទាំង និងអ្វីៗផ្សេងទៀតដែលអ្នកបានជ្រើសរើស តាមពេលវេលា។

1. បើក **[en:tran:Setting]**។ នៅផ្នែកខាងក្រោមនៃរបារចំហៀងខាងឆ្វេង នៅក្រោម **[en:tran:Apply Settings]** មាន **[en:tran:Export Settings]** និង **[en:tran:Import Settings]** — ដូចគ្នានៅគ្រប់ថេប។ 📸
2. ចុច **[en:tran:Export Settings]**។ ផ្ទាំងមួយរាយការកំណត់ជាផ្នែកៗ៖ **[en:tran:General]**, **[en:tran:Bible]**, **[en:tran:Screens]**, **[en:tran:Foreground]**, **[en:tran:Background]**, **[en:tran:Documents & Lyrics]**, **[en:tran:Layout]**, **[en:tran:AI & Assistant]**, **[en:tran:Connections]**, **[en:tran:API Keys & Sign-ins]** និង **[en:tran:Other Settings]**។ ផ្នែកនីមួយៗប្រាប់ថា វាមានការកំណត់ប៉ុន្មាន ឬ **[en:tran:All default]** ពេលគ្មានអ្វីនៅក្នុងនោះធ្លាប់ត្រូវបានប្តូរ។ អ្វីៗទាំងអស់ចាប់ផ្តើមដោយបានធីករួច លើកលែងតែសោ API។ 📸
3. ព្រួញនៅខាងឆ្វេងនៃផ្នែកមួយ បើកផ្នែកនោះ ហើយផ្នែករងនីមួយៗ អាចធីកដោយឡែកបាន — **[en:tran:General]** មាន **[en:tran:Language]**, **[en:tran:Theme]**, **[en:tran:Font]**, **[en:tran:Tips of the Day]**, **[en:tran:Folders]** និង **[en:tran:File Color Notes]**។ ផ្នែកដែលមានតែផ្នែករងខ្លះត្រូវបានធីក បង្ហាញសញ្ញាដាច់ (–) នៅក្នុងប្រអប់របស់វា។ ការធីកផ្នែកនោះ នឹងធីកផ្នែករងទាំងអស់។ **[en:tran:Deselect All]** / **[en:tran:Select All]** ធ្វើគ្រប់ផ្នែកក្នុងពេលតែមួយ។
4. នៅក្រោមបញ្ជី មានគូ **[en:tran:Password]** / **[en:tran:Confirm Password]** ដូចគ្នានឹងការនាំចេញផ្សេងទៀតដែរ។ **សោ API និងការចូលគណនី អាចដាក់ចូលក្នុងឯកសារបាន តែពេលមានពាក្យសម្ងាត់ប៉ុណ្ណោះ**៖ ជួររបស់វានៅតែពណ៌ក្រហម ជាមួយ **[en:tran:Type a password below to include these]** រហូតដល់មានពាក្យសម្ងាត់ត្រូវបានវាយ ហើយត្រឡប់មកវិញដោយមិនបានធីក ប្រសិនបើពាក្យសម្ងាត់ត្រូវបានលុប។ ប្រសិនបើវាយខុសគ្នា ប្រអប់ទាំងពីរនឹងបង្ហាញថា **[en:tran:Passwords do not match]** ហើយផ្ទាំងនឹងត្រឡប់មកវិញ ដោយរក្សាអ្វីដែលបានធីក។
5. ចុច **[en:tran:Ok]**។ `Settings.owasetting.tar.gz` ត្រូវបានសរសេរទៅក្នុងថត **Downloads** (`Settings.owasetting.enc` ពេលមានពាក្យសម្ងាត់) ហើយថតនោះបើកឡើង ដោយចង្អុលទៅឯកសារនោះ។
6. នៅលើកុំព្យូទ័រម្ខាងទៀត បើក **[en:tran:Setting]** ចុច **[en:tran:Import Settings]** ហើយជ្រើសឯកសារនោះ។ ឯកសារដែលមានការការពារ នឹងសួររកពាក្យសម្ងាត់របស់វាជាមុនសិន។
7. ផ្ទាំងមួយរាយផ្នែកដែលឯកសារនោះមាន នៅក្រោមការព្រមាន **[en:tran:Each ticked section replaces the same section on this computer; what the file leaves out goes back to its default]**។ **[en:tran:Folders]**, **[en:tran:Screen Mirror & Virtual Displays]** និងសោ API ចាប់ផ្តើមដោយមិនបានធីក — ព្រោះវាប៉ះពាល់លើសពីរូបរាងរបស់កម្មវិធី។ 📸
8. ចុច **[en:tran:Ok]**។ សារមួយប្រាប់ថា មានការកំណត់ប៉ុន្មានត្រូវបានសរសេរ ហើយប៉ុន្មានបានត្រឡប់ទៅលំនាំដើមវិញ។ បន្ទាប់មក កម្មវិធីស្នើផ្ទុកបង្អួចរបស់វាឡើងវិញ (**[en:tran:Apply Settings]**) ឬចាប់ផ្តើមកម្មវិធីឡើងវិញ ពេលផ្នែកដែលបានធីក ត្រូវបានអានតែនៅពេលចាប់ផ្តើមប៉ុណ្ណោះ (**[en:tran:Screens & Monitors]**, **[en:tran:Screen Mirror & Virtual Displays]**)។

> កំណត់សម្គាល់៖ ការនាំចូល **ជំនួស** ផ្នែកនីមួយៗដែលបានធីក មិនមែនបន្ថែមលើវាទេ — ការកំណត់អក្សររត់ដែលបានប្តូរនៅទីនេះ ប៉ុន្តែមិនមាននៅក្នុងឯកសារ នឹងត្រឡប់ទៅលំនាំដើមវិញ ហើយផ្នែកដែលមិនបានធីក មិនត្រូវបានប៉ះពាល់ទាល់តែសោះ។
> អ្វីដែលមិនដែលត្រូវបានផ្ទេរ ទោះបីធីកអ្វីក៏ដោយ៖ ថតទិន្នន័យណាដែលកម្មវិធីប្រើ អត្តសញ្ញាណរបស់កុំព្យូទ័រនេះនៅលើបណ្ដាញ និងឧបករណ៍ដែលវាទុកចិត្ត ថាតើមុខងារ AI ត្រូវបានបើកឬអត់ ការសន្ទនាជាមួយជំនួយការ និងអ្វីដែលកំពុងនៅលើអេក្រង់ឥឡូវនេះ។
> បង្អួចម៉ាស៊ីនបញ្ចាំងដែលកំពុងបើក រក្សារូបរាងចាស់របស់វា រហូតដល់វាត្រូវបានបើកម្ដងទៀត។
> ការចូលគណនី SongSelect ដែលបានចម្លងតាមវិធីនេះ អាចធ្វើឲ្យកុំព្យូទ័រមួយក្នុងចំណោមកុំព្យូទ័រទាំងពីរ ត្រូវចេញពីគណនី នៅពេលបន្ទាប់ដែលកុំព្យូទ័រណាមួយធ្វើឲ្យការចូលនោះថ្មី។
