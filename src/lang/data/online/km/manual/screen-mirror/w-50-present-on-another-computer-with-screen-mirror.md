# W-50 — បង្ហាញលើកុំព្យូទ័រមួយទៀត ដោយប្រើ Screen Mirror

ប្រើកម្មវិធីមួយជាម៉ាស៊ីនមេ (host) និងមួយទៀតជាម៉ាស៊ីនភ្ញៀវ (guest)។ កុំព្យូទ័រទាំងពីរ ត្រូវការកំណែកម្មវិធី
ដូចគ្នា និងការតភ្ជាប់បណ្ដាញដែលអាចទៅដល់គ្នាបាន — បណ្ដាញតែមួយ ឬអ៊ីនធឺណិត នៅពេលម៉ាស៊ីនមេ
បើកទៅកាន់អ៊ីនធឺណិត (ជំហានទី 7)។

1. នៅលើទំព័រ ធ្វើបទបង្ហាញ របស់ម៉ាស៊ីនមេ សូមចុច **[en:tran:Mini Screen Options]** — សញ្ញា ⋮
   នៅខាងក្រោមស្ដាំ នៃបញ្ជីអេក្រង់តូច — ហើយនៅក្នុងម៉ឺនុយដែលវាបើក
   សូមចុច **[en:tran:Virtual Screens Manager]** បន្ទាប់មកជ្រើសរើសថេប
   **[en:tran:Screen Mirror Connection]** របស់ផ្ទាំងអណ្ដែត។ ផ្ទាំងនេះចងចាំ
   ថាថេបណាត្រូវបានបើក និងថាតើវាត្រូវបានបើកឬអត់។ ការធ្វើជាម៉ាស៊ីនមេត្រូវបានបិទ រហូតដល់អ្នក
   បើក **[en:tran:Let other computers connect]** នៅខាងលើថេប —
   មុនពេលនោះ គ្មានកុំព្យូទ័រផ្សេងណាអាចរកឃើញ ឬចូលរួមជាមួយកុំព្យូទ័រនេះបានទេ។
   នៅពេលវាបើក ផ្ទាំងបង្ហាញ **[en:tran:Host addresses]** និង
   **[en:tran:Port]**: កម្មវិធីផ្ដល់សេវា HTTP និង WebSocket នៅលើច្រកទំនេរមួយ
   ពី 39240–39259 ហើយកុងតាក់នៅតែបើក សម្រាប់ការបើកកម្មវិធីលើកក្រោយ។ នៅក្រោម
   **[en:tran:This network]** អាសយដ្ឋាននីមួយៗរបស់កុំព្យូទ័រនេះ ត្រូវបានសរសេរជា
   `address:port` (ឧទាហរណ៍ `192.168.1.3:39240`) ជាមួយប៊ូតុងពីរ:
   **[en:tran:Copy address]** ដាក់អត្ថបទនោះទៅក្ដារតម្បៀតខ្ទាស់ ហើយ
   **[en:tran:QR code]** បង្ហាញវាជាកូដ QR នៅក្រោមជួរនោះ។ កូដនេះផ្ទុក
   អត្ថបទធម្មតាដដែល មិនមែនជាតំណទេ ដូច្នេះទូរសព្ទដែលស្កេនវា នឹងផ្ដល់ពាក្យទាំងនោះឲ្យចម្លង។
   **[en:tran:Copy image]** នៅក្រោមកូដ ចម្លងវាជារូបភាព
   ដោយមានអាសយដ្ឋានសរសេរនៅខាងក្រោម ដើម្បីផ្ញើទៅអ្នកដែលរៀបចំម៉ាស៊ីនភ្ញៀវ។
2. នៅលើម៉ាស៊ីនភ្ញៀវ សូមបើកទំព័រ **[en:tran:Screen Mirror]**។ វាគ្មានក្បាលកម្មវិធីទេ
   មានតែរបារខាងលើមួយ: **[en:tran:Presenter]** នៅខាងឆ្វេងរបស់វា នាំត្រឡប់ក្រោយវិញ ហើយ
   រូបពែងនៅខាងស្ដាំរបស់វា គឺ **[en:tran:Stay Awake]** — វាបើកជានិច្ច លុះត្រាតែអ្នកបិទវា
   វាការពារកុំព្យូទ័រនេះពីការដេក (sleep) ដរាបណាទំព័រនេះនៅបើក
   ដែលជាអ្វីដែលកុំព្យូទ័រដែលជំនួសម៉ាស៊ីនបញ្ចាំង ត្រូវការ។ ទំព័រនេះ
   ស្វែងរកម៉ាស៊ីនមេ នៅពេលវាបើក ហើយរាយពួកវានៅក្រោម
   **[en:tran:Hosts on this network]**។ **[en:tran:Rescan]** ស្វែងរកម្តងទៀត។
   ការស្កេនសួរនៅលើគ្រប់បណ្ដាញដែលកុំព្យូទ័រនេះភ្ជាប់ នៅគ្រប់ច្រកពី
   39240 ដល់ 39259។ ម៉ាស៊ីនមេដែលឆ្លើយតបនៅលើបណ្ដាញច្រើន ត្រូវបានរាយតែម្តង
   នៅលើអាសយដ្ឋានល្អបំផុតរបស់វា (LAN ពិតមុន adapter និម្មិត ឬ loopback) ហើយ
   ម៉ាស៊ីនមេទីមួយ ត្រូវបានបំពេញចូលក្នុង **[en:tran:Host address]** និង
   **[en:tran:Port]** នៅក្រោម **[en:tran:Connect by address]** — មិនដែលសរសេរជាន់លើ
   អាសយដ្ឋានដែលអ្នកបានវាយ ឬម៉ាស៊ីនមេដែលអ្នកបានជ្រើសរើសទេ។ ជ្រើសរើសម៉ាស៊ីនមេផ្សេង ឬវាយ
   អាសយដ្ឋាន បើចាំបាច់ បន្ទាប់មកចុច **[en:tran:Connect]**។ អាសយដ្ឋានដែលនរណាម្នាក់
   បានផ្ញើមកអ្នក មិនចាំបាច់វាយឡើងវិញទេ: **[en:tran:Paste address]** បំពេញ
   **[en:tran:Host address]** និង **[en:tran:Port]** ពីអ្វីដែលបាន
   ចម្លង — `address:port` តំណ `http://` ទាំងមូល អាសយដ្ឋាន IPv6 ក្នុង
   តង្កៀប ឬរូបភាពនៃកូដ QR របស់ម៉ាស៊ីនមេ — ហើយ
   **[en:tran:Read QR code]** ធ្វើដូចគ្នា ពីឯកសាររូបភាពដែលអ្នកជ្រើសរើស។
   ការបិទភ្ជាប់ `address:port` ចូលក្នុង **[en:tran:Host address]** ដោយផ្ទាល់ ក៏បំបែកវា
   ដែរ ហើយរូបភាពដែលបិទភ្ជាប់នៅកន្លែងណាមួយក្នុងទម្រង់ ត្រូវបានអានជាកូដ QR។
   ក្ដារតម្បៀតខ្ទាស់ដែលគ្មានអាសយដ្ឋាន នឹងបង្ហាញ
   **[en:tran:No host address found in the clipboard.]** ហើយទុកទម្រង់
   ដដែល។ នៅក្នុងរបៀបអនុម័ត ម៉ាស៊ីនភ្ញៀវបង្ហាញ
   **[en:tran:Waiting for host approval]** ខណៈពេលម៉ាស៊ីនមេចុច
   **[en:tran:Allow connection]** នៅក្នុងផ្ទាំងអណ្ដែត។
3. ម៉ាស៊ីនភ្ញៀវបង្ហាញ **[en:tran:Connected]** ហើយនៅក្រោម
   **[en:tran:This computer]** ម៉ូនីទ័ររបស់វា មានបុព្វបទដែលម៉ាស៊ីនមេស្គាល់
   វា ដូចជា a1 — ជាឈ្មោះដែលត្រូវជ្រើសរើស ក្នុងកម្មវិធីជ្រើសម៉ូនីទ័ររបស់ម៉ាស៊ីនមេ។ ម៉ាស៊ីនមេ
   រាយវានៅក្រោម
   **[en:tran:Connected guests]** ពីលើការមើលជាមុនអេក្រង់តូច និងនៅ
   ខាងលើម៉ឺនុយបញ្ជីរបស់ពួកវា។ ម៉ាស៊ីនភ្ញៀវនីមួយៗ មានបុព្វបទថេរ ដូចជា a1 ឬ a2។
   ចុចប៊ូតុងក្បាលរបស់វា ដើម្បីបើកផ្ទាំងអណ្ដែត នៅលើថេបដែលវាបានបើកចុងក្រោយ
   (ជួររបស់ម៉ាស៊ីនភ្ញៀវក្នុងម៉ឺនុយបញ្ជី បើកវានៅលើ
   **[en:tran:Screen Mirror Connection]**)។ នៅក្នុងផ្ទាំង ម៉ាស៊ីនភ្ញៀវ
   និងសំណើនីមួយៗ បង្ហាញថាវាមកពីណា:
   **[en:tran:This network]** សម្រាប់កុំព្យូទ័រនៅលើបណ្ដាញមួយរបស់ម៉ាស៊ីនមេផ្ទាល់
   ឬ **[en:tran:Internet]** — រូបផែនដី និងគែមពណ៌លឿងទុំ — សម្រាប់
   កុំព្យូទ័រមកពីខាងក្រៅ។ ប៊ូតុងក្បាលរបស់ម៉ាស៊ីនភ្ញៀវតាមអ៊ីនធឺណិត ក៏មានពណ៌លឿងទុំ
   និងរូបផែនដីដែរ។
4. ជ្រើសរើសម៉ូនីទ័រដែលមានបុព្វបទរបស់ម៉ាស៊ីនភ្ញៀវ នៅក្នុងកម្មវិធីជ្រើសម៉ូនីទ័រ នៃកាតអេក្រង់។
   បង្ហាញស្លាយមួយ និងរូបភាពផ្ទៃខាងក្រោយមួយ បន្ទាប់មកប្រើប៊ូតុងបង្ហាញរបស់កាត

   ដូច្នេះម៉ាស៊ីនភ្ញៀវដែលទៅដល់ម៉ាស៊ីនមេតាមរយៈរ៉ោតទ័រ ក៏ទទួលបានពួកវាតាមរយៈ
