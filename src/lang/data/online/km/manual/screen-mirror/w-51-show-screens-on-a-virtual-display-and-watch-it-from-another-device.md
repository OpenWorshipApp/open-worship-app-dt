# W-51 — បង្ហាញអេក្រង់លើម៉ូនីទ័រនិម្មិត ហើយមើលវាពីឧបករណ៍ផ្សេង

ម៉ូនីទ័រនិម្មិត គឺជាម៉ូនីទ័រដែលមានតែនៅក្នុងកម្មវិធីប៉ុណ្ណោះ។ អេក្រង់ត្រូវបានបង្ហាញលើវា ដូចលើម៉ូនីទ័រពិតដែរ ហើយទូរស័ព្ទ ទូរទស្សន៍ ឬកុំព្យូទ័រណាក៏ដោយ អាចមើលវាបាន — ក្នុងកម្មវិធីរុករកបណ្ដាញ (web browser) ឬជាវីដេអូក្នុងកម្មវិធីចាក់មេឌៀ — ដោយមិនចាំបាច់មានខ្សែ ឬកម្មវិធីនេះច្បាប់ទីពីរទេ។
1. នៅលើទំព័រធ្វើបទបង្ហាញ ចុច **[en:tran:Mini Screen Options]** — សញ្ញា ⋮ នៅជ្រុងខាងក្រោមខាងស្ដាំនៃបញ្ជីអេក្រង់តូច — ហើយនៅក្នុងម៉ឺនុយដែលវាបើក ចុច **[en:tran:Virtual Screens Manager]** រួចជ្រើសរើសថេប **[en:tran:Virtual Displays]** របស់ផ្ទាំងអណ្ដែតនោះ (វាបើកលើថេបដែលវាបាននៅលើកចុងក្រោយ)។ ឧបករណ៍ជ្រើសរើសម៉ូនីទ័ររបស់កាតអេក្រង់ ក៏នាំទៅទីនោះដែរ៖ ជួរចុងក្រោយរបស់វា **[en:tran:Manage Virtual Displays]** បើកថេបដដែលនោះ។

4. នៅក្នុងឧបករណ៍ជ្រើសរើសម៉ូនីទ័ររបស់កាតអេក្រង់ ជ្រើសរើសម៉ូនីទ័រនោះ — វាត្រូវបានរាយជាឈ្មោះរបស់វា **[en:tran:Virtual]** និងទំហំរបស់វា ដូចជា `Virtual Display 1 (Virtual): 1920x1080`។ បង្ហាញអ្វីមួយ ហើយប្រើប៊ូតុងបង្ហាញរបស់កាត (F5)៖ គ្មានបង្អួចណាបើកលើម៉ូនីទ័រណាមួយទេ; អេក្រង់បង្ហាញលើម៉ូនីទ័រនិម្មិតជំនួសវិញ ពីលើរូបផ្ទៃខាងក្រោយរបស់វា។ អេក្រង់ច្រើនលើម៉ូនីទ័រតែមួយ ត្រូវបានដាក់ត្រួតគ្នាតាមលំដាប់ដែលវាត្រូវបានបង្ហាញ ដូចដែលវានឹងនៅលើម៉ូនីទ័រពិតដែរ ហើយកាតនោះប្រាប់ពីរឿងនេះ ពេលវាកំពុងត្រួតគ្នា។ **[en:tran:Screens on this display]** នៅក្រោម **[en:tran:Settings]** រាយពួកវា។ ពេលគ្មានម៉ូនីទ័រទីពីរដោត ចម្រៀង និងស្លាយថ្មីៗ ត្រូវបានរៀបចំតាមទំហំម៉ូនីទ័រនិម្មិត ដូច្នេះវាពេញម៉ូនីទ័រនោះ។ អេក្រង់ដែលកំពុងបង្ហាញលើម៉ូនីទ័រនិម្មិត នឹងបង្ហាញម្ដងទៀត ជាមួយអ្វីដែលវាមាន នៅពេលកម្មវិធីចាប់ផ្ដើមលើកក្រោយ ដូច្នេះអ្នកមើលរបស់វាមិនត្រូវបានទុកឲ្យមើលតែរូបផ្ទៃខាងក្រោយទេ; លាក់វា (F5) វានឹងនៅលាក់ដដែល។ អេក្រង់លើម៉ូនីទ័រពិត មិនដែលបើកឡើងដោយខ្លួនឯងទេ ហើយការទៅទំព័រអានព្រះគម្ពីរ ដែលលាក់អេក្រង់ទាំងអស់ នឹងរក្សាពួកវាទាំងអស់ឲ្យនៅលាក់។
