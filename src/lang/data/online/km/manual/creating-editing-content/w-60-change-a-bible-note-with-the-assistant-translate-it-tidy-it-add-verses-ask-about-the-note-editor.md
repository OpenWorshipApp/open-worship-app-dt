4. ចម្លើយប្រាប់ពីអ្វីដែលបានផ្លាស់ប្ដូរ។ មានតែផ្នែកដែលបានសួរប៉ុណ្ណោះ ដែលត្រូវបានសរសេរឡើងវិញ៖ ផ្នែកដែលនៅសល់នៃកំណត់ត្រា — ចំណងជើង បញ្ជី ការលើកឡើងខគម្ពីរ តារាង រូបភាព គំនូរ និងកំណត់ចំណាំស្អិតរបស់វា — នៅដដែលដូចមុន។ តារាង រូបភាព គំនូរ កំណត់ចំណាំស្អិត ឬវគ្គបទគម្ពីរ អាចផ្លាស់ទី ឬដកចេញបាន ប៉ុន្តែមិនដែលសរសេរឡើងវិញទេ។ ការផ្លាស់ប្ដូរ **មិនទាន់បានរក្សាទុកនៅឡើយទេ** បង្អួច **[en:tran:Bible Note]** ដែលបើកលើកំណត់ត្រា បង្ហាញវាភ្លាមៗ។ **[en:tran:Undo this change]** នៅក្រោមចម្លើយដាក់វាត្រឡប់វិញ ហើយ **[en:tran:Show it in the list]** រកឃើញជួររបស់វា។ ពាក្យដែលអ្នកបានវាយ ដើម្បីដាក់ចូលកំណត់ត្រា ចូលទៅតាមអក្សរនីមួយៗ ដូចដែលអ្នកបានវាយ។ ប្រសិនបើជំនួយការផ្លាស់ប្ដូរកំណត់ត្រា ហើយបន្ទាប់មកឈប់ដោយគ្មានចម្លើយ ចម្លើយនៅតែប្រាប់ថាកំណត់ត្រាត្រូវបានផ្លាស់ប្ដូរ ជាមួយប៊ូតុងពីរដដែលនៅខាងក្រោម។
