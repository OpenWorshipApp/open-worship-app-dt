# W-56 — កែសម្រួលចម្រៀងជាមួយជំនួយការ (បកប្រែវា បន្ថែមផ្នែកមួយ អាកូដ សូរគន្លឹះរបស់វា)

**គោលដៅ៖** ឱ្យបង្អួចជំនួយកែចម្រៀងមួយរបស់អ្នកជំនួសអ្នក — ដាក់វាជាភាសាផ្សេង បន្ថែមឃ្លាមួយ ឬកំណត់ចំណាំមួយសម្រាប់ក្រុមតន្ត្រី កែពាក្យរបស់វា បន្ថែមអាកូដ ឬប្ដូរវាទៅសូរគន្លឹះផ្សេង — ដោយអ្នកមិនចាំបាច់សរសេរសញ្ញាណផ្ទាល់របស់ចម្រៀងនោះទេ។

1. នៅក្នុង **[en:tran:Documents]** ចុចកណ្ដុរស្ដាំលើចម្រៀងមួយ (ជួរដែលមានរូប 🎵) ឬចុច **⋮** ស្រាលៗនៅចុងខាងស្ដាំរបស់វា (W-01b) ហើយជ្រើសរើស **[en:tran:Open in Chatbot]**។ 📸 នៅក្នុង **[en:tran:Lyric Editor]** ប៊ូតុងរូបយន្ត នៅខាងឆ្វេងប៊ូតុង **Reset** និង **Save** ធ្វើដូចគ្នាសម្រាប់ចម្រៀងដែលវាបង្ហាញ។
2. បង្អួចជំនួយបើកការជជែកមួយរបស់វាផ្ទាល់ ដោយមានចម្រៀងនោះភ្ជាប់នៅក្រោមប្រអប់ និងកាតមួយដែលប្រាប់ពីអ្វីដែលវាអាចកែបាន៖ បន្ថែមឃ្លាមួយ ឬផ្នែកផ្សេងទៀត កែពាក្យរបស់វា បកប្រែវា បន្ថែមអាកូដ ប្ដូរសូរគន្លឹះរបស់វា ឬរៀបលំដាប់ផ្នែករបស់វាឡើងវិញ ឬដកផ្នែកណាមួយចេញ។ 📸
3. ចុចប៊ូតុងនៅក្រោមកាត ឬវាយអ្វីដែលអ្នកចង់បាន៖
   - **ជំនួសពាក្យដោយ …** ដាក់ចម្រៀងជាភាសានោះជំនួសពាក្យរបស់វា ព្រមទាំងចំណងជើង និងចំណងជើងរងរបស់វាផងដែរ។ សូមធ្វើការនេះលើច្បាប់ចម្លងមួយ (**[en:tran:Duplicate]** នៅក្នុងម៉ឺនុយរបស់ជួរ) នៅពេលអ្នកចង់បានទាំងពីរភាសា៖ ច្បាប់ចម្លងរក្សាផ្នែកដដែល តាមលំដាប់ដដែល ដែលជាអ្វីដែល **[en:tran:Long Text Show]** ត្រូវការ ដើម្បីបង្ហាញពួកវានៅក្បែរគ្នា (W-53)។
   - **បន្ថែម … នៅក្រោមបន្ទាត់នីមួយៗ** រក្សាពាក្យ ហើយសរសេរការបកប្រែនៅក្រោមបន្ទាត់នីមួយៗ៖ ចម្រៀងមួយជាពីរភាសា។
   - ភាសាដែលផ្ដល់ជូន គឺភាសាដែលឈ្មោះចម្រៀងប្រាប់ (`Still khmer`) បើមិនដូច្នោះទេ គឺភាសាដែលកម្មវិធីបង្ហាញ។ បើគ្មានទាំងពីរ ប៊ូតុងនិយាយថា _another language_ ហើយជំនួយការសួរថាភាសាណា។ ពេលត្រូវបានសុំឱ្យបកប្រែ ដោយមិនបានប្រាប់ថាបកពីភាសាណាទៅភាសាណា វាសួររឿងនោះជាមុនសិន។
   - **[en:tran:Add a section]**, **[en:tran:Add chords]** និង **[en:tran:Change the key]**៖ ជំនួយការសួររកពាក្យ ឬសូរគន្លឹះ នៅពេលវាត្រូវការ។ កំណត់ចំណាំសម្រាប់ក្រុមតន្ត្រី គឺជាផ្នែកមួយដាច់ដោយឡែក ដែលមិនដែលត្រូវបានដាក់បង្ហាញលើអេក្រង់ទេ។
   - វាយជាពាក្យរបស់អ្នកផ្ទាល់៖ _បកប្រែវាជាភាសាខ្មែរ_ _បន្ថែមឃ្លាមួយបន្ទាប់ពីឃ្លាទី 2៖ …_ _ប្ដូរវាទៅសូរគន្លឹះ G_ _ដកផ្នែក Bridge ចេញ_។
4. ចម្លើយប្រាប់ពីអ្វីដែលបានផ្លាស់ប្ដូរ។ ការផ្លាស់ប្ដូរ **មិនទាន់បានរក្សាទុកនៅឡើយទេ**៖ ចម្រៀងបង្ហាញសញ្ញា **\*** ពណ៌ក្រហម នៅក្បែរឈ្មោះរបស់វាក្នុង **[en:tran:Documents]**។ **[en:tran:Undo this change]** នៅក្រោមចម្លើយដាក់វាត្រឡប់វិញ ហើយ **[en:tran:Show it in the list]** រកឃើញជួររបស់វា។
5. ដើម្បីរក្សាវាទុក ចុច **[en:tran:Save]** នៅក្នុងជួរនៅក្រោមក្បាល **[en:tran:Stage Previewer]** របស់ចម្រៀង ក្នុងទំព័រធ្វើបទបង្ហាញ (**[en:tran:Undo]** នៅទីនោះក៏ធ្វើឱ្យវាថយក្រោយវិញដែរ) ឬបើកចម្រៀងដោយ **[en:tran:Edit]** នៅក្នុងម៉ឺនុយរបស់វា ហើយចុច **Save**។ កម្មវិធីកែសម្រួលទំនុកច្រៀងដែលបើកលើចម្រៀងនោះរួចហើយ បង្ហាញការផ្លាស់ប្ដូរដោយខ្លួនឯង។ ប្រសិនបើអ្នកកំពុងវាយនៅក្នុងវានៅពេលនោះ អ្វីដែលអ្នកបានវាយនៅតែមាន ហើយបន្ទាត់
