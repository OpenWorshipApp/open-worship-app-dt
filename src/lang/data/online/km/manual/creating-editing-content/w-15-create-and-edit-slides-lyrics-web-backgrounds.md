# W-15 — បង្កើត និងកែសម្រួលស្លាយ / ទំនុកចម្រៀង / ផ្ទៃខាងក្រោយគេហទំព័រ

**ការបង្កើតហ្វាល់ថ្មី:** នៅក្នុងបញ្ជី **[en:tran:Documents]** ចុច **⋮** នៅក្បាលបញ្ជី (ឬចុចកណ្ដុរស្ដាំលើកន្លែងទទេនៃបញ្ជី) ហើយជ្រើសរើស **[en:tran:New App Document]** (ឯកសារស្លាយ) ឬ **[en:tran:New Lyric]** (ចម្រៀង)។ វាយឈ្មោះមួយចូលក្នុងជួរដែលលេចឡើង ហើយចុច **Enter** (ឬចុច ✓)។ ប្រភេទទាំងពីរនេះ ស្ថិតនៅក្នុងថតឯកសារដដែល។ 📸

**ស្លាយ** ([en:tran:Slide Editor])៖

1. ជ្រើសរើសឯកសារស្លាយមួយ រួចចុចថេប **[en:tran:Slide Editor]** នៅរបារខាងលើ។ 📸
2. ខាងឆ្វេង៖ បញ្ជីស្លាយ — ចុចដើម្បីជ្រើសរើស អូសដើម្បីប្ដូរលំដាប់។ ចុចកណ្ដុរស្ដាំលើកន្លែងទទេរបស់វា → **[en:tran:New Slide]**; ចុចកណ្ដុរស្ដាំលើស្លាយមួយ → **[en:tran:Duplicate]** / **[en:tran:Delete]**។
3. ផ្ទាំងគូរ (canvas)៖ ចុចប្រអប់មួយដើម្បីជ្រើសរើសវា; អូសដើម្បីផ្លាស់ទី; អូសចំណុចចាប់ (handles) ដើម្បីប្ដូរទំហំ; **ចុចពីរដងលើប្រអប់អក្សរ** ដើម្បីវាយអក្សរចូល; **Ctrl+Enter** ផ្ដោតលើផ្ទាំងគូរ។ 📸 (ពី **[en:tran:Presenter]** ចុចកណ្ដុរស្ដាំលើស្លាយមួយ → **[en:tran:Edit] ↗** បើកកម្មវិធីកែសម្រួលនេះក្នុងបង្អួចផ្ទាល់ខ្លួន ដោយផ្ដោតលើស្លាយនោះ។)
4. បន្ថែមប្រអប់ថ្មីៗ ដោយប្រើរបារឧបករណ៍នៅខាងលើផ្ទាំងគូរ — **[en:tran:New]**, **[en:tran:Insert Medias]**, **[en:tran:Insert Media Link]**, **[en:tran:Insert YouTube]**, **[en:tran:Insert Website]**, **[en:tran:Insert Camera]** — ឬបញ្ជីដដែលពីការចុចកណ្ដុរស្ដាំលើផ្ទាំងគូរ។ (ថេប **[en:tran:Canvas Items]** ខាងស្ដាំ គឺជាបញ្ជីសម្រាប់មើល/ជ្រើសរើស មិនមែនជាកន្លែងសម្រាប់អូសប្រអប់ចេញទេ។) អ្នកក៏អាច **អូសធាតុចូលពីផ្ទាំងផ្ទៃខាងក្រោយ** បានដែរ — សូមមើល W-28។
   **បញ្ចូលវីដេអូពីតំណ។** នៅក្នុង **[en:tran:Slide Editor]** ជ្រើសស្លាយ ចុច **[en:tran:Insert Media Link]** នៅខាងលើផ្ទាំងគូរ បិទភ្ជាប់អាសយដ្ឋានវីដេអូផ្ទាល់ទៅក្នុង **[en:tran:Media URL:]** ហើយចុច **[en:tran:Ok]**។ សម្រាប់អាសយដ្ឋាន YouTube ប្រើ **[en:tran:Insert YouTube]** និងប្រអប់ **[en:tran:YouTube URL:]** របស់វាជំនួសវិញ រួចចុច **[en:tran:Ok]**។ ផ្លាស់ទី ឬកែទំហំប្រអប់ថ្មីលើស្លាយ ហើយរក្សាទុកដោយចុច **Ctrl+S**។
   **បញ្ចូលកាមេរ៉ាលើស្លាយ។** ជ្រើសស្លាយក្នុង **[en:tran:Slide Editor]** ចុច **[en:tran:Insert Camera]** រួចជ្រើសឈ្មោះកាមេរ៉ាពីម៉ឺនុយឧបករណ៍ដែលបើកឡើង។ ការជ្រើសឧបករណ៍នឹងបន្ថែមប្រអប់កាមេរ៉ារបស់វាទៅលើស្លាយ។ ផ្លាស់ទី ឬកែទំហំប្រអប់ ហើយរក្សាទុកដោយចុច **Ctrl+S**។ ប្រសិនបើកម្មវិធីប្រាប់ថា **[en:tran:No camera found]** សូមភ្ជាប់កាមេរ៉ា ហើយសាកម្ដងទៀត។
5. **ប្រអប់គេហទំព័របង្ហាញរូបភាពនៃទំព័រ មិនមែនទំព័រដែលកំពុងដំណើរការទេ។** Open Worship ថតរូបអេក្រង់ ហើយបង្ហាញរូបនោះគ្រប់កន្លែងដែលអ្នកកែសម្រួល ដូច្នេះកម្មវិធីថ្វាយបង្គំដែលមានស្លាយគេហទំព័រច្រើន នៅតែលឿន សូម្បីតែលើម៉ាស៊ីនចាស់។ មានរឿងពីរកើតឡើងពីនេះ៖
   - **ដាក់កណ្ដុរលើប្រអប់នោះប្រហែលមួយវិនាទី** ដើម្បីមើលទំព័រផ្ទាល់; រំកិលកណ្ដុរចេញ រូបភាពនឹងមកវិញ។ 📸
   - រូបភាពនោះមិនធ្វើបច្ចុប្បន្នភាពដោយខ្លួនឯងទេ។ បើទំព័រនោះប្រែប្រួល (នាឡិកា ការរាប់ថយក្រោយ តារាងពិន្ទុ) សូមចុចកណ្ដុរស្ដាំលើប្រអប់នោះ → **[en:tran:Refresh Preview]**។

   នៅពេលអ្នកបង្ហាញស្លាយនោះពិតប្រាកដ អេក្រង់អ្នកទស្សនាបង្ហាញ **ទំព័រពិត ដែលកំពុងដំណើរការផ្ទាល់** — មានតែទិដ្ឋភាពកែសម្រួល និងមើលជាមុនរបស់អ្នកប៉ុណ្ណោះ ដែលប្រើរូបភាព។

6. **លាយប្រអប់មួយជាមួយប្រអប់ដែលនៅពីក្រោមវា។** ជ្រើសរើសប្រអប់មួយ ហើយនៅក្រោម **[en:tran:Shape Properties]** ក្នុងថេប **[en:tran:Properties]** ខាងស្ដាំ ជ្រើសរើស **[en:tran:Blend Mode]** — **[en:tran:Multiply]** ដើម្បីធ្វើឲ្យងងឹត **[en:tran:Screen Blend]** ដើម្បីដកពណ៌ខ្មៅចេញពីឃ្លីប **[en:tran:Overlay]** សម្រាប់វាយនភាព (texture) លើរូបថត។ វាលាយជាមួយ **ធាតុផ្ទាំងគូរដែលនៅពីក្រោមវាក្នុងស្លាយដដែល** ដូច្នេះវាបង្ហាញតែត្រង់កន្លែងដែលប្រអប់នោះត្រួតលើប្រអប់មួយទៀតប៉ុណ្ណោះ; ដាក់ប្រអប់រូបភាព ឬវីដេអូមួយនៅពីក្រោយ ដែលមានទំហំ **[en:tran:Full]** ហើយលាយពីលើវា។ វា **មិន** ទៅដល់ផ្ទៃខាងក្រោយដែលអ្នកបានភ្ជាប់ទៅស្លាយទេ។ **[en:tran:Normal]** បិទវាវិញ។
7. **ដាក់ស្រមោលឲ្យប្រអប់មួយ។** នៅក្នុងក្រុម **[en:tran:Shape Properties]** ដដែល ជ្រើសរើស **[en:tran:Shadow]**។ មានពីរប្រភេទ ហើយវាមិនដូចគ្នាទេ៖
   - **[en:tran:Box Shadow]** គឺជាស្រមោលរបស់ប្រអប់ខ្លួនឯង — រាងចតុកោណរបស់វា ជាមួយជ្រុងមូលណាមួយដែលអ្នកបានដាក់ឲ្យវា។ នេះជាស្រមោលសម្រាប់ប្រអប់អក្សរដែលមានពណ៌ផ្ទៃខាងក្រោយ។
   - **[en:tran:Drop Shadow]** គឺជាស្រមោលនៃអ្វីដែលពិតជាត្រូវបានគូរ ដូច្នេះវាតាមរាង **តួអក្សរ** នៃប្រអប់ដែលគ្មានពណ៌ផ្ទៃខាងក្រោយ និងគែមកាត់នៃរូបភាពឡូហ្គោ។ ការដាក់ស្រមោលប្រអប់ឲ្យឡូហ្គោថ្លា នឹងគូររាងចតុកោណមួយអណ្ដែតលើអាកាសនៅពីក្រោយវា — នេះជាការកំណត់ដែលជៀសវាងបញ្ហានោះ។

8. **អនុវត្តការកំណត់ពុម្ពអក្សរលើធាតុច្រើន។** នៅក្រោម **[en:tran:Properties]** ពង្រីក **[en:tran:Bulk Font]**។ ទុក **[en:tran:Apply to]** នៅលើ **[en:tran:All Slides]** សម្រាប់ឯកសារទាំងមូល ឬជ្រើសរើស **[en:tran:Choose slides and items]**។ ធីកស្លាយមួយ ដើម្បីជ្រើសរើសធាតុអក្សររបស់វា; ពង្រីកបញ្ជី **[en:tran:Canvas Items]** របស់វា ដើម្បីធីកធាតុនីមួយៗ។ អ្នកអាចផ្សំធាតុពីស្លាយច្រើន។ ស្លាយដែលត្រូវបានជ្រើសរើសមួយផ្នែក បង្ហាញសញ្ញាដាច់ (-) នៅក្នុងប្រអប់ធីករបស់វា។ ធាតុអក្សរ ព្រះគម្ពីរ និង HTML ត្រូវបានរួមបញ្ចូល; ធាតុមេឌៀគ្មានការកំណត់ពុម្ពអក្សរទេ។ ធាតុដែលបានចាក់សោ នៅដដែល លុះត្រាតែអ្នកធីក **[en:tran:Include locked items]**។ បញ្ចូល **[en:tran:Font Size]** ជាលេខវិជ្ជមាន គិតជាភីកសែល ហើយចុច **[en:tran:Apply Font Size]** ឬជ្រើសរើស **[en:tran:Font Family]** ហើយចុច **[en:tran:Apply Font Family]**។ ប៊ូតុងនីមួយៗអនុវត្តតែលក្ខណៈនោះប៉ុណ្ណោះ ដោយទុករចនាប័ទ្ម និងទីតាំងផ្សេងទៀតនៅដដែល។ លទ្ធផលរាយការណ៍ថាមានធាតុប៉ុន្មានត្រូវបានប្ដូរ។ ការអនុវត្តម្ដងៗ គឺជាជំហាន **[en:tran:Undo]** មួយ; **[en:tran:Redo]** អនុវត្តវាម្ដងទៀត។ ដើម្បីប្ដូរពណ៌អក្សរផងដែរ សូមជ្រើសរើសប្រអប់ ហើយចុចតម្លៃ hex នៅក្រោម **[en:tran:Text Properties] → [en:tran:Color]**។ វាយ ឬបិទភ្ជាប់ពណ៌ hex ថ្មី រួចចុច **Enter** ឬចុចកន្លែងផ្សេង ដើម្បីអនុវត្តវា (ជំហានទី 9)។ 📸
9. **វាយពណ៌ឲ្យចំពិតប្រាកដ។** ជ្រើសរើសប្រអប់មួយ រួចចុចតម្លៃ hex នៅក្បែរ **[en:tran:Background Color]** ឬនៅក្រោម **[en:tran:Text Properties] → [en:tran:Color]**។ វាយ ឬបិទភ្ជាប់ពណ៌ hex មួយ រួចចុច **Enter** ឬចុចកន្លែងផ្សេង ដើម្បីអនុវត្តវា។ តម្លៃ hex បី បួន ប្រាំមួយ និងប្រាំបីខ្ទង់ ប្រើបានទាំងអស់ មាន ឬគ្មាន `#` ក៏បាន; ប្រាំបីខ្ទង់រួមបញ្ចូលកម្រិតថ្លា ឧទាហរណ៍ `#2468AC80`។ **Escape** បោះបង់ការកែដែលមិនទាន់ចប់។ តម្លៃមិនត្រឹមត្រូវ ឬមិនពេញលេញ នឹងត្រឡប់ទៅពណ៌បច្ចុប្បន្នវិញ ដោយមិនប្ដូរស្លាយទេ។ ព្រួញនៅតែបើកគំរូពណ៌ និងរបាររំកិលកម្រិតថ្លា។ **[en:tran:Undo]** / **[en:tran:Redo]** ស្ដារ និងអនុវត្តការផ្លាស់ប្ដូរម្ដងទៀត។ 📸
10. រក្សាទុកដោយចុច **Ctrl+S**។

**HTML និងអត្ថបទធម្មតា:** HTML ដែលនាំចូល រក្សាទ្រង់ទ្រាយរបស់វា ប៉ុន្តែស្គ្រីប កម្មវិធីដោះស្រាយព្រឹត្តិការណ៍ (event handlers) និងទំព័របង្កប់ ត្រូវបានដកចេញនៅក្នុងកម្មវិធីកែសម្រួល ការមើលជាមុន ការបង្ហាញលើអេក្រង់ និងការបោះពុម្ព។ សូមប្រើ **[en:tran:Insert Website]** ឬ **[en:tran:Insert YouTube]** ដើម្បីបង្កប់ទំព័រ ឬវីដេអូ។ ប្រអប់ **អក្សរ** (Text) បង្ហាញកូដសម្គាល់ (markup) តាមដែលវាសរសេរ ហើយរក្សាការចុះបន្ទាត់; សូមប្រើប្រអប់ HTML សម្រាប់ទ្រង់ទ្រាយសម្បូរបែប។ ហ្វាល់ដែលមានស្រាប់ ត្រូវបានរក្សាទុកដូចដែលបានរក្សាទុក។
