# W-57 — កែសម្រួលស្លាយជាមួយជំនួយការ (បកប្រែវា ប្ដូររចនាប័ទ្មវា ធ្វើស្លាយដូចរូបភាព)

**គោលដៅ៖** ឱ្យបង្អួចជំនួយកែឯកសារស្លាយមួយរបស់អ្នកជំនួសអ្នក — ដាក់ពាក្យរបស់វាជាភាសាផ្សេង ឬបន្ថែមភាសាមួយនៅក្រោមពាក្យទាំងនោះ ពិនិត្យអក្ខរាវិរុទ្ធ ធ្វើឱ្យអក្សរធំជាងមុន ប្ដូរពណ៌ និងប្លង់ បន្ថែម ចម្លង ផ្លាស់ទី ឬដកស្លាយចេញ ឬធ្វើស្លាយដែលមើលទៅដូចរូបភាពនៃស្លាយដែលអ្នកចូលចិត្ត។

1. នៅក្នុង **[en:tran:Documents]** ចុចកណ្ដុរស្ដាំលើឯកសារស្លាយមួយ (ជួរដែលមានរូបស្លាយ) ឬចុច **⋮** ស្រាលៗនៅចុងខាងស្ដាំរបស់វា (W-01b) ហើយជ្រើសរើស **[en:tran:Open in Chatbot]** នៅខាងក្រោម **[en:tran:Open Slides Preview]**។ 📸 នៅក្នុង **[en:tran:Slide Editor]** ប៊ូតុងរូបយន្ត នៅខាងស្ដាំ **[en:tran:Undo]**, **[en:tran:Redo]**, **[en:tran:Discard changed]** និង **[en:tran:Save]** នៅខាងក្រោមផ្ទាំងគូរ ធ្វើដូចគ្នាសម្រាប់ឯកសារដែលកំពុងកែសម្រួល។
2. បង្អួចជំនួយបើកការជជែកមួយរបស់វាផ្ទាល់ ដោយមានឯកសារនោះភ្ជាប់នៅក្រោមប្រអប់ និងកាតមួយដែលប្រាប់ពីអ្វីដែលវាអាចកែបាន ជាមួយប៊ូតុងប្រាំ។ 📸
3. ចុចប៊ូតុងនៅក្រោមកាត ឬវាយអ្វីដែលអ្នកចង់បាន៖
   - **ជំនួសពាក្យដោយ …** ដាក់ពាក្យរបស់ស្លាយជាភាសានោះជំនួសពាក្យរបស់វា **បន្ថែម … នៅក្រោមបន្ទាត់នីមួយៗ** រក្សាពាក្យ ហើយសរសេរការបកប្រែនៅលើបន្ទាត់ខាងក្រោមបន្ទាត់នីមួយៗ ដោយធ្វើឱ្យអក្សរតូចជាងមុនបន្តិច ដើម្បីឱ្យប្រអប់នៅតែដាក់វាបានគ្រប់។ ភាសាដែលផ្ដល់ជូន គឺភាសាដែលឈ្មោះឯកសារប្រាប់ បើមិនដូច្នោះទេ គឺភាសាដែលកម្មវិធីបង្ហាញ។ បើគ្មានទាំងពីរ ប៊ូតុងនិយាយថា _another language_ ហើយជំនួយការសួរថាភាសាណា។ ពេលវាយ សូមប្រាប់ភាសា៖ _បន្ថែមភាសាអេស្ប៉ាញនៅក្រោមបន្ទាត់នីមួយៗ_។
   - **[en:tran:Check the spelling]** កែតែអ្វីដែលសរសេរខុស ហើយប្រាប់ពីអ្វីដែលវាបានកែ។
   - **[en:tran:Make the words larger]** ធ្វើឱ្យអក្សរនៃប្រអប់នីមួយៗធំជាងមុន ក្នុងការផ្លាស់ប្ដូរតែមួយ ដោយប្រអប់នីមួយៗរក្សាទំហំរបស់វាធៀបនឹងប្រអប់ផ្សេងទៀត (ចំណងជើងនៅតែធំជាងបន្ទាត់នៅក្រោមវា)។ បើវាយ _ធ្វើឱ្យអក្សរតូចជាងមុន_ ឬ _ធ្វើឱ្យអក្សរទាំងអស់ 110 px_ ក៏ធ្វើដូចគ្នាដែរ។ ការទាំងបីនេះ បង្អួចជំនួយធ្វើដោយខ្លួនឯងភ្លាមៗ — មិនត្រូវការជំនួយការសម្រាប់វាទេ ដូច្នេះវាដំណើរការដោយគ្មានសោ AI និងគ្មានអ៊ីនធឺណិត។
   - **[en:tran:Make slides like a picture]**៖ ភ្ជាប់រូបភាពនៃស្លាយដែលអ្នកចង់បាន — 📷 នៅក្រោមប្រអប់ភ្ជាប់រូបភាពនៃកម្មវិធី ហើយរូបឃ្លីបក្រដាសភ្ជាប់ឯកសាររូបភាព — ហើយប្រាប់ថាស្លាយគួរមានពាក្យអ្វីខ្លះ ឧទាហរណ៍ _បន្ថែមស្លាយ 2 ដែលមើលទៅដូចស្លាយទី 2 ក្នុងរូបភាពនេះ៖ មួយសរសេរថា សូមស្វាគមន៍ មួយទៀតសរសេរថា ចូរយើងអធិស្ឋាន_ — ឬផ្ញើរូបភាពដោយគ្មានពាក្យអ្វីសោះ។ បើគ្មានរូបភាព វាសុំរូបភាពមួយ។ រូបថត ឬវីដេអូនៅពីក្រោយពាក្យ គឺជា **ផ្ទៃខាងក្រោយ** របស់ស្លាយ មិនមែនជាប្រអប់ទេ៖ ជំនួយការដាក់រូបភាព ឬវីដេអូមួយ ក្នុងចំណោមរូបភាព ឬវីដេអូផ្ទាល់របស់ផ្ទាំង **[en:tran:Background]** នៅពីក្រោយស្លាយ គឺមួយដែលឈ្មោះរបស់វាត្រូវគ្នា (_mountain_ រកឃើញ `wp_mountain_reflection.jpg`) ហើយប្រាប់ថាវាជាមួយណា។ នៅពេលគ្មានមួយណាត្រូវគ្នាទេ សូមទម្លាក់រូបភាពនោះចូលទៅក្នុងរូបភាពរបស់ផ្ទាំង **[en:tran:Background]** ជាមុនសិន ហើយសួរម្ដងទៀត។
   - **ផ្ទៃខាងក្រោយ** តាមពាក្យ៖ _ដាក់រូបភាពថ្ងៃរះនៅពីក្រោយស្លាយនីមួយៗ_ _ធ្វើឱ្យផ្ទៃខាងក្រោយរបស់ស្លាយទី 3 ទៅជាពណ៌ខៀវចាស់_ _ដកផ្ទៃខាងក្រោយចេញពីស្លាយទី 2_។ ផ្ទៃខាងក្រោយ **ត្រូវបានរក្សាទុកភ្លាមៗ** — វាមិនមែនជាការផ្លាស់ប្ដូរមួយក្នុងចំណោមការផ្លាស់ប្ដូរដែលមិនទាន់បានរក្សាទុកទេ ហើយមិនចាំបាច់ចុចរក្សាទុកទេ — ហើយកាតស្លាយបង្ហាញវា។
   - _list me more options_ វាយជាភាសាអង់គ្លេស បង្ហាញកាត និងប៊ូតុងរបស់វាម្ដងទៀត។ សួរជាភាសាខ្មែរ ជំនួយការជាអ្នកឆ្លើយ ដោយបញ្ចប់ដោយជម្រើសរបស់វាផ្ទាល់។
