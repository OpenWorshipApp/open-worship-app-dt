# W-65 — កែឯកសារ PowerPoint ឬ Word ជាមួយជំនួយការ

**គោលដៅ:** ឲ្យបង្អួចជំនួយកែឯកសារ PowerPoint (`.pptx`) ឬ Word (`.docx`) ក្នុងបញ្ជី Documents របស់អ្នក
ជំនួសអ្នក — កែអក្ខរាវិរុទ្ធ ប្ដូរពាក្យមួយនៅគ្រប់កន្លែង សរសេរឡើងវិញ បន្ថែម ឬដកបន្ទាត់មួយចេញ
ប្ដូរកំណត់ចំណាំរបស់អ្នកធ្វើបទបង្ហាញនៃស្លាយមួយ បន្ថែមស្លាយពីប្លង់មួយ ចម្លង ផ្លាស់ទី លាក់ ឬដកស្លាយមួយចេញ
ប្ដូររូបរាងរបស់ពាក្យ (ពណ៌ ទំហំ អក្សរដិត ពុម្ពអក្សរ ការតម្រឹម បន្ទាត់កាត់ពីលើ តំណ) ឬផ្ទៃខាងក្រោយរបស់ស្លាយ
(ពណ៌មួយ ពណ៌ច្រើនលាយបន្តគ្នា ឬលំនាំ) ផ្លាស់ទី ប្ដូរទំហំ ដាក់ពណ៌ បង្វិល ឬត្រឡប់ប្រអប់មួយ
បន្ថែមប្រអប់អត្ថបទ រាង ការប្ដូរស្លាយ (transition) ចលនា (animation) លេខស្លាយ បាតកថា រូបភាព វីដេអូ
ឬសំឡេង កែតារាង គំនូសតាង ពាក្យ ឬពណ៌ និងរាងក្នុងដ្យាក្រាម SmartArt ប្ដូរអ្វីដែលស្លាយមេ (slide
