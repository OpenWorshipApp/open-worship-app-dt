# W-14 — រក្សាកំណត់ត្រាព្រះគម្ពីរ

**គោលដៅ:** ភ្ជាប់កំណត់ត្រាផ្ទាល់ខ្លួនរបស់អ្នក ទៅនឹងការសិក្សា។

1. រកផ្ទាំង **[en:tran:Bible Notes]**។ វាជាផ្ទាំងមួយ មិនមែនជាថេបទេ៖ វានៅក្បែរ **[en:tran:Bibles]** (នៅខាងក្រោមវា ពេលជួរឈរតូចចង្អៀត) នៅក្នុងផ្នែក **[en:tran:Bible and Notes]** — នៅខាងលើនៃជួរឈរខាងស្ដាំ ក្នុងទំព័រធ្វើបទបង្ហាញ ហើយនៅខាងឆ្វេង ក្នុងទំព័រអានព្រះគម្ពីរ។
   **ការបង្កើតឯកសារថ្មី:** ចុច **⋮ [en:tran:More Options]** នៅក្នុងចំណងជើងរបស់ផ្ទាំង (ឬចុចកណ្ដុរស្ដាំលើកន្លែងទំនេរនៅក្រោមឯកសារ) ហើយជ្រើស **[en:tran:New Bible Note]** (ឯកសារកំណត់ត្រា ដែលផ្ទុកកំណត់ត្រានានា) ឬ **[en:tran:New Markdown File]** (ទំព័រ `.md` ផ្ទាល់ខ្លួនរបស់អ្នក)។ វាយឈ្មោះមួយ ហើយចុច **Enter**។ ឯកសារ Markdown ត្រូវបានរាយជាមួយរូបតំណាង markdown ក្នុងចំណោមឯកសារកំណត់ត្រា បន្ទាត់ទីមួយរបស់វាគឺជាឈ្មោះ ក្នុងទម្រង់ជាចំណងជើង ហើយវាបើកក្នុងបង្អួច **Markdown Preview** ផ្ទាល់ខ្លួនរបស់វា — ចុចជួររបស់វា ដើម្បីបើកវាម្ដងទៀត ហើយចុច **[en:tran:Edit]** នៅទីនោះ ដើម្បីសរសេរ (W-37 ជំហាន 6)។ ម៉ឺនុយនៃជួររបស់វា បន្ថែម **[en:tran:Preview]**, **[en:tran:Open in Chatbot]** (ពេលមុខងារ AI បើក) និង **[en:tran:Open in Default App]** ទៅលើធាតុធម្មតា — កែឈ្មោះ ស្ទួន ផ្ទុកឡើងវិញ ចម្លងផ្លូវ បង្ហាញទីតាំង និង **[en:tran:Move to Trash]**។ ឯកសារ Markdown ដែលទម្លាក់លើផ្ទាំងនេះ ត្រូវបានចម្លងចូលក្នុងថតរបស់វា ដូចឯកសារកំណត់ត្រាដែរ។ 📸
2. បើកកំណត់ត្រាមួយដើម្បីកែសម្រួល — កម្មវិធីកែ **កំណត់ត្រាព្រះគម្ពីរ** បើកក្នុងបង្អួចដាច់ដោយឡែករបស់វា។ 📸
3. វាយកំណត់ត្រារបស់អ្នក។ មិនទាន់មានអ្វីត្រូវបានសរសេរចូលក្នុងឯកសារកំណត់ត្រានៅឡើយទេ — អ្វីដែលអ្នកវាយ ត្រូវបានរក្សាទុកក្នុងប្រវត្តិនៃការកែសម្រួល ហើយជួរប៊ូតុងដែលលេចឡើងនៅជ្រុងខាងក្រោមខាងស្ដាំនៃបង្អួច គឺជាកន្លែងដែលអ្នកសម្រេចថា ត្រូវធ្វើអ្វីជាមួយវា។
4. ចុច **[en:tran:Save]** (**Ctrl+S**) ដើម្បីសរសេរវាចូលក្នុងឯកសារកំណត់ត្រា។
5. **[en:tran:Undo Saved Change]** និង **[en:tran:Redo Saved Change]** ដើរតាមប្រវត្តិនោះ — វាដើរថយក្រោយ ឬទៅមុខ តាមអ្វីដែលបានវាយ ហើយថយក្រោយហួសពីការរក្សាទុកក៏បានដែរ ហើយវានៅតែដំណើរការ ទោះបីបង្អួចត្រូវបានបិទ ហើយបើកម្ដងទៀតក៏ដោយ ដូច្នេះការកែដែលធ្វើខុស អាចយកមកវិញបាន។ **[en:tran:Discard changed]** បោះចោលអ្វីដែលបានវាយ ប៉ុន្តែមិនទាន់រក្សាទុក រួមទាំងប្រវត្តិនោះផង ហើយធ្វើឲ្យកំណត់ត្រាត្រឡប់ទៅដូចពេលរក្សាទុកចុងក្រោយវិញ។

::: tip
ព្រួញនៅផ្នែក **ខាងលើ** នៃបង្អួច គឺជាប៊ូតុងត្រឡប់ក្រោយ និងធ្វើឡើងវិញ របស់កម្មវិធីកែអត្ថបទផ្ទាល់។
ព្រួញនៅខាងក្រោម គឺសម្រាប់ **ឯកសារ** កំណត់ត្រា។
:::

កំណត់ត្រាសម្រាប់ស៊េរីធម្មទេសនាមួយ អាចស្ថិតនៅក្នុងថតដាច់ដោយឡែករបស់វា៖ ជួរនៅក្រោមចំណងជើង **[en:tran:Bible Notes]** ប្ដូរទៅមករវាងថតទាំងនោះ (W-58)។

បង្អួចជំនួយអាចកែកំណត់ត្រាមួយជំនួសអ្នក ឬឆ្លើយពីរបៀបធ្វើអ្វីមួយនៅក្នុងកម្មវិធីកែកំណត់ត្រា៖ **[en:tran:Open in Chatbot]** នៅក្នុងម៉ឺនុយនៃជួររបស់កំណត់ត្រាមួយ ឬរូបយន្តនៅខាងក្រោមបង្អួចកំណត់ត្រាព្រះគម្ពីរ (W-60)។
