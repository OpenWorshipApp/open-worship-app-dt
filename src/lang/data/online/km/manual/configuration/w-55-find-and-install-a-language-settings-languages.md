# W-55 — ស្វែងរក និងដំឡើងភាសា (ការកំណត់ → ភាសា)

**គោលដៅ:** បង្ហាញកម្មវិធីជាភាសារបស់អ្នក ឬឈប់ផ្ដល់ភាសាដែលអ្នកមិនដែលប្រើ។

ភាសាអង់គ្លេសជាផ្នែកមួយនៃកម្មវិធី។ ភាសាផ្សេងទៀតនីមួយៗ ជាកញ្ចប់ដាច់ដោយឡែក ដែលដំឡើងពីបញ្ជីដែល Open Worship ផ្សព្វផ្សាយលើអ៊ីនធឺណិត។ ភាសាដែលបានដំឡើង ត្រូវបានរក្សាទុកក្នុងថតទិន្នន័យរបស់អ្នក ក្រោម `lang`។

1. បើកការកំណត់ (**រូបស្ពឺ**, W-16) ហើយជ្រើសថេប **[en:tran:Languages]**។ ផ្នែកទីមួយរបស់វា **[en:tran:Language]** មានប៊ូតុងសម្រាប់ជ្រើសភាសាដែលកម្មវិធីបង្ហាញ (W-16 ជំហាន 4a)។ 📸
2. **[en:tran:Installed Languages]** រាយភាសាទាំងអស់នៅលើកុំព្យូទ័រនេះ នីមួយៗក្រោមឈ្មោះផ្ទាល់ខ្លួនរបស់វា ជាមួយឈ្មោះជាភាសាអង់គ្លេសនៅក្បែរ កំណែរបស់វា និង **[en:tran:Installed]** (អ្នកបានដំឡើងវា)។ ភាសាអង់គ្លេសនៅខាងមុខគេ បង្ហាញ **[en:tran:Built in]** ហើយតែងតែបើក។ ដើម្បីមើលកន្លែងដែលភាសាមួយត្រូវបានរក្សាទុក ចុចរូបតំណាងថតឯកសារ (**[en:tran:Reveal Folder]**) នៅលើជួររបស់វា៖ កម្មវិធីរុករកឯកសាររបស់អ្នកនឹងបើកនៅថតរបស់វា ហើយគ្មានអ្វីផ្លាស់ប្ដូរក្នុងកម្មវិធីទេ។
3. **ដើម្បីឈប់ផ្ដល់ភាសាមួយ** បិទកុងតាក់របស់វា។ វាលែងត្រូវបានផ្ដល់នៅក្រោម **[en:tran:Language]** ខាងលើថេបនេះ (ឬកន្លែងផ្សេងទៀតដែលមានការជ្រើសភាសា) ហើយជួររបស់វាបង្ហាញ **[en:tran:Turned off]**។ ប្រសិនបើកម្មវិធីកំពុងបង្ហាញជាភាសានោះ កម្មវិធីនឹងត្រឡប់ទៅភាសាអង់គ្លេសវិញ។ បើកកុងតាក់វិញ ដើម្បីផ្ដល់វាម្តងទៀត។ មិនថាបិទ ឬបើក បង្អួចដែលបើកទាំងអស់នឹងផ្ទុកឡើងវិញភ្លាមៗ ដើម្បីធ្វើតាម។ មិនចាំបាច់ចុចអ្វីទៀតទេ។ ការផ្លាស់ប្ដូរនីមួយៗនៅលើថេបនេះ — បិទ ឬបើកភាសាមួយ ដំឡើង ធ្វើបច្ចុប្បន្នភាព លុប នាំចូល ឬជ្រើសភាសាមួយ — ត្រូវបានអនុវត្តតាមរបៀបនេះ ដោយមិនចាំបាច់ **[en:tran:Apply Settings]**។
4. **ដើម្បីដំឡើងភាសាមួយ** វាយឈ្មោះរបស់វាក្នុង **[en:tran:Search languages]** ក្រោម **[en:tran:Find a Language]** — ជាភាសាអង់គ្លេស (`hebrew`) ឬជាពាក្យនៃភាសានោះផ្ទាល់ — ហើយចុច **[en:tran:Install]** នៅលើជួររបស់វា។ នៅពេលវាបានដំឡើងរួច បង្អួចដែលបើកទាំងអស់នឹងផ្ទុកឡើងវិញ ហើយវាត្រូវបានរាយនៅក្រោម **[en:tran:Installed Languages]**។ បញ្ជីនេះត្រូវការអ៊ីនធឺណិត៖ បើគ្មាន វាប្រាប់ថាមិនអាចយកបញ្ជីបាន ហើយ **[en:tran:Refresh]** (ព្រួញរង្វង់) ព្យាយាមម្តងទៀត។
5. **ដើម្បីបង្ហាញកម្មវិធីជាភាសានោះ** ចុចប៊ូតុងរបស់ភាសានោះ នៅក្រោម **[en:tran:Language]** ខាងលើថេបនេះ៖ បង្អួចទាំងអស់នឹងផ្ទុកឡើងវិញជាភាសានោះ (W-16 ជំហាន 4a)។
6. **នៅពេលមានកំណែថ្មីជាង** ជួររបស់វាបង្ហាញ **[en:tran:Update to]** ជាមួយលេខថ្មី ហើយផ្នែកនោះបង្ហាញ **[en:tran:Update Available]**។ ចុចវា៖ កំណែថ្មីជំនួសកំណែចាស់ ហើយបង្អួចទាំងអស់នឹងផ្ទុកឡើងវិញជាមួយកំណែថ្មីនោះ។ អ្នកមិនចាំបាច់ចូលមករកមើលទេ៖ ពីរបីវិនាទីបន្ទាប់ពីកម្មវិធីចាប់ផ្ដើម វាពិនិត្យភាសាដែលអ្នកបានដំឡើងជាមួយបញ្ជីម្ដង ហើយនៅពេលភាសាណាមួយមានកំណែថ្មីជាង ចំណុចពណ៌លឿងតូចមួយលេចឡើងនៅលើ **រូបស្ពឺ** នៅជ្រុងខាងលើផ្នែកខាងស្តាំនៃបង្អួច។ សូមដើរតាមចំណុចទាំងនោះ — ក្នុងការកំណត់ មួយនៅបន្ទាប់ពី **[en:tran:Languages]** មួយទៀតនៅបន្ទាប់ពី **[en:tran:Installed Languages]** និងមួយនៅលើជួររបស់ភាសានោះផ្ទាល់។ ពួកវាបាត់ទៅវិញ នៅពេលភាសានោះត្រូវបានធ្វើបច្ចុប្បន្នភាពរួច។ បើគ្មានអ៊ីនធឺណិត គ្មានអ្វីត្រូវបានពិនិត្យ ហើយគ្មានចំណុចណាលេចឡើងទេ។
7. **ដើម្បីលុបភាសាដែលអ្នកបានដំឡើង** ចុចរូបធុងសំរាមនៅលើជួររបស់វា ហើយបញ្ជាក់ដោយ **[en:tran:Delete]** ក្នុង **[en:tran:Delete Language]**។ បង្អួចទាំងអស់នឹងផ្ទុកឡើងវិញ ហើយប្រសិនបើកម្មវិធីកំពុងបង្ហាញជាភាសាដែលបានលុប វានឹងបង្ហាញជាភាសាអង់គ្លេសវិញ។ ពេលឯកសារខ្លះរបស់ភាសានោះនៅតែកំពុងប្រើ គ្មានអ្វីផ្ទុកឡើងវិញទេ៖ សារមួយប្រាប់ឱ្យបិទកម្មវិធី ហើយចុចវាម្តងទៀតដើម្បីបញ្ចប់ ហើយ **[en:tran:Apply Settings]** ប្រែជាពណ៌ទឹកក្រូច សម្រាប់អ្វីដែលបានផ្លាស់ប្ដូរ។
8. **ដើម្បីផ្ដល់ភាសាមួយទៅកុំព្យូទ័រដែលគ្មានអ៊ីនធឺណិត** ចុចព្រួញទាញយក (**[en:tran:Download]**) នៅលើជួររបស់វា ក្រោម **[en:tran:Find a Language]**។ ភាសានោះត្រូវបានរក្សាទុកជាឯកសារមួយ ក្នុងថត Downloads របស់អ្នក ដែលបើកបង្ហាញវា — មានឈ្មោះដូចជា `es-0.0.1.tar.gz`។ ចម្លងវាទៅកុំព្យូទ័រម្ខាងទៀត (USB ឬថតដែលចែករំលែក)។ នៅទីនោះ ចុច **[en:tran:Import]** នៅជ្រុងខាងលើផ្នែកខាងស្តាំនៃ **[en:tran:Installed Languages]** ហើយជ្រើសឯកសារនោះ៖ វាដំឡើងដូចពីបញ្ជីដែរ បង្អួចទាំងអស់នឹងផ្ទុកឡើងវិញ ហើយវាត្រូវបានរាយនៅក្រោម **[en:tran:Installed Languages]**។ កម្មវិធីពិនិត្យឯកសារជាមួយបញ្ជីដែល Open Worship ផ្សព្វផ្សាយជាមុនសិន។ ពេលវាមិនអាចពិនិត្យបាន — ឯកសារត្រូវបានកែប្រែ ឬគ្មានអ៊ីនធឺណិតសម្រាប់ពិនិត្យ — វាសួរមុនពេលដំឡើង៖ ភាសាមួយមានកូដដែលកម្មវិធីដំណើរការ ដូច្នេះចុច **[en:tran:Import]** តែចំពោះឯកសារពីអ្នកដែលអ្នកទុកចិត្តប៉ុណ្ណោះ បើមិនដូច្នោះទេ ចុច **[en:tran:Cancel]**។ ឯកសារដែលមិនមែនជាភាសាដែលកម្មវិធីនេះអាចដំឡើងបាន ត្រូវបានបដិសេធ ជាមួយសារមួយដែលប្រាប់ដូច្នោះ។
