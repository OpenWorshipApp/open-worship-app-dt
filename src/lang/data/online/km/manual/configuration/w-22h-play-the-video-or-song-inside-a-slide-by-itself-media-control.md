# W-22h — ឲ្យវីដេអូ ឬចម្រៀងនៅក្នុងស្លាយ ចាក់ដោយខ្លួនឯង (ការគ្រប់គ្រងមេឌៀ)

**គោលដៅ:** តារាងកម្មវិធីចុចចាក់វីដេអូ ឬសំឡេងរបស់ស្លាយមួយជំនួសអ្នក — ចាប់ពីកន្លែងដែលអ្នកកំណត់ និងយូរប៉ុណ្ណាតាមដែលអ្នកកំណត់។

1. **ការគ្រប់គ្រងមេឌៀ — ឲ្យវីដេអូ ឬចម្រៀងនៅក្នុងស្លាយ ចាក់ដោយខ្លួនឯង។** ស្លាយមួយអាចមានវីដេអូ ឬឃ្លីបសំឡេងផ្ទាល់ខ្លួន ហើយជាធម្មតា អ្នកចុចចាក់វាដោយដៃនៅលើអេក្រង់តូច។ ចុចកណ្ដុរស្ដាំលើស្លាយនោះ (ឬបន្ទាត់ឯកសារ ឬបន្ទាត់របស់ស្លាយមួយនៅក្នុងឯកសារ) → **[en:tran:Add Media Control]** ហើយតារាងកម្មវិធីនឹងធ្វើវាជំនួសអ្នក។ ផ្ទាំងការកំណត់មួយបើកឡើងជាមុនសិន — គ្មានអ្វីត្រូវបានបន្ថែមទេ រហូតដល់អ្នកចុច **[en:tran:Ok]**៖

   - **[en:tran:Action]** — **[en:tran:Play]**, **[en:tran:Pause]** ឬ **[en:tran:Stop]**។ លេង ចាប់ផ្ដើមចាក់មេឌៀ; ផ្អាក ទុកវានៅត្រង់កន្លែងដែលវាកំពុងនៅ; បញ្ឈប់ ផ្អាកវា ហើយរំកិលវាត្រឡប់ទៅចំណុចចាប់ផ្ដើមវិញ ដូច្នេះបន្ទាត់ដដែលអាចប្រើម្ដងទៀតបាន។ ដាក់ ផ្អាក ឬ បញ្ឈប់ នៅលើបន្ទាត់មួយនៅពេលក្រោយ ដើម្បីកាត់ឃ្លីបឲ្យខ្លី។
   - **[en:tran:Delay Before]** — រង់ចាំប៉ុន្មានវិនាទីនេះ បន្ទាប់ពីស្លាយឡើងលើអេក្រង់ មុននឹងធ្វើអ្វីមួយ។ ទុកវានៅ 0 ដើម្បីធ្វើភ្លាមៗ។
   - **[en:tran:Media Start At]** — ចំណុចក្នុងឃ្លីបដែលត្រូវចាប់ផ្ដើម គិតជាវិនាទី។
   - **[en:tran:Then Pause]** — **[en:tran:Never]**, **[en:tran:After]** ចាក់បានប៉ុន្មានវិនាទី ឬ **[en:tran:At Media Time]** ដើម្បីឈប់នៅចំណុចមួយនៃឃ្លីបខ្លួនឯង (ដូច្នេះ "ចាក់ពី 0:10 ដល់ 1:10" គឺជាលេខពីរ មិនមែននាឡិកាវាស់ម៉ោងទេ)។
   - **[en:tran:Volume]** និង **[en:tran:Speed]** — នីមួយៗមានប្រអប់ធីកនៅពីមុខ ព្រោះការមិនធីកមានន័យថា "កុំប៉ះវា"៖ កម្រិតដែលអ្នកបានកំណត់ដោយដៃនៅលើអេក្រង់តូច នៅដដែល។
   - **[en:tran:Set Specific Screen]** — ទុកប្រអប់ទាំងអស់ឲ្យទទេ វានឹងធ្វើការលើអេក្រង់ណាក៏ដោយដែលស្លាយបានទៅដល់។ ធីកមួយ វានឹងធ្វើការ **តែ** នៅកន្លែងដែលស្លាយក៏បានទៅដល់ដែរ។ វាគ្រប់គ្រងមេឌៀដែលស្លាយបានដាក់លើអេក្រង់ ដូច្នេះអេក្រង់ដែលស្លាយមិនដែលទៅដល់ គ្មានអ្វីនៅលើវាសម្រាប់គ្រប់គ្រងទេ។
2. បន្ទាត់ថ្មីលេចឡើងជាធាតុ CC នៅក្រោមស្លាយ ដោយសរសេរពីអ្វីដែលវានឹងធ្វើ — **[en:tran:Slide: Media Control] ([en:tran:Play] +3s 10s→70s 70% 2x)** — ជាមួយ **រូបស្ពឺពណ៌ខៀវខ្ចី** តូចមួយនៅខាងស្ដាំរបស់វា។ ចុចរូបស្ពឺនោះ (ឬចុចកណ្ដុរស្ដាំ → **[en:tran:Media Control Settings]**) ដើម្បីកែវានៅពេលក្រោយ; វាបើកឡើងជាមួយអ្វីដែលអ្នកបានកំណត់លើកមុន។ បន្ទាត់ **[en:tran:Slide: Media Control]** ធម្មតាមួយ ក៏ត្រូវបានបន្ថែមនៅខាងចុងបញ្ជីដែរ៖ ធាតុ CC ចង្អុលទៅបន្ទាត់នោះ ដូច្នេះសូមទុកវានៅទីនោះ — ការដកវាចេញ នឹងដកការគ្រប់គ្រងនោះចេញជាមួយ។ 📸

   វីដេអូ និងឃ្លីបសំឡេងទាំងអស់នៅក្នុងស្លាយនោះ ត្រូវបានបញ្ជាជាមួយគ្នា។ សំឡេងចេញពីកុំព្យូទ័រដែលធ្វើបទបង្ហាញ ដូចពេលអ្នកចុចចាក់ដោយដៃដែរ ដូច្នេះ **[en:tran:Volume]** គឺជាកម្រិតសំឡេងដែលអ្នកឮនៅតុបញ្ជា; អេក្រង់ដែលបញ្ចាំង នៅស្ងាត់ ហើយគ្រាន់តែដើរស្របគ្នា ក្នុងល្បឿនដដែល។
3. **ការចាកចេញពីស្លាយ នឹងបញ្ឈប់វា។** នៅពេលអ្នកដាក់ស្លាយផ្សេងលើអេក្រង់នោះ — ឬលុបអេក្រង់ — អ្វីៗដែលការគ្រប់គ្រងមេឌៀបានចាប់ផ្ដើម ត្រូវបានបញ្ឈប់ ហើយអ្វីដែលនៅរង់ចាំ (ដូចជា "ឈប់នៅ 1:10" ឬការចាប់ផ្ដើមដែលពន្យារពេល) ត្រូវបានបោះបង់ ដូច្នេះគ្មានអ្វីបន្តទៅកាន់អ្វីដែលអ្នកដាក់បង្ហាញបន្ទាប់ទេ។ នេះហើយដែលធ្វើឲ្យតារាងកម្មវិធីអាចបន្តទៅមុខបាន៖ ឃ្លីបដែលអ្នកបានចាប់ផ្ដើម **ដោយដៃ** នៅលើអេក្រង់តូច រារាំងស្លាយបន្ទាប់ រហូតដល់អ្នកផ្អាកវា (កម្មវិធីបង្ហាញថា **[en:tran:Media is Playing]**) ព្រោះនៅទីនោះ កម្មវិធីមិនអាចដឹងថាអ្នកចង់ទុកវាឲ្យនៅចាក់ឬអត់ — ប៉ុន្តែឃ្លីបដែលតារាងកម្មវិធីបានចាប់ផ្ដើម គឺតារាងកម្មវិធីជាអ្នកបញ្ឈប់វា។ 📸

   មុខងារនេះ ភ្ជាប់តែជាមួយស្លាយប៉ុណ្ណោះ៖ អ្នកនឹងមិនឃើញវានៅក្រោម **[en:tran:Add Action]** នៅលើតារាងកម្មវិធីផ្ទាល់ទេ ព្រោះ "ចាប់ផ្ដើមវីដេអូនេះពីវិនាទីទីដប់" គឺជាប្រយោគអំពីស្លាយជាក់លាក់មួយ។
