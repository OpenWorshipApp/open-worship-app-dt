# W-58 — ទុកចម្រៀង តារាងកម្មវិធី បញ្ជីព្រះគម្ពីរ និងកំណត់ត្រា ក្នុងថតច្រើនជាងមួយ (វគ្គថត)

**គោលដៅ៖** ទុកចម្រៀងសម្រាប់ថ្ងៃអាទិត្យនេះ សំណុំចម្រៀងនៃបុណ្យអ៊ីស្ទើរឆ្នាំមុន ឬកំណត់ត្រានៃស៊េរីធម្មទេសនាមួយ ក្នុងថតដាច់ដោយឡែករបស់វា ហើយប្ដូរទៅមករវាងពួកវាពីបញ្ជីនោះផ្ទាល់ — ដោយមិនចាំបាច់ប្ដូរថតដែលកម្មវិធីត្រូវបានរៀបចំឡើងជាមួយនោះទេ។

1. នៅក្រោមចំណងជើងរបស់ **[en:tran:Documents]**, **[en:tran:Presenting Flows]**, **[en:tran:Bibles]** និង **[en:tran:Bible Notes]** មានជួរប៊ូតុងតូចៗ៖ **[en:tran:Default]** និង **＋** មួយ (**[en:tran:Add Session]**)។ 📸 **[en:tran:Default]** គឺជាថតដែលបញ្ជីតែងតែបង្ហាញ — ថតដែលមានចែងក្នុង **[en:tran:Path Settings]** (W-16) — ហើយគ្មានអ្វីនៅលើជួរនេះប្ដូរវាឡើយ។
2. ចុច **＋**។ ប៊ូតុង **វគ្គ 2** លេចឡើង ហើយជាវគ្គដែលអ្នកកំពុងនៅ។ បញ្ជីរបស់វាទទេ ហើយបង្ហាញ **[en:tran:No directory selected]**។
3. ផ្ដល់ថតមួយឱ្យវា៖ ចុច **[en:tran:Choose a folder]** ហើយជ្រើសថតមួយ ឬចុចបន្ទាត់ថតនៅខាងលើបញ្ជី វាយផ្លូវរបស់ថត ហើយចុច Enter។ **[en:tran:Select Default]** ចង្អុលវាទៅថតធម្មតារបស់បញ្ជីជំនួសវិញ។ ឥឡូវនេះ បញ្ជីបង្ហាញឯកសារនៃថតនោះ ជាមួយការតម្រៀប និងតម្រងផ្ទាល់ខ្លួនរបស់វា។ 📸
4. ចុច **[en:tran:Default]** ដើម្បីត្រឡប់ទៅវិញ ហើយចុច **វគ្គ 2** ដើម្បីមកវិញម្ដងទៀត — កម្មវិធីចងចាំវគ្គដែលអ្នកបាននៅ។
5. **⋮** នៅលើវគ្គដែលអ្នកកំពុងនៅ (ឬការចុចកណ្ដុរស្ដាំលើវគ្គណាមួយ) មាន **[en:tran:Rename Session]** ហើយនៅលើគ្រប់វគ្គ លើកលែងតែ **[en:tran:Default]** មាន **[en:tran:Remove Session]** ដែលសួរជាមុនសិន។ ការលុបចេញ បំភ្លេចវគ្គ និងការកំណត់ថតរបស់វា — ឯកសារនៅក្នុងថតនោះ មិនដែលត្រូវបានប៉ះពាល់ទេ។ **[en:tran:Default]** អាចប្ដូរឈ្មោះបាន ប៉ុន្តែមិនអាចលុបចេញបានទេ។

អ្វីដែលធ្វើតាមវគ្គដែលអ្នកកំពុងនៅ៖

- ចម្រៀង ឬឯកសារស្លាយដែលបើកដោយ **[en:tran:Edit]** និងកំណត់ត្រាព្រះគម្ពីរដែលបើកពីបញ្ជី បើកពីថតរបស់វគ្គនោះ។
- អ្វីដែលអ្នកបង្កើតពីកន្លែងផ្សេង ចូលទៅក្នុងវា — ចម្រៀង ឬស្លាយដែលបង្កើតពីបទគម្ពីរមួយ (W-06) ខគម្ពីរដែលរក្សាទុកពី **[en:tran:Bible Lookup]** ទៅក្នុងបញ្ជី **Default** នៃ **[en:tran:Bibles]** ចម្រៀង ឬស្លាយដែលជំនួយការសរសេរ (W-42, W-56, W-57) និងឯកសារដែលអ្នកនាំចូល (W-23, W-22j, W-24, W-41)។
- ថតរបស់វគ្គមួយដែលនៅក្រៅថតទិន្នន័យ ត្រូវបានតាមដានដូចថតទិន្នន័យដែរ ដូច្នេះឯកសារដែលចម្លងចូលទៅក្នុងវា លេចឡើងក្នុងបញ្ជី។

អ្វីដែល **មិន** ធ្វើតាមវា៖ ការគូសពណ៌ និងមតិយោបល់របស់អ្នកលើខគម្ពីរ (W-40) តែងតែត្រូវបានរក្សាទុកក្នុងកំណត់ត្រារបស់វគ្គ **[en:tran:Default]** ដូច្នេះការប្ដូរវគ្គនៃ **[en:tran:Bible Notes]** មិនដែលលាក់ពួកវាទេ ហើយទំព័រអានព្រះគម្ពីរសម្គាល់ខគម្ពីរដែលមានកំណត់ត្រា ពីទាំងវគ្គ **[en:tran:Default]** និងពីវគ្គដែលអ្នកកំពុងនៅ។ ទំព័រធ្វើបទបង្ហាញ និងទំព័រអានព្រះគម្ពីរ រក្សាវគ្គ **[en:tran:Bibles]** របស់វាដាច់ពីគ្នា ដូចដែលវារក្សាថតរបស់វាដាច់ពីគ្នាដែរ។

ជំហាន 1–5 ត្រូវបានមើលឃើញផ្ទាល់នៅថ្ងៃទី 2026-11-07 លើទំព័រធ្វើបទបង្ហាញនៃកម្មវិធីអភិវឌ្ឍន៍៖ ជួរនៅក្រោមចំណងជើងទាំងបួន; **＋** នៅលើ **[en:tran:Documents]** បង្កើត **វគ្គ 2** ដោយមាន **[en:tran:Choose a folder]** នៅក្នុងបញ្ជីទទេរបស់វា; ថតដែលបានវាយ បង្ហាញចម្រៀង និងឯកសារស្លាយរបស់វា; **[en:tran:Edit]** លើនីមួយៗ បើកវាពីថតនោះ (កម្មវិធីកែសម្រួលទំនុកច្រៀង និងកម្មវិធីកែសម្រួលឯកសារ); **[en:tran:Default]** នាំបញ្ជីធម្មតាត្រឡប់មកវិញ; និងម៉ឺនុយរបស់ **[en:tran:Default]** ផ្ដល់តែ **[en:tran:Rename Session]** ប៉ុណ្ណោះ។ បានសាកល្បងដោយតេស្តឯកតា ប៉ុន្តែមិនទាន់បានឃើញផ្ទាល់៖ ខគម្ពីរដែលរក្សាទុកពីការស្វែងរកព្រះគម្ពីរទៅក្នុងបញ្ជីរបស់វគ្គមួយ ចម្រៀងដែលបង្កើតពីបទគម្ពីរទៅក្នុងវគ្គមួយ ការគូសចំណាំខគម្ពីរដែលនៅតែស្ថិតក្នុងកំណត់ត្រារបស់វគ្គ **[en:tran:Default]** និងជួរ **[en:tran:Bibles]** របស់ផ្ទាំងស្វែងរកព្រះគម្ពីរ ដែលធ្វើតាមជួររបស់ជួរឈរខាងស្ដាំ។
