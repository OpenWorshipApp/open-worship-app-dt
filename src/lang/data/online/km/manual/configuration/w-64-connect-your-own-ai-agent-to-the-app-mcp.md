# W-64 — ភ្ជាប់ភ្នាក់ងារ AI ផ្ទាល់ខ្លួនរបស់អ្នកទៅកម្មវិធី (MCP)

**គោលដៅ:** អនុញ្ញាតឲ្យភ្នាក់ងារ AI ដែលអ្នកដំណើរការលើកុំព្យូទ័រនេះ — Claude Code, Claude Desktop, Cursor ឬកម្មវិធីផ្សេងទៀតដែលនិយាយភាសា MCP (Model Context Protocol) — មើលឃើញ Open Worship ហើយប្រើវា ដូចដែលជំនួយការរបស់កម្មវិធីខ្លួនឯងធ្វើ។ កម្មវិធីដែលភ្នាក់ងារនិយាយជាមួយ មកជាមួយឧបករណ៍ទាញយក ដូច្នេះកុំព្យូទ័រមិនត្រូវការដំឡើងអ្វីផ្សេងទៀតទេ។

1. បើក **[en:tran:Setting]** → **[en:tran:Others]** → **[en:tran:Extra Binaries]**។ បើកាតបង្ហាញ **[en:tran:Not installed]** ចុច **[en:tran:Download and Install]** (W-21); បើវាផ្ដល់ **[en:tran:Update to]** ចុចវា — ឧបករណ៍មុនកំណែ 0.0.6 មិនមានកម្មវិធីសម្រាប់ភ្នាក់ងារទេ។ 📸
2. នៅពេលឧបករណ៍ត្រូវបានដំឡើងរួច កាតនេះមានប្រអប់ជ្រើសរើស **[en:tran:AI agents (MCP)]**។ ជ្រើសរើសកម្មវិធី AI របស់អ្នកនៅក្នុងនោះ៖ ក្រោម **[en:tran:Terminal command]** គឺកម្មវិធីដែលកំណត់ដោយវាយពាក្យបញ្ជា (Claude Code, Codex — ដែលកម្មវិធី ChatGPT សម្រាប់កុំព្យូទ័រប្រើរួមគ្នា —, Gemini CLI, GitHub Copilot CLI …) ក្រោម **[en:tran:Settings file]** គឺកម្មវិធីដែលកំណត់ក្នុងឯកសារ (Claude Desktop, Cursor, Windsurf, VS Code, Zed, Cline, Continue …) ហើយក្រោម **[en:tran:Others]** គឺប្លុក JSON ធម្មតាសម្រាប់កម្មវិធីផ្សេងទៀត ឬ **[en:tran:Program path]** ដែលជាផ្លូវរបស់កម្មវិធីនេះផ្ទាល់។ នៅក្រោមប្រអប់ជ្រើសរើស គឺអក្សរសម្រាប់កម្មវិធីដែលបានជ្រើស៖ ពាក្យបញ្ជាមួយ ជាមួយ **[en:tran:Run this in a terminal.]** ឬអ្វីដែលត្រូវដាក់ក្នុងឯកសារការកំណត់របស់វា ជាមួយ **[en:tran:Paste into:]** និងឯកសារនោះ។ ចុច **[en:tran:Copy]** — កំណត់សម្គាល់មួយនៅជ្រុងខាងលើផ្នែកខាងស្តាំប្រាប់ថា អក្សរត្រូវបានចម្លង — ហើយបិទភ្ជាប់វានៅទីនោះ។ ប្រអប់ជ្រើសរើសចងចាំជម្រើសរបស់អ្នកសម្រាប់លើកក្រោយ។ 📸
3. ទុក Open Worship ឲ្យបើកនៅ៖ ភ្នាក់ងាររកឃើញកម្មវិធីដែលកំពុងបើកដោយខ្លួនឯង។ វាត្រូវការឲ្យមុខងារ AI របស់កម្មវិធីបើក (**[en:tran:AI Providers]** → **[en:tran:Enable AI features]** ដែលបើកជានិច្ច លុះត្រាតែមាននរណាម្នាក់បានបិទវា)។
4. សួរភ្នាក់ងារអំពីកម្មវិធី ឧទាហរណ៍ _តើមានអ្វីនៅលើអេក្រង់?_ ពេលវាចុចអ្វីមួយ កំណត់សម្គាល់មួយនៅផ្នែកខាងក្រោមនៃបង្អួចប្រាប់ថា ជំនួយការបានចុច។ ដូចជំនួយការរបស់កម្មវិធីខ្លួនឯងដែរ វាអាចចង្អុលទៅអ្វីក៏បាន ហើយចុចបានស្ទើរតែគ្រប់យ៉ាង ប៉ុន្តែប៊ូតុងដែលមិនអាចត្រឡប់វិញបាន — លុប ដកចេញ សម្អាតទាំងអស់ … — នៅតែជាប៊ូតុងសម្រាប់អ្នកចុចផ្ទាល់។
5. ពេលមាន Open Worship បើកច្រើនជាងមួយនៅលើកុំព្យូទ័រនេះ — ឧទាហរណ៍ កម្មវិធីដែលបានដំឡើង និងច្បាប់ចម្លងសាកល្បងមួយ — ភ្នាក់ងាររាយឈ្មោះពួកវា (នីមួយៗតាមប្រវត្តិរូបទិន្នន័យ ប្រភេទ និងកំណែរបស់វា) ហើយសួរអ្នកថា ត្រូវធ្វើការជាមួយមួយណា; វាមិនធ្វើអ្វីក្នុងកម្មវិធីណាមួយទេ រហូតដល់អ្នកឆ្លើយ។ វាក៏ពិនិត្យថា កម្មវិធីរបស់វាជាកំណែដូចគ្នានឹងកម្មវិធី Open Worship ដែរឬទេ ហើយប្រាប់អ្នកនៅពេលវាមិនដូចគ្នា។

> ចំណាំ៖ កម្មវិធីនេះស្ថិតនៅក្នុងថតទិន្នន័យរបស់អ្នក ក្រោម `extra-bin` ក្នុងថតមួយឈ្មោះ `mcp` ដោយមាន `README.md` នៅក្បែរ។ សូមរក្សាថតនោះឲ្យនៅគ្រប់ចំនួន៖ កម្មវិធីអានឯកសារដែលនៅក្បែរវា។ ពាក្យបញ្ជាដាក់ផ្លូវរបស់កម្មវិធីក្នុងសញ្ញាសម្រង់តែមួយ នៅលើ Mac ឬ Linux និងក្នុងសញ្ញាសម្រង់ពីរ នៅលើ Windows ព្រោះផ្លូវរបស់ថតទិន្នន័យអាចមានដកឃ្លា។ ឧបករណ៍ដែលដំឡើងពីឯកសារ (W-21) ក៏មានកម្មវិធីនេះដែរ នៅពេលឯកសារនោះមកពីកំណែ 0.0.6 ឬក្រោយនោះ។ ChatGPT នៅក្នុងកម្មវិធីរុករកបណ្ដាញ មិនអាចចាប់ផ្ដើមកម្មវិធីនៅលើកុំព្យូទ័រនេះបានទេ; កម្មវិធី ChatGPT សម្រាប់កុំព្យូទ័រ ទៅដល់វាតាមរយៈការកំណត់របស់ Codex។

ជំហាន 1–4 ត្រូវបានមើលឃើញផ្ទាល់នៅថ្ងៃទី 2026-11-13 លើប្រវត្តិរូបអភិវឌ្ឍន៍សាកល្បងមួយ នៅលើ Mac ជាភាសាអង់គ្លេស និងភាសាខ្មែរ៖ **[en:tran:Download and Install]** បានដំឡើង 0.0.6 បន្ទាត់នោះបានបង្ហាញពាក្យបញ្ជា **[en:tran:Copy]** បានដាក់ពាក្យបញ្ជានោះយ៉ាងពិតប្រាកដទៅក្ដារតម្បៀតខ្ទាស់ ជាមួយកំណត់សម្គាល់របស់វា ហើយប៊ូតុង JSON របស់បន្ទាត់នោះ (ដែលត្រូវបានដកចេញតាំងពីពេលនោះ) បានដាក់ JSON; កម្មវិធីនេះ ដែលចាប់ផ្ដើមដោយខ្លួនឯងដោយគ្មានការកំណត់អ្វីសោះ បានរកឃើញកម្មវិធី បានថតរូបផ្ទាំងធ្វើបទបង្ហាញ បានចុចថេបមួយនៃការកំណត់ ហើយបានបដិសេធមិនចុច _Delete everything_; Claude Code បានទទួលពាក្យបញ្ជាដែលបានចម្លង ហើយរាយការណ៍ថាកម្មវិធីបានភ្ជាប់។ ពេលថតរបស់កម្មវិធីត្រូវបានផ្លាស់ទីចេញ កាតនៅតែបង្ហាញ **[en:tran:Installed]** ហើយបន្ទាត់នោះបានបាត់។ ប្រអប់ជ្រើសរើស (ជំហាន 2) ត្រូវបានមើលឃើញផ្ទាល់នៅថ្ងៃដដែល លើកម្មវិធីអភិវឌ្ឍន៍ និងលើច្បាប់ចម្លងសាកល្បងមួយជាភាសាខ្មែរ៖ Claude Code, Cursor, ឯកសារការកំណត់របស់ Codex, Continue និង **[en:tran:Program path]** នីមួយៗបានដាក់អក្សរដែលបង្ហាញនោះយ៉ាងពិតប្រាកដទៅក្ដារតម្បៀតខ្ទាស់ Cursor និង Claude Desktop បានប្រាប់ឈ្មោះឯកសាររបស់វា ហើយជម្រើសនៅតែមាន បន្ទាប់ពីចាកចេញពីថេប ហើយបើកវាម្ដងទៀត។ ជំហាន 5 ត្រូវបានមើលឃើញតាមរយៈច្បាប់ចម្លងថ្មីនៃកម្មវិធីនេះ ពេលមានកម្មវិធីបើកពីរ ហើយបន្ទាប់មកបី៖ វាបានរាយឈ្មោះពួកវា បានឆ្លើយរាល់ការចុចដោយបញ្ជីនោះ រហូតដល់មួយត្រូវបានជ្រើស បន្ទាប់មកធ្វើការតែក្នុងកម្មវិធីនោះ ហើយដើរតាមពេលប្ដូរទៅកម្មវិធីមួយទៀត។ មិនទាន់បានមើលឃើញផ្ទាល់៖ Claude Desktop ឬ Cursor ខ្លួនឯង, Windows ឬ Linux, ការធ្វើបច្ចុប្បន្នភាពពី 0.0.5។
