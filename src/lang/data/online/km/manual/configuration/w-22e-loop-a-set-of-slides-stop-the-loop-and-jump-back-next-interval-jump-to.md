# W-22e — ធ្វើឱ្យស្លាយមួយក្រុមវិលជុំ បញ្ឈប់ការវិលជុំ និងលោតត្រឡប់ក្រោយ (បន្ទាប់៖ រៀងរាល់ចន្លោះពេល, លោតទៅ)

**គោលដៅ:** ស្លាយសេចក្ដីប្រកាសមួយក្រុម ដែលវិលជុំដោយខ្លួនឯងមុនពេលកម្មវិធីថ្វាយបង្គំ ហើយឈប់
នៅកន្លែងដែលអ្នកកំណត់ និងតារាងកម្មវិធីដែលអាចត្រឡប់ទៅបន្ទាត់មុនៗបាន។

1. ចុចកណ្ដុរស្ដាំលើ **តារាងកម្មវិធីនោះផ្ទាល់** — ជួររបស់វាផ្ទាល់នៅក្នុងបញ្ជី មិនមែនផ្នែកទទេនៃ
   បញ្ជី ហើយក៏មិនមែនបន្ទាត់ណាមួយរបស់វាដែរ — រួចជ្រើសរើស **[en:tran:Add Action]** →
   **[en:tran:Next: Interval]**។ វាសួរថាប៉ុន្មាន **[en:tran:Seconds]** ហើយចម្លើយនោះជាផ្នែកមួយនៃ
   បន្ទាត់។ ចុចកណ្ដុរស្ដាំលើបន្ទាត់នោះ → **[en:tran:Change Seconds]** ដើម្បីប្ដូរវា។ ដូចបន្ទាត់ **[en:tran:Next]៖** ទាំងអស់ដែរ
   វាដំណើរការតែពេលផ្ទាំងមើលជាមុនកំពុងបើកប៉ុណ្ណោះ (W-22b)។
2. **[en:tran:Next: Interval]** បន្តដំណើរការជានិច្ច។ វារំកិលកម្មវិធីទៅមុខរៀងរាល់ប៉ុន្មានវិនាទីម្ដង — ស្លាយ
   សេចក្ដីប្រកាសវិលជុំ មុនពេលកម្មវិធីថ្វាយបង្គំ។ ការដែលអ្នកទៅកន្លែងណាមួយដោយខ្លួនឯង មិនបញ្ឈប់វាទេ វា
   **ចាប់ផ្ដើមរាប់ឡើងវិញពីទីនោះ** ដូច្នេះបន្ទាត់ដែលអ្នកទៅដល់ដោយដៃ ទទួលបានចន្លោះពេលពេញ
   ជាជាងវិនាទីដែលនៅសល់ពីបន្ទាត់មុន។ ដើម្បីបញ្ឈប់វា សូមចុច
   ⊗ (**[en:tran:Stop Auto Next]**) នៅលើស្លាករាងមូល ដែលវាដាក់នៅជ្រុងខាងស្ដាំខាងលើនៃផ្ទាំងមើលជាមុន (វាបង្ហាញវិនាទីដែលនៅសល់ ក្នុង
   ពណ៌ដូចបន្ទាត់ដែលបានចាប់ផ្ដើមវា)។ សញ្ញា ⏸ នៅលើស្លាករាងមូលដដែល (**[en:tran:Pause Auto Next]**) ផ្អាកការរាប់នៅត្រឹមនោះ រហូតដល់អ្នកចុចវាម្ដងទៀត។ ការបិទផ្ទាំងនោះ ក៏បញ្ឈប់វាដែរ ដូចការ
   ទៅដល់ចុងបញ្ចប់នៃតារាងដែរ។
3. **[en:tran:Next: Clear Interval]** បញ្ឈប់ការវិលជុំនោះ ហើយវាជា
   វិធីតែមួយគត់ដែល **តារាង** ខ្លួនឯងអាចបញ្ឈប់វាបាន៖ ស្លាករាងមូល ការបិទផ្ទាំង និងចុងបញ្ចប់នៃបញ្ជី
   សុទ្ធតែត្រូវការអ្នកនៅឯម៉ាស៊ីន។ បន្ថែមវា — វាមិនសួរអ្វីទេ ព្រោះមាននាឡិកាតែមួយប៉ុណ្ណោះ
   ដែលដំណើរការ — ហើយបន្ទាត់នោះសរសេរថា **⊘ [en:tran:Next: Clear Interval]** ក្នុងពណ៌របស់ចន្លោះពេលនោះផ្ទាល់
   ព្រោះវាជារបស់ដដែលនោះ ដែលត្រូវបានលុបចោល។ ដាក់វានៅកន្លែងដែលកម្មវិធីនឹងទៅដល់វា៖ នៅក្រោយស្លាយ
   ដែលចន្លោះពេលនោះដើរកាត់តែម្ដង ឬភ្ជាប់ជាមួយស្លាយមួយ (មើលខាងក្រោម) ដូច្នេះការវិលជុំឈប់ ពេលស្លាយនោះ
   ត្រូវបានបង្ហាញ ហើយរង់ចាំអ្នក។ បន្ទាត់ដែលនៅក្រោយ **[en:tran:Jump to]** ដែលចង្អុលត្រឡប់ទៅចន្លោះពេលនោះ
   មិនដែលត្រូវបានទៅដល់ទេ — ការលោតកើតឡើងភ្លាម ពេលកម្មវិធីទៅដល់វា — ដូច្នេះការវិលជុំបែបនោះ
   ត្រូវបញ្ចប់ដោយអ្នក៖ ចុចប៊ូតុងរបស់បន្ទាត់នេះ នៅក្នុងផ្ទាំងមើលជាមុន ឬ ⊗ នៅលើស្លាករាងមូល។
   ការដំណើរការវាពេលគ្មានអ្វីកំពុងវិលជុំ មិនធ្វើ
   អ្វីសោះ ហើយមិននិយាយអ្វីទេ ដូច្នេះវាមានសុវត្ថិភាពក្នុងការទុកវានៅក្នុងតារាងដែលអ្នកដំណើរការម្ដងទៀត។ វាក៏បញ្ឈប់
   ចន្លោះពេលដែលអ្នកបាន **ផ្អាក** ដែរ។ ចំណែក **[en:tran:Next: Timeout]** វិញ វាទុកចោលមិនប៉ះពាល់ទេ ដូច្នេះការរង់ចាំ
   ដែលភ្ជាប់ជាមួយស្លាយមួយ មិនដែលត្រូវបានសម្លាប់ដោយបន្ទាត់ដែលគ្រាន់តែចង់បញ្ចប់ការវិលជុំនោះទេ។ 📸
   **[en:tran:Next: Interval] មិនអាចទៅជាមួយបន្ទាត់ផ្សេងបានទេ** —
   ចន្លោះពេលមិនត្រូវបានបញ្ឈប់ដោយអ្វីដែលអ្នកធ្វើទេ ដូច្នេះចន្លោះពេលដែលភ្ជាប់ជាមួយស្លាយមួយ នឹងបន្តរំកិល
   តារាងកម្មវិធីទៅមុខ ដោយគ្មានអ្វីអាចបញ្ឈប់វាបាន ក្រៅពីស្លាករាងមូលរបស់ផ្ទាំងនោះផ្ទាល់។ ចំណែក
   **[en:tran:Next: Clear Interval]** វិញ **អាច** ភ្ជាប់បាន ដោយហេតុផលផ្ទុយគ្នា៖ "ដាក់ស្លាយចុងក្រោយនេះ
   ឡើង **ហើយ** បញ្ឈប់ការវិលជុំ" គឺជាការចុចតែមួយដង ហើយអ្វីដែលបញ្ឈប់ការវិលជុំ មិនអាចនាំ
   តារាងកម្មវិធីរត់ចេញពីការគ្រប់គ្រងបានឡើយ។
4. **ត្រឡប់ក្រោយបាន មិនមែនតែទៅមុខប៉ុណ្ណោះទេ។** **[en:tran:Jump to]** គឺជារបៀបដែល
