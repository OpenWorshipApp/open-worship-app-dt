# W-27 — ខ្ទាស់ឯកសារដែលអ្នកកំពុងបង្ហាញ

**គោលដៅ:** ការពារកុំឱ្យការចុចច្រឡំនៅក្នុងបញ្ជីឯកសារ ប្ដូរឯកសារដែលអ្នកកំពុងបង្ហាញ
ពាក់កណ្ដាលទី។

**លក្ខខណ្ឌជាមុន:** មានឯកសារមួយត្រូវបានជ្រើសរើស នៅក្នុងថេប **[en:tran:Documents]** នៅកណ្ដាល។

1. មើលចំណងជើងថេប **[en:tran:Documents]** នៅកណ្ដាល។ ពេលមានឯកសារមួយត្រូវបានជ្រើសរើស មាន
   **ប៊ូតុងខ្ទាស់** ព្រាលៗមួយ (គូរជារូបសោរបើក) នៅបន្ទាប់ពីពាក្យនោះ — បើគ្មានអ្វីត្រូវបានជ្រើសរើស គ្មានប៊ូតុងខ្ទាស់ទេ។ 📸
2. ចុចប៊ូតុងខ្ទាស់។ រូបសោរបិទ ហើយប្រែជាពណ៌លឿងទុំដិត៖ ឯកសារនោះឥឡូវ **ត្រូវបានខ្ទាស់**។ ពេលដាក់ទស្សន៍ទ្រនិចលើវា
   វាសរសេរថា **[en:tran:Unpin document]**។ 📸
3. ចុចឯកសារផ្សេងមួយនៅក្នុងបញ្ជីខាងឆ្វេង។ **គ្មានអ្វីផ្លាស់ប្ដូរទេ** — កម្មវិធីមើលជាមុននៅតែរក្សា
   ឯកសាររបស់អ្នក។ សារមួយនិយាយថា **ឯកសារត្រូវបានខ្ទាស់** / _សូមដោះខ្ទាស់ឯកសារដើម្បីមើល
   ឯកសារផ្សេងទៀត_ ([en:tran:Document is pinned]) ហើយប៊ូតុងខ្ទាស់ភ្លឹបភ្លែត ដើម្បីឱ្យអ្នកឃើញថាអ្វីបាន
   រារាំងវា។ 📸
4. ការការពារដដែលនេះ គ្របដណ្ដប់គ្រប់វិធីនៃការប្ដូរឯកសារ៖ ជួរចម្រៀងមួយ ឯកសារមួយ
   នៅក្នុង **តារាងកម្មវិធី** និងការចុចឈ្មោះឯកសារនៅបាតរបស់កម្មវិធីមើលជាមុនផ្ទាល់ (ដែល
   ជាធម្មតាបើកបញ្ជីឯកសារផ្សេងទៀតនៅក្នុងថត — ពេលកំពុងខ្ទាស់ វាមិនបើក
   សោះ)។
5. ចុចប៊ូតុងខ្ទាស់ម្ដងទៀត ដើម្បីដោះខ្ទាស់។ ការចុចពីជំហានទី 3 ឥឡូវដំណើរការធម្មតាវិញ។

គន្លឹះ៖

- ការខ្ទាស់នៅតែមាន ពេលអ្នក **បើកកម្មវិធីឡើងវិញ** — វាត្រូវបានចងចាំជាមួយការជ្រើសរើស។
- **ការប្ដូរឈ្មោះ** ឯកសារដែលបានខ្ទាស់ មិនមែនជាការប្ដូរឯកសារទេ៖ កម្មវិធីមើលជាមុនតាមឈ្មោះថ្មី ហើយ
  នៅតែខ្ទាស់។
- **ការបោះចោលទៅធុងសំរាម** នូវឯកសារដែលបានខ្ទាស់ នឹងដោះខ្ទាស់ដោយស្វ័យប្រវត្តិ ហើយប៊ូតុងខ្ទាស់បាត់ទៅ ព្រោះ
  លែងមានអ្វីត្រូវកាន់ទុកទៀតហើយ។
- ការចុចជួររបស់ឯកសារដែលបានខ្ទាស់ម្ដងទៀត គឺស្ងាត់ — នោះក៏មិនមែនជាការប្ដូរឯកសារដែរ។
