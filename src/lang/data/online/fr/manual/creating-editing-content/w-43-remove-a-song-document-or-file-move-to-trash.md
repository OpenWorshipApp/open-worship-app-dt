# W-43 — Supprimer un chant, un document ou un fichier (Mettre à la corbeille)

**Objectif :** vous débarrasser d'un fichier dont vous ne voulez plus — un chant, un document de diapositives, un PDF, une image ou une vidéo d'arrière-plan, un déroulé, une note biblique — sans le perdre pour de bon.

Aucune ligne de fichier n'a de **[en:tran:Delete]**. Chaque ligne de fichier a **[en:tran:Move to Trash]** à la place, et cela fait exactement ce que cela dit : le fichier va dans la Corbeille de votre ordinateur (sous Windows comme sur Mac), d'où il peut être récupéré si vous changez d'avis.

1. Trouvez la ligne dans sa liste — un chant ou un document de diapositives dans **[en:tran:Documents]**, une image ou une vidéo dans le panneau **[en:tran:Background]**, un déroulé dans **[en:tran:Presenting Flows]**. 📸
2. Faites un clic droit sur la ligne, ou cliquez sur le **⋮** discret à son extrémité droite (W-01b). Le menu de la ligne s'ouvre.
3. Choisissez **[en:tran:Move to Trash]** — le dernier élément, avec une icône de corbeille rouge. 📸
4. Une petite fenêtre demande **[en:tran:Moving File to Trash]** — _Voulez-vous vraiment déplacer « … » vers la corbeille ?_ Cliquez sur **[en:tran:Yes]**. (**[en:tran:No]** laisse tout comme avant.)
   Une clé USB sous Windows n'a pas de Corbeille : une deuxième fenêtre, **[en:tran:Delete Permanently]**, demande alors s'il faut plutôt supprimer le fichier pour de bon — cela ne peut pas être annulé, et **[en:tran:Cancel]** le garde.
5. La ligne disparaît de la liste. Le fichier, ainsi que les petits fichiers à côté de lui qui retiennent ses arrière-plans et ses transitions, se trouvent dans la Corbeille — ouvrez-la depuis votre bureau pour les restaurer.

**Pas là ?** Un élément d'arrière-plan qui est **à l'écran en ce moment** n'a pas **[en:tran:Move to Trash]** dans son menu — retirez-le d'abord de l'écran (**[en:tran:Clear Background]** dans le panneau Mini-écran, W-10), puis réessayez. Une diapositive À L'INTÉRIEUR d'un document n'est pas un fichier : pour en supprimer une, ouvrez le document dans l'**[en:tran:Slide Editor]** et faites un clic droit sur la diapositive dans la liste de gauche (W-15). Un fichier du panneau **[en:tran:Resources]** n'en a pas du tout : retirez-le de son dossier sur votre ordinateur.
