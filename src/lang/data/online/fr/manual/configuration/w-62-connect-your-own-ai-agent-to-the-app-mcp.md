# W-62 — Connecter votre propre agent d'IA à l'application (MCP)

**Objectif :** permettre à un agent d'IA que vous utilisez sur cet ordinateur — Claude Code, Claude Desktop, Cursor ou un autre programme qui parle MCP (le Model Context Protocol) — de voir Open Worship et de s'en servir comme le fait l'assistant de l'application. Le programme auquel l'agent parle est fourni avec les outils de téléchargement : il n'y a donc rien d'autre à installer sur l'ordinateur.

1. Ouvrez **[en:tran:Setting]** → **[en:tran:Others]** → **[en:tran:Extra Binaries]**. Si la carte affiche **[en:tran:Not installed]**, appuyez sur **[en:tran:Download and Install]** (W-21) ; si elle propose **[en:tran:Update to]**, appuyez dessus — les outils d'avant la version 0.0.6 n'ont pas de programme pour un agent. 📸
2. Une fois les outils installés, la carte a un sélecteur **[en:tran:AI agents (MCP)]**. Choisissez-y votre programme d'IA : sous **[en:tran:Terminal command]** ceux qui se règlent en tapant une commande (Claude Code, Codex — que partage l'application de bureau ChatGPT —, Gemini CLI, GitHub Copilot CLI …), sous **[en:tran:Settings file]** ceux qui se règlent dans un fichier (Claude Desktop, Cursor, Windsurf, VS Code, Zed, Cline, Continue …), et sous **[en:tran:Others]** un simple bloc JSON pour tout autre programme, ou **[en:tran:Program path]**, le chemin du programme lui-même. Sous le sélecteur se trouve le texte du programme choisi : une commande, avec **[en:tran:Run this in a terminal.]**, ou ce qui va dans son fichier de paramètres, avec **[en:tran:Paste into:]** et ce fichier. Appuyez sur **[en:tran:Copy]** — une note en haut à droite indique que le texte a été copié — et collez-le à cet endroit. Le sélecteur garde votre choix pour la prochaine fois. 📸
3. Gardez Open Worship ouvert : l'agent trouve de lui-même l'application ouverte. Il lui faut les fonctionnalités d'IA de l'application activées (**[en:tran:AI Providers]** → **[en:tran:Enable AI features]**, qui est activé sauf si quelqu'un l'a désactivé).
4. Interrogez l'agent sur l'application, par exemple _qu'y a-t-il à l'écran ?_ Quand il appuie sur quelque chose, une note en bas de la fenêtre indique que l'assistant l'a fait. Comme l'assistant de l'application, il peut montrer n'importe quoi et appuyer sur presque tout, mais c'est toujours à vous d'appuyer sur un bouton qu'on ne peut pas annuler — supprimer, retirer, tout effacer …
5. Avec plus d'un Open Worship ouvert sur cet ordinateur — l'application installée et une copie de test, par exemple —, l'agent les énumère (chacun avec son profil de données, son type et sa version) et vous demande avec lequel travailler ; il ne fait rien dans aucun d'eux tant que vous n'avez pas répondu. Il vérifie aussi que son programme est de la même version que l'application, et vous prévient quand ce n'est pas le cas.

> Remarques : le programme se trouve dans votre dossier de données sous `extra-bin`, dans un dossier nommé `mcp` avec un `README.md` à côté. Gardez ce dossier entier : le programme lit les fichiers qui l'entourent. La commande met le chemin du programme entre guillemets simples sur un Mac ou sous Linux et entre guillemets doubles sous Windows, car le chemin d'un dossier de données peut contenir des espaces. Les outils installés depuis un fichier (W-21) contiennent aussi le programme quand le fichier vient de la version 0.0.6 ou d'une version plus récente. ChatGPT dans un navigateur web ne peut pas lancer de programme sur cet ordinateur ; l'application de bureau ChatGPT y accède par les paramètres de Codex.

Les étapes 1 à 4 ont été observées en direct le 2026-11-13 sur un profil de développement de test, sur un Mac, en anglais et en khmer : **[en:tran:Download and Install]** a installé la 0.0.6, la ligne a affiché la commande, **[en:tran:Copy]** a mis exactement cette commande dans le presse-papiers avec sa note, et le bouton JSON de la ligne (retiré depuis) le JSON ; le programme, lancé seul sans aucun réglage, a trouvé l'application, a pris une image du Présentateur, a appuyé sur un onglet des Paramètres et a refusé d'appuyer sur _Delete everything_ ; Claude Code a accepté la commande copiée et a indiqué que le programme était connecté. Avec le dossier du programme déplacé ailleurs, la carte affichait toujours **[en:tran:Installed]** et la ligne avait disparu. Le sélecteur (étape 2) a été observé en direct le même jour sur l'application de développement et sur une instance de test en khmer : Claude Code, Cursor, le fichier de configuration de Codex, Continue et **[en:tran:Program path]** ont chacun mis exactement le texte affiché dans le presse-papiers, Cursor et Claude Desktop ont nommé leur fichier, et le choix était toujours là après avoir quitté l'onglet puis l'avoir rouvert. L'étape 5 a été observée avec une nouvelle copie du programme, deux puis trois applications ouvertes : il les a énumérées, a répondu à chaque appui par la liste jusqu'à ce qu'une soit choisie, puis n'a travaillé que dans celle-là, en suivant un passage à une autre. Non observé en direct : Claude Desktop ou Cursor eux-mêmes, Windows ou Linux, une mise à jour depuis la 0.0.5.
