# W-27 — Épingler le document à partir duquel vous présentez

**Objectif :** empêcher qu'un clic malencontreux dans la liste Documents remplace le document que vous êtes en train de présenter.

**Prérequis :** un document sélectionné dans l'onglet **[en:tran:Documents]** du milieu.

1. Regardez le titre de l'onglet **[en:tran:Documents]** du milieu. Quand un document est sélectionné, une **épingle** discrète (dessinée comme un cadenas ouvert) se trouve juste après le mot — aucun document sélectionné, pas d'épingle. 📸
2. Cliquez sur l'épingle. Le cadenas se ferme et devient orange plein : le document est maintenant **épinglé**. Au survol, on lit **[en:tran:Unpin document]**. 📸
3. Cliquez sur un autre document dans la liste de gauche. **Rien ne change** — l'aperçu garde votre document. Un message indique **Le document est épinglé** / _Désépinglez le document pour en prévisualiser un autre_ ([en:tran:Document is pinned]), et l'épingle clignote pour que vous voyiez ce qui a bloqué le changement. 📸
4. La même protection couvre toutes les façons de changer de document : une ligne de chant, un document dans un **déroulé**, et un clic sur le nom du fichier dans le pied de l'aperçu lui-même (qui ouvre normalement une liste des autres documents du dossier — quand le document est épinglé, elle ne s'ouvre même pas).
5. Cliquez de nouveau sur l'épingle pour désépingler. Les clics de l'étape 3 fonctionnent alors normalement.

Astuces :

- L'épingle reste en place quand vous **redémarrez l'application** — elle est retenue avec la sélection.
- **Renommer** le document épinglé n'est pas un changement de document : l'aperçu suit le nouveau nom et reste épinglé.
- **Mettre à la corbeille** le document épinglé le désépingle automatiquement et l'épingle disparaît, puisqu'il n'y a plus rien à retenir.
- Cliquer de nouveau sur la ligne du document épinglé lui-même ne fait rien — ce n'est pas non plus un changement de document.
