# Statements only the running app can settle

A ledger. Reading a document against the code (`SKILL.md` §3) leaves some
statements the code cannot decide: how something looks, how long it takes, what
a second computer or a TV does. They stay as written in their document and are
listed here, so they are not lost with a run's report. A `/owa-robot-test` run
that observes one takes its line off (and corrects the document when the app
says otherwise); a run of this skill adds what it could not settle. A line
ending _needs …_ says what an agent on one machine does not have; a line
without one can be settled on a single running copy of the app.

Filed by run `20261011-2330`, the first full pass: 62 in the manual, 18 in the
notes and references. A second read the same day (`SKILL.md` §3c,
`references/second-read.md`) settled 45 of the 80 from files the first
reader had not followed to the end — 18 of them wrong, and corrected — and
four more were settled on a scratch dev instance or from the handler itself. **31 are open**: 27 in the
manual, 4 in the notes.
